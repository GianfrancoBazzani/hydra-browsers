# Hydra Browsers v1 — Plan 06: Live Proxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a logged-in user open the Neko live view of one session in an iframe on the live origin: a one-use live ticket becomes a live grant (cookie per `sid`), the gateway proxies the Neko HTTP and WebSocket traffic to the pod with the Neko login injected, and the grant ends by the rules of spec section 9.2.

**Architecture:** `LiveService` (`live-proxy/live-service.ts`) keeps live tickets in memory, live grants in the `live_grants` table (only the cookie HMAC), a registry of the open WebSockets of each grant, and the grant end rules: bus events (`login.ended`, `rights.changed`, `session.state`), a check of all rules on each request and upgrade, and a check every 60 s. The public scope gets `POST /api/sessions/:sid/live-ticket` and `DELETE /api/sessions/:sid/live-grant` (`api/live.ts`). The live scope gets the ticket redemption and an undici HTTP proxy (`live-proxy/http-routes.ts`). A raw `'upgrade'` listener on the Node HTTP server (`live-proxy/ws-proxy.ts`) checks the grant, sets the Neko login query values through the `NekoLoginStrategy` (`live-proxy/neko-login.ts`), and pipes the browser socket to the pod socket without parsing frames.

**Tech Stack:** TypeScript (strict, ESM), Node.js 24.21.0 built-ins (`node:http`, `node:net`, `node:stream`, `node:crypto`), Fastify 5, undici, Drizzle ORM on better-sqlite3, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-10-hydra-browsers-design.md`. This plan implements sections 1.3 (live ticket, live grant), 6.7, 6.8 (live origin), 9.1 to 9.4, 12.1 (live routes), 13.1 (`live_grants`), 14 (logs, SIGTERM, restart), and the rights change test of 15.2. Read these sections and section 7.10 before you start.

**Index:** `docs/superpowers/plans/2026-10-10-00-index.md`: section 2 (conventions), 3 (checkpoint step), 4 (file ownership), 5 (contracts, mainly 5.9, 5.11, 5.12), 6 (rows S2 and S3).

**Runs after:** plans 01 to 05. They deliver the contracts of index sections 5.1 to 5.11 and the test helpers `createTestApp`, `seedUser`, `loginAs`, `seedSession`, `FakeClock`, `testConfig` (index 5.12).

- Redemption: "The gateway validates and removes the ticket, creates a live grant (DB) and the audit event `live.opened`, sets the cookie `__Host-hydra_live_<sid>` (`HttpOnly`, `Secure`, `SameSite=Strict`, `Path=/`), and sends a 303 redirect to `<HYDRA_LIVE_URL>/s/<sid>/?embed=1&usr=<display name>&pwd=x`." (spec 9.2 step 3)
- "The proxy reads only the cookie of the `sid` in the path." (spec 9.2 step 3)
- Subkey `hydra/live-grant/v1`: "HMAC of live grant cookie values and live tickets" (spec 6.1). "The database stores no secret in plain text." (spec 6.2)
- `neko_password(sid, profile) = base64url(HMAC-SHA256(subkey neko, sid + "|" + profile))`. "owner, operator, and admin → Neko `admin` profile. Viewer → Neko `user` profile". "The browser never gets them" (spec 6.7).
- WebSocket: the gateway "replaces the `username` query value with the Hydra display name and the `password` value with the Neko password of the Neko profile" (spec 9.2 step 4).
- Live origin headers: `Content-Security-Policy: frame-ancestors <HYDRA_PUBLIC_URL>`, `Strict-Transport-Security: max-age=31536000`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` (spec 6.8).
- Proxy: "`/s/<sid>/*` on the live host goes to `podEndpoint(sid, 8080)` + `/*` … without the `/s/<sid>` prefix." "Each HTTP request and each WebSocket upgrade must have a valid live grant for that `sid`. If not: 401 for HTTP, and the upgrade is refused." "The gateway removes `Set-Cookie`, `Content-Security-Policy`, and the other headers of section 6.8 from pod responses". "It does not parse WebSocket frames." "No timeout on open WebSockets." (spec 9.3)
- A grant ends when its login session ends (`login.ended`); when the user loses `live.watch` or the Neko profile changes (`rights.changed`); when the session state changes to a state other than `starting` or `running`; 30 s after its last WebSocket closes, or 30 s after its creation if no WebSocket opens ("After a gateway restart, these 30 s start at the restart"); on `DELETE /api/sessions/<sid>/live-grant`; 12 h after its creation. "When a grant ends, the gateway closes its WebSockets at once." "Every 60 s, the live proxy also checks each open WebSocket against these rules" (spec 9.2).
- "SIGTERM: stop new requests, close open MCP streams and WebSockets after 10 s, close the DB." (spec 14)
- Logs never contain a grant cookie value, a Neko password, or a ticket that can still be used (spec 14 redact list; the request log shows `req.url` only after the redemption, see Task 5).
- Errors: `{ "error": { "code", "message" } }`. `unauthenticated` 401; `not_found` 404 without `session.read`; `invalid_state` 409 "a live ticket for a session that is not running" (spec 12.2).
- Each task ends with the Checkpoint step of index section 3.

## Verified facts

These facts were checked on 2026-10-10. The code of this plan depends on them.

**Neko v3.1.6** (tag commit `65fba485de2987998c7028b04240b21669d674e0`, released 2026-09-30, `github.com/m1k1o/neko`):

1. The image serves the legacy Vue client: `Dockerfile.tmpl` copies the `client/` build to `/var/www`. `client/vue.config.js` has `publicPath: './'`, so all asset URLs are relative and the client works under `/s/<sid>/` (the trailing slash matters).
2. WebSocket path: `client/src/neko/index.ts` builds `location.protocol.replace(/^http/, 'ws') + '//' + location.host + location.pathname.replace(/\/$/, '') + '/ws'`, so the browser opens `/s/<sid>/ws`, and the pod gets `/ws`.
3. Query names: `client/src/neko/base.ts` opens `${url}?password=${encodeURIComponent(password)}&username=${encodeURIComponent(displayname)}`.
4. Auto login: `client/src/components/connect.vue` reads `pwd` and `usr` with `new URL(location.href).searchParams` and then removes them from the address bar (`history.pushState`). A display name that the client stored earlier wins over `usr`; the gateway overwrites `username` anyway. `client/src/app.vue` reads `embed`.
5. HTTP requests of the client go to `<location.pathname>` + relative path: `GET api/oauth/config` on mount, `emoji.json`, `keyboard_layouts.json`, and file transfer (off in Hydra).
6. Server: `server/internal/http/legacy/handler.go` registers `GET /ws`, reads `username` and `password` from the query, and accepts any `Origin` (`CheckOrigin` returns true). `session.go` `create()` first calls `/api/whoami` with the `Cookie` header of the upgrade request if there is one, else `POST /api/login` with `{ username, password }`.
7. Legacy mode is on by default: `server/internal/config/root.go` defines the flag `legacy` with default `true`; `server/internal/http/manager.go` mounts the legacy routes.
8. Session cookies are off by default (`session.cookie.enabled`, `server/internal/config/session.go`), so `POST /api/login` returns the token in the JSON body (`server/internal/api/session.go`), which the legacy handler needs.
9. The `multiuser` provider (`server/internal/member/multiuser/provider.go`) selects the profile by password (admin password first) and uses `<username>-<random>` as the Neko session ID, so one display name can connect two times.
10. The legacy client does not reconnect a closed WebSocket by itself: `base.ts` sets `onclose = () => this.onDisconnected.bind(…)`, which returns a bound function and does not call it.

**Node.js 24.21.0, Fastify 5.12.5, undici 8.11.2** (scratch experiments). All code of this plan ran in a scratch copy of the server package with these versions plus drizzle-orm 0.45.3, better-sqlite3 13.0.3, pino 10.4.0, zod 4.6.5, Vitest 5.0.3, and stand-ins for the contracts of plans 02 to 05 (index section 5): 69 tests pass, `tsc --noEmit` passes with TypeScript 6.0.3 (also 5.9.3 and 7.0.2), ESLint 10.12.0 with typescript-eslint 8.71.0 `strictTypeChecked` passes (plan 01 uses the looser `recommended`), and Prettier 3.9.9 (`printWidth` 100) passes. The state after each task was also checked on its own.

11. `app.server.on('upgrade', …)` works next to host-constrained Fastify routes. With such a listener, Node sends every upgrade request of every host to it; requests without `Upgrade` still go to Fastify.
12. `app.close()` does not finish while an upgraded socket is open. It finishes when the socket is destroyed. So SIGTERM and the test helper must close the WebSockets.
13. `http.request({ agent: false, timeout })` with `Upgrade` emits `'upgrade'` with the parsed 101 response (`rawHeaders`) and the raw pod socket. Node removes the request timeout listener after the 101.
14. `scope.all('/s/:sid/*', …)` registers GET, HEAD, TRACE, DELETE, OPTIONS, PATCH, PUT, POST, QUERY. `/s/<sid>/` matches (empty wildcard); `/s/<sid>` does not.
15. A host constraint matches the exact `Host` value: `live.hydra.localhost:8080` does not match `live.hydra.localhost`.
16. In an encapsulated scope, `removeAllContentTypeParsers()` plus `addContentTypeParser('*', (request, payload, done) => done(null, payload))` makes `request.body` the raw request stream, also for a POST without `Content-Type`.
17. `reply.send(response.body)` of undici `request()` streams the body; undici `request()` does not decompress (`Content-Encoding` passes through); HEAD and 304 work.
18. An `onSend` hook of a child scope runs after the `onSend` hooks of the root, also for error responses, so the live scope can set its own CSP.
19. undici refuses the request headers `transfer-encoding`, `keep-alive`, `upgrade`, `expect`, and a `connection` value other than `keep-alive` or `close`.
20. `reply.redirect(url, 303)` is the Fastify 5 argument order.

## Review Focus

Inputs and conditions that the spec implies but that a person meets before a reviewer does. Each line has a test in the task that owns the code.

1. **The same session in two browser tabs of one browser.** The second ticket replaces the cookie `__Host-hydra_live_<sid>` of the first tab. Expected: the first tab's live view stays connected when the second tab closes, because its WebSocket keeps its own grant alive. Test: Task 7, "the same session in two browser tabs: closing one tab does not close the other".
2. **Display names with spaces, `&`, `+`, `%`, and non-ASCII letters.** Expected: the `usr` value of the redirect and the `username` value that Neko gets decode to exactly the display name. Tests: Task 5, "sets the grant cookie and redirects to the Neko client with the display name"; Task 6, "sends the upgrade to the pod with the display name and the Neko password of the profile".
3. **A logout in one browser while the same user watches in another browser.** Expected: only the live views of the ended login session close. Test: Task 7, "a logout ends the live views of that login session only".
4. **The pod is not reachable or goes away** (Restart, Stop, crash, port-forward not ready). Expected: HTTP and upgrade get 502, an open browser socket closes when the pod socket closes, the registry releases it (so the 30 s rule starts), and the failure itself does not end the grant. Tests: Task 5, "answers 502 when the pod is not reachable or its address is not known"; Task 6, "answers 502 …, and the grant stays" and "closes the browser socket when the pod goes away".
5. **The dashboard switches sessions in one browser tab before the previous ticket was redeemed.** Expected: `DELETE /api/sessions/<previous sid>/live-grant` also cancels the unused tickets of this login session for that session, so no grant appears after the DELETE. Test: Task 3, "ends only the grants of this login session for this session, and its unused tickets".

## Spec deviations

1. **When a WebSocket counts as open (spec 9.2, 30 s rule).** The plan counts a WebSocket from the moment the gateway accepts its upgrade request (valid grant) until its sockets close, also while the connection to the pod opens and also when that connection then fails. Reason: a grant end must close all WebSockets of the grant at once (spec 9.2), and that includes a WebSocket whose pod connection is still opening. Effect: a failed pod connection starts the 30 s again (once per upgrade attempt of a browser that holds the grant). The legacy client does not retry by itself (Verified fact 10), so this does not keep a closed view alive.

No other deviations. Notes that are not deviations: the redemption also accepts a session in `starting` (the grant rules permit `starting`; ticket creation still needs `running`); the redirect has `Cache-Control: no-store`; the 60 s check also deletes expired and idle grants, more often than the daily job of spec 13.3; an unreachable pod gives 502 with a short `text/plain` body, because spec 12.2 has no code for it and `/s/:sid/*` is not an `/api` route; an upgrade for another host or path gets 404.

```ts
/** A request path on the live host: /s/<sid><path>?<search>. */
export interface LivePath {
  sessionId: string;
  /** The path without the /s/<sid> prefix. It starts with "/". */
  path: string;
  /** The raw query string without "?", or "". */
  search: string;
}

// sid: 12 characters of [a-z2-7] (spec section 7.1).
const LIVE_PATH = /^\/s\/([a-z2-7]{12})(\/[^?]*)(?:\?(.*))?$/;

/** Parses the raw request URL (origin-form) of a live host request. Returns null for other URLs. */
export function parseLivePath(url: string): LivePath | null {
  const match = LIVE_PATH.exec(url);
  if (match === null) return null;
  const [, sessionId = '', path = '/', search = ''] = match;
  return { sessionId, path, search };
}

/** The upstream path: the path without the prefix, and the query with the given values set. */
export function upstreamPathOf(target: LivePath, set: Record<string, string>): string {
  if (Object.keys(set).length === 0) {
    return target.search === '' ? target.path : `${target.path}?${target.search}`;
  }
  const query = new URLSearchParams(target.search);
  for (const [name, value] of Object.entries(set)) query.set(name, value);
  return `${target.path}?${query.toString()}`;
}
```

Create `packages/server/src/live-proxy/headers.ts`. The pod must never get the cookies of the live origin: a compromised pod (spec 7.10) could reach the live origin through the internet and use them. `expect` and the hop-by-hop headers are removed because undici refuses them (Verified fact 19).

```ts
import type { IncomingHttpHeaders, IncomingMessage } from 'node:http';
import type { Config } from '../config/index.js';

type HeaderValue = string | string[] | undefined;

// Hop-by-hop headers (RFC 9110 section 7.6.1). undici also refuses most of them in a request.
const HOP_BY_HOP = [
  'connection',
  'keep-alive',
  'proxy-authenticate',
  'proxy-authorization',
  'proxy-connection',
  'te',
  'trailer',
  'transfer-encoding',
  'upgrade',
];

// The pod never gets the live grant cookies or other credentials of the browser.
// undici refuses `expect`.
const REMOVED_REQUEST_HEADERS = new Set([
  ...HOP_BY_HOP,
  'host',
  'cookie',
  'authorization',
  'expect',
]);

// A pod cannot set cookies or security headers on the live origin (spec sections 6.8 and 9.3).
const REMOVED_RESPONSE_HEADERS = new Set([
  ...HOP_BY_HOP,
  'set-cookie',
  'content-security-policy',
  'content-security-policy-report-only',
  'strict-transport-security',
  'x-content-type-options',
  'referrer-policy',
  'x-frame-options',
]);

/** The headers of the live origin (spec section 6.8). */
export function liveSecurityHeaders(config: Config): Record<string, string> {
  return {
    'content-security-policy': `frame-ancestors ${config.publicUrl.origin}`,
    'strict-transport-security': 'max-age=31536000',
    'x-content-type-options': 'nosniff',
    'referrer-policy': 'no-referrer',
  };
}

// Header names that the Connection header lists are hop-by-hop too.
function connectionTokens(value: HeaderValue): Set<string> {
  const joined = Array.isArray(value) ? value.join(',') : (value ?? '');
  return new Set(
    joined
      .split(',')
      .map((token) => token.trim().toLowerCase())
      .filter((token) => token !== ''),
  );
}

function withoutHeaders(
  headers: Record<string, HeaderValue>,
  removed: ReadonlySet<string>,
): Record<string, string | string[]> {
  const listed = connectionTokens(headers.connection);
  const result: Record<string, string | string[]> = {};
  for (const [name, value] of Object.entries(headers)) {
    const lower = name.toLowerCase();
    if (value === undefined || removed.has(lower) || listed.has(lower)) continue;
    result[lower] = value;
  }
  return result;
}

/** The browser request headers that the proxy sends to the pod. */
export function forwardRequestHeaders(
  headers: IncomingHttpHeaders,
): Record<string, string | string[]> {
  return withoutHeaders(headers, REMOVED_REQUEST_HEADERS);
}

/** The pod response headers that the proxy sends to the browser. */
export function filterResponseHeaders(
  headers: Record<string, HeaderValue>,
): Record<string, string | string[]> {
  return withoutHeaders(headers, REMOVED_RESPONSE_HEADERS);
}

/**
 * The raw "101 Switching Protocols" head for the browser. It keeps the pod's Upgrade, Connection,
 * and Sec-WebSocket-* headers, and removes the REMOVED_RESPONSE_HEADERS (for example Set-Cookie).
 */
export function upgradeResponseHead(response: IncomingMessage): string {
  const lines = ['HTTP/1.1 101 Switching Protocols'];
  for (let index = 0; index + 1 < response.rawHeaders.length; index += 2) {
    const name = response.rawHeaders[index] ?? '';
    const lower = name.toLowerCase();
    const handshake = lower === 'upgrade' || lower === 'connection';
    if (!handshake && REMOVED_RESPONSE_HEADERS.has(lower)) continue;
    lines.push(`${name}: ${response.rawHeaders[index + 1] ?? ''}`);
  }
  return `${lines.join('\r\n')}\r\n\r\n`;
}
```

```ts
import type { NekoProfile } from '@hydra/shared';
import { nekoPassword, type Subkeys } from '../crypto/index.js';
import type { LiveGrant } from './types.js';

/** What a strategy changes in a request to the pod. */
export interface UpstreamPatch {
  /** Query values to set. They replace the values that the browser sent. */
  query: Record<string, string>;
  /** Headers to set. */
  headers: Record<string, string>;
}

export interface NekoLoginInput {
  grant: LiveGrant;
  /** The current Hydra display name of the grant user. */
  displayName: string;
  /** Neko in the pod, as 'http://host:port' (podEndpoint(sid, 8080)). */
  endpoint: string;
}

/**
 * How the gateway logs the browser in to Neko (spec section 9.2 steps 4 and 5). This file is the
 * only place that changes when spike S2 or S3 fails (index section 6).
 *
 * - `queryRewrite` (main path, spec section 9.2 step 4). Verified in Neko v3.1.6: the legacy
 *   client opens `<location.pathname>/ws?password=…&username=…` (client/src/neko/index.ts and
 *   base.ts). The legacy handler (`GET /ws`, on by default: flag `legacy`, default true) reads the
 *   query values `username` and `password` and calls its own `POST /api/login`
 *   (server/internal/http/legacy/handler.go and session.go). The gateway replaces both values.
 *   HTTP requests need no login.
 * - `serverLogin` (fallback, spec section 9.2 step 5). Plan 09 adds it here only if spike S2
 *   fails. The legacy handler first calls `/api/whoami` with the Cookie header of the upgrade
 *   request and keeps that Neko session if it is valid (session.go `create()`). Neko reads a
 *   session cookie only with `NEKO_SESSION_COOKIE_ENABLED=true` (server/internal/session/auth.go
 *   `getToken()`, default false), and then `POST /api/login` returns the token in the
 *   `NEKO_SESSION` Set-Cookie header, not in the JSON body (server/internal/api/session.go
 *   `Login()`). So serverLogin sets `NEKO_SESSION_COOKIE_ENABLED=true` in the pod environment
 *   (orchestrator/manifests/neko-env.ts), logs in from the gateway with the Neko password of the
 *   profile, keeps the token per grant in memory, and sends `Cookie: NEKO_SESSION=<token>` with
 *   each HTTP request and upgrade to the pod. `forget()` drops the token. The browser never gets
 *   the token, because the proxy removes Set-Cookie.
 */
export interface NekoLoginStrategy {
  readonly name: 'queryRewrite' | 'serverLogin';
  /** Changes for a WebSocket upgrade request to the pod. */
  forUpgrade(input: NekoLoginInput): Promise<UpstreamPatch>;
  /** Changes for a proxied HTTP request to the pod. */
  forHttp(input: NekoLoginInput): Promise<UpstreamPatch>;
  /** The grant ended. Drop the state that the strategy keeps for it. */
  forget(grantId: string): void;
}

/**
 * The Neko user name of a person. Main path: the Hydra display name (spec section 9.2 step 4).
 * Spike S3 fallback (spec section 6.7): the fixed user of the Neko profile (`hydra-admin` or
 * `hydra-viewer`).
 */
export function nekoUsername(_profile: NekoProfile, displayName: string): string {
  return displayName;
}

export function createQueryRewriteStrategy(subkeys: Pick<Subkeys, 'neko'>): NekoLoginStrategy {
  return {
    name: 'queryRewrite',
    forUpgrade: ({ grant, displayName }) =>
      Promise.resolve({
        query: {
          username: nekoUsername(grant.nekoProfile, displayName),
          password: nekoPassword(subkeys.neko, grant.sessionId, grant.nekoProfile),
        },
        headers: {},
      }),
    forHttp: () => Promise.resolve({ query: {}, headers: {} }),
    forget: () => {},
  };
}

/** The strategy of the gateway. Plan 09 returns `serverLogin` here only if spike S2 fails. */
export function createNekoLoginStrategy(deps: {
  subkeys: Pick<Subkeys, 'neko'>;
}): NekoLoginStrategy {
  return createQueryRewriteStrategy(deps.subkeys);
}
```

How the service works:
- **Tickets** live in a `Map`. The key is the hex HMAC (subkey `liveGrant`) of the ticket, so the process does not keep the ticket value. A ticket is removed on its first use, also when the use fails. Expired tickets are removed on each `createTicket()`.

- **Each request checks all rules** (`endReason()`): 12 h expiry, the 30 s idle rule, the login session (spec 6.4), the session state (`starting` or `running`), and the current Neko profile (no `live.watch` or another profile ends the grant). A grant that breaks a rule ends there.
- **The 30 s idle rule** uses an in-memory map of grant activity. A grant that the process does not know (it was created before a gateway restart) is idle since `max(createdAt, startedAt)`, so its 30 s start at the restart (spec 9.2).
- **The access check** of `createTicket()` is `AccessService.requireSession(…, 'live.watch', …)`, which also writes `admin.session_access` for admins (index 5.8). The service builds the `request` argument (`POST /api/sessions/<sid>/live-ticket`), because the index signature `createTicket(context, sessionId)` has no request.
- **`users` and `login_sessions`** are read directly (index issue 5).

```ts
// A grant ends when its session state changes to a state other than these (spec section 9.2).
const GRANT_STATES: ReadonlySet<SessionState> = new Set<SessionState>(['starting', 'running']);

function toGrant(row: typeof liveGrants.$inferSelect): LiveGrant {

function invalidTicket(): HydraError {
  return new HydraError(
    'unauthenticated',

/**
 * Live tickets (in memory), live grants (table `live_grants`), the WebSocket registry, and the
 * grant end rules of spec section 9.2.
 */
export class LiveService {
  /** The Neko login strategy (spec section 9.2 steps 4 and 5). */
  readonly nekoLogin: NekoLoginStrategy;
  private readonly deps: LiveServiceDeps;
  /** After a gateway restart, the 30 s idle time of old grants starts here (spec section 9.2). */
  private readonly startedAt: number;
  /** Key: hex HMAC (subkey liveGrant) of the ticket. The ticket itself is not kept. */
  private readonly tickets = new Map<string, Ticket>();
  /** Key: grant ID. Grants that this process created or that have WebSockets. */
  private readonly activity = new Map<string, GrantActivity>();

  constructor(deps: LiveServiceDeps) {
    this.deps = deps;
    this.startedAt = deps.clock.now();
    this.nekoLogin = createNekoLoginStrategy(deps);
  }

  /** POST /api/sessions/:sid/live-ticket (spec section 9.2 steps 1 and 2). */
  createTicket(context: LoginContext, sessionId: string): LiveTicketResponse {
    const view = this.deps.access.requireSession(context, sessionId, 'live.watch', {
      method: 'POST',
      path: `/api/sessions/${sessionId}/live-ticket`,
    });
    if (this.sessionState(sessionId) !== 'running') {
      throw new HydraError('invalid_state', MESSAGES.sessionNotRunning);
    }
    const role = effectiveRole(context.user, view);
    if (role === null) throw new HydraError('not_found', 'Session not found.');
    const now = this.deps.clock.now();
    this.pruneTickets(now);
    const ticket = randomBase64Url(32);
    this.tickets.set(this.ticketKey(ticket), {
      loginSessionId: context.loginSessionId,
      userId: context.user.id,
      sessionId,
      nekoProfile: nekoProfileOf(role),
      expiresAt: now + LIVE_TICKET_TTL_MS,
    });
    const url = new URL(`/s/${sessionId}/`, this.deps.config.liveUrl);
    url.searchParams.set('ticket', ticket);
    return { url: url.href };
  }

  /**
   * GET /s/:sid/?ticket=… on the live host (spec section 9.2 step 3). Removes the ticket, checks
   * the grant rules, creates the grant, and writes `live.opened`. Throws `unauthenticated`.
   */
  redeemTicket(
    sessionId: string,
    ticket: string,
    meta: { ip: string },
  ): { cookieValue: string; grant: LiveGrant; displayName: string } {
    const key = this.ticketKey(ticket);
    const entry = this.tickets.get(key);
    this.tickets.delete(key);
    const now = this.deps.clock.now();
    if (entry === undefined || entry.expiresAt <= now || entry.sessionId !== sessionId) {
      throw invalidTicket();
    }
    const displayName = this.displayNameOf(entry.userId);
    if (
      displayName === null ||
      !this.loginSessionActive(entry.loginSessionId, now) ||
      !GRANT_STATES.has(this.sessionState(sessionId) ?? 'deleted') ||
      this.currentProfile(entry.userId, sessionId) !== entry.nekoProfile
    ) {
      throw invalidTicket();
    }
    const cookieValue = randomBase64Url(32);
    const grant: LiveGrant = {
      id: newUlid(this.deps.clock),
      loginSessionId: entry.loginSessionId,
      userId: entry.userId,
      sessionId,
      nekoProfile: entry.nekoProfile,
      createdAt: now,
      expiresAt: now + LIVE_GRANT_TTL_MS,
    };
    this.deps.db
      .insert(liveGrants)
      .values({ ...grant, cookieHmac: hmac(this.deps.subkeys.liveGrant, cookieValue) })
      .run();
    this.activity.set(grant.id, { grant, sockets: new Set(), idleSince: now });
    this.deps.audit.write({
      kind: 'live.opened',
      actorType: 'user',
      actorId: grant.userId,
      sessionId,
      data: { grantId: grant.id, nekoProfile: grant.nekoProfile, ip: meta.ip },
    });
    return { cookieValue, grant, displayName };
  }

  /**
   * The grant of this cookie value for this session, or null. A grant that breaks a rule of spec
   * section 9.2 ends here (its WebSockets close).
   */
  validateGrant(sessionId: string, cookieValue: string | undefined): LiveGrant | null {
    if (cookieValue === undefined || cookieValue === '') return null;
    const row = this.deps.db
      .select()
      .from(liveGrants)
      .where(eq(liveGrants.cookieHmac, hmac(this.deps.subkeys.liveGrant, cookieValue)))
      .get();
    if (row === undefined || row.sessionId !== sessionId) return null;
    const grant = toGrant(row);
    const reason = this.endReason(grant, this.deps.clock.now());
    if (reason !== null) {
      this.endGrants([grant], reason);
      return null;
    }
    return grant;
  }

  /** DELETE /api/sessions/:sid/live-grant: ends the grants of this login session there. */
  endGrant(context: LoginContext, sessionId: string): void {
    const matches = (item: { loginSessionId: string; sessionId: string }): boolean =>
      item.loginSessionId === context.loginSessionId && item.sessionId === sessionId;
    const where = and(
      eq(liveGrants.loginSessionId, context.loginSessionId),
      eq(liveGrants.sessionId, sessionId),
    );
    this.endGrants(this.findGrants(where, matches), 'ended_by_user');
    this.dropTickets(matches);
  }

  /** The current Hydra display name of a user, or null. */
  displayNameOf(userId: string): string | null {
    const row = this.deps.db
      .select({ displayName: users.displayName })
      .from(users)
      .where(eq(users.id, userId))
      .get();
    return row?.displayName ?? null;
  }

  /** The first rule of spec section 9.2 that the grant breaks, or null. */
  private endReason(grant: LiveGrant, now: number): GrantEndReason | null {
    if (now >= grant.expiresAt) return 'expired';
    const entry = this.activity.get(grant.id);
    if (entry === undefined || entry.sockets.size === 0) {
      const idleSince = entry?.idleSince ?? Math.max(grant.createdAt, this.startedAt);
      if (now - idleSince >= LIVE_GRANT_IDLE_MS) return 'idle';
    }
    if (!this.loginSessionActive(grant.loginSessionId, now)) return 'login_ended';
    if (!GRANT_STATES.has(this.sessionState(grant.sessionId) ?? 'deleted')) return 'session_state';
    if (this.currentProfile(grant.userId, grant.sessionId) !== grant.nekoProfile) {
      return 'rights_changed';
    }
    return null;
  }

  // Idle timeout 12 h and maximum life (expires_at) of spec section 6.4.
  private loginSessionActive(loginSessionId: string, now: number): boolean {
    const row = this.deps.db
      .select({ lastSeenAt: loginSessions.lastSeenAt, expiresAt: loginSessions.expiresAt })
      .from(loginSessions)
      .where(eq(loginSessions.id, loginSessionId))
      .get();
    return row !== undefined && row.expiresAt > now && now - row.lastSeenAt < LOGIN_IDLE_MS;
  }

  private sessionState(sessionId: string): SessionState | null {
    const row = this.deps.db
      .select({ state: sessions.state, deletedAt: sessions.deletedAt })
      .from(sessions)
      .where(eq(sessions.id, sessionId))
      .get();
    return row === undefined || row.deletedAt !== null ? null : row.state;
  }

  /** The Neko profile that the user has now on the session, or null without `live.watch`. */
  private currentProfile(userId: string, sessionId: string): NekoProfile | null {
    const user = this.loadUser(userId);
    const view = this.deps.access.view(userId, sessionId);
    if (user === null || view === null || !authorize(user, view, 'live.watch')) return null;
    const role = effectiveRole(user, view);
    return role === null ? null : nekoProfileOf(role);
  }

  private loadUser(userId: string): AuthedUser | null {
    const row = this.deps.db
      .select({
        id: users.id,
        email: users.email,
        displayName: users.displayName,
        role: users.role,
        status: users.status,
        mustChangePassword: users.mustChangePassword,
      })
      .from(users)
      .where(eq(users.id, userId))
      .get();
    return row ?? null;
  }

  /** Grants from the DB plus grants that are only in memory (their row is already gone). */
  private findGrants(where: SQL | undefined, matches: (grant: LiveGrant) => boolean): LiveGrant[] {
    const found = new Map<string, LiveGrant>();
    for (const row of this.deps.db.select().from(liveGrants).where(where).all()) {
      found.set(row.id, toGrant(row));
    }
    for (const entry of this.activity.values()) {
      if (matches(entry.grant)) found.set(entry.grant.id, entry.grant);
    }
    return [...found.values()];
  }

  /** Deletes the grants and closes their WebSockets at once. Returns the number of grants. */
  private endGrants(grants: LiveGrant[], reason: GrantEndReason): number {
    const unique = [...new Map(grants.map((grant) => [grant.id, grant])).values()];
    if (unique.length === 0) return 0;
    const ids = unique.map((grant) => grant.id);
    this.deps.db.delete(liveGrants).where(inArray(liveGrants.id, ids)).run();
    for (const grant of unique) {
      const entry = this.activity.get(grant.id);
      this.activity.delete(grant.id);
      this.nekoLogin.forget(grant.id);
      const sockets = entry === undefined ? [] : [...entry.sockets];
      for (const socket of sockets) socket.close(reason);
      this.deps.logger.info(
        {
          grantId: grant.id,
          sessionId: grant.sessionId,
          userId: grant.userId,
          reason,
          sockets: sockets.length,
        },
        'live grant ended',
      );
    }
    return unique.length;
  }

  private ticketKey(ticket: string): string {
    return hmac(this.deps.subkeys.liveGrant, ticket).toString('hex');
  }

  private pruneTickets(now: number): void {
    this.dropTickets((ticket) => ticket.expiresAt <= now);
  }

  private dropTickets(matches: (ticket: Ticket) => boolean): void {
    for (const [key, ticket] of this.tickets) {
      if (matches(ticket)) this.tickets.delete(key);
    }
  }
}
```

**Files:**
- Modify: `packages/server/src/live-proxy/live-service.ts`, `packages/server/src/live-proxy/index.ts`, `packages/server/src/main.ts`, `packages/server/test/helpers/app.ts`
- Create: `packages/server/src/live-proxy/deps.ts`, `packages/server/src/live-proxy/connection-check.ts`
- Test: `packages/server/test/integration/live-grant-rules.test.ts`, `packages/server/src/live-proxy/connection-check.test.ts`

How it works:
- `openSocket(grant, socket)` adds a `LiveSocket` to the grant. The returned function removes it; when the last one goes, the 30 s idle time starts.
- The bus handlers end grants at once and call `close()` on their sockets: `login.ended` (the grant rows can already be gone by the cascade of `login_sessions`, so the in-memory registry is also searched), `rights.changed` (re-checks each grant of the user; only grants whose Neko profile changed or that lost `live.watch` end), `session.state` (all grants of the session end for states other than `starting` and `running`).
- `checkConnections()` runs `endReason()` for every grant row, ends grants that break a rule, and closes the sockets of grants whose row disappeared without an event. It also removes expired tickets.
- `closeAll(reason)` closes all sockets and keeps the grants (SIGTERM, spec 14: "Live grants are in the DB, so the live view continues after the restart").

**Interfaces:**
- Consumes: `LiveService` of Task 3; `PodEndpointResolver` from `src/orchestrator/index.ts` (index 5.10); `EventBus.subscribe(type, handler): () => void` (index 5.6, events `login.ended` with `loginSessionIds`, `rights.changed` with `userId`, `session.state` with `sessionId` and `state`).
- Produces: `LiveService.openSocket(grant: LiveGrant, socket: LiveSocket): () => void`, `openSocketCount(grantId?: string): number`, `checkConnections(): number` (number of ended grants), `closeAll(reason: string): number` (number of closed sockets), `dispose(): void`; `interface LiveProxyDeps { config; logger; live; podEndpoints }`; `startLiveConnectionCheck(deps: Pick<LiveProxyDeps, 'live' | 'logger'>): () => void`.

How it works:
- `registerLiveHostRoutes(scope, deps)` runs inside the live scope of `buildApp`, so every route gets the host constraint `config.liveUrl.host` (index 5.9). It replaces the content type parsers of this scope with a catch-all parser that returns the raw request stream (Verified fact 16), and adds an `onSend` hook that sets the live origin headers on every response of the scope, also on errors (Verified fact 18).
- `GET /s/<sid>/?ticket=…` redeems the ticket (spec 9.2 step 3). The redirect builds `usr` with `encodeURIComponent`, which both `URLSearchParams` (Neko client) and `decodeURIComponent` read back.
- Every other request needs a valid grant for the `sid` in the path (cookie `__Host-hydra_live_<sid>`), else 401 `unauthenticated`. The proxy uses undici `request()` with the raw body stream, removes the request headers of Task 1 (no cookies, no credentials), and sends the pod response back with `filterResponseHeaders()`. The upstream URL is built by string concatenation, so a path like `//evil.example/x` stays a path on the pod.
- An unreachable pod gives 502 with a short `text/plain` body.
- The Fastify request log writes `req.url`, which contains the ticket of a redemption. The service removes the ticket before it sends the response, so a log reader gets only a used ticket. Upgrade requests do not go through Fastify, so the Neko password in the upstream query is never logged.

- Consumes: `LiveService` (Tasks 3 and 4), `LiveProxyDeps` (Task 4), `PodEndpointResolver.endpoint(sessionId, 8080): Promise<string>` (index 5.10, `'http://host:port'`), `request` from `undici`, `HydraError`, the helpers of Task 1, `NekoLoginStrategy.forHttp()` (Task 2).

```ts
/** An unmasked text frame (server to client), payload shorter than 126 bytes. */
export function serverTextFrame(text: string): Buffer {
  const payload = Buffer.from(text);
  return Buffer.concat([Buffer.from([0x81, payload.length]), payload]);

/**
 * A fake Neko server (HTTP and WebSocket) for the live proxy tests.
 * - GET / and GET /?…: an HTML page with the headers that the proxy must remove.
 * - Other HTTP requests: JSON echo of { method, url, headers, body }.
 * - WebSocket upgrade: records path, query, and headers, answers 101 (with a Set-Cookie header that
 *   the proxy must remove), sends the text frame "hello", and then echoes all bytes unparsed.
 */
export async function startFakeNeko(): Promise<FakeNeko> {
  const upgrades: FakeNekoUpgrade[] = [];
  const sockets = new Set<Socket>();
  const server = createServer((request, response) => {
    let body = '';
    request.setEncoding('utf8');
    request.on('data', (chunk: string) => {
      body += chunk;
    });
    request.on('end', () => {
      if (request.url === '/' || request.url?.startsWith('/?') === true) {
        response.writeHead(200, {
          'content-type': 'text/html; charset=utf-8',
          'set-cookie': 'NEKO_SESSION=abc; Path=/',
          'content-security-policy': "default-src 'none'",
          'x-frame-options': 'DENY',
          'strict-transport-security': 'max-age=1',
          'referrer-policy': 'unsafe-url',
          'x-neko': 'fake',
        });
        response.end('<!doctype html><title>neko</title>');
        return;
      }
      response.writeHead(200, { 'content-type': 'application/json' });
      response.end(
        JSON.stringify({
          method: request.method,
          url: request.url,
          headers: request.headers,
          body,
        }),
      );
    });
  });
  server.on('connection', (socket) => {
    sockets.add(socket);
    socket.on('close', () => sockets.delete(socket));
  });
  server.on('upgrade', (request, socket) => {
    const url = new URL(request.url ?? '/', 'http://neko.invalid');
    upgrades.push({ path: url.pathname, query: url.searchParams, headers: request.headers });
    const accept = createHash('sha1')
      .update(`${String(request.headers['sec-websocket-key'])}${WS_GUID}`)
      .digest('base64');
    socket.write(
      [
        'HTTP/1.1 101 Switching Protocols',
        'Upgrade: websocket',
        'Connection: Upgrade',
        `Sec-WebSocket-Accept: ${accept}`,
        'Set-Cookie: NEKO_SESSION=abc; Path=/',
        '',
        '',
      ].join('\r\n'),
    );
    socket.write(serverTextFrame('hello'));
    socket.on('data', (chunk: Buffer) => socket.write(chunk));
    socket.on('end', () => socket.end());
    socket.on('error', () => socket.destroy());
  });
  await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve));
  const { port } = server.address() as AddressInfo;
  return {
    url: `http://127.0.0.1:${String(port)}`,
    upgrades,
    stop: async () => {
      for (const socket of sockets) socket.destroy();
      await new Promise<void>((resolve) => {
        server.close(() => {
          resolve();
        });
      });
    },
  };
```

```ts
import { Readable } from 'node:stream';
import type { FastifyInstance, FastifyReply, FastifyRequest } from 'fastify';
import { request as undiciRequest, type Dispatcher } from 'undici';
import { HydraError } from '../lib/errors.js';
import { NEKO_PORT } from './constants.js';
import { liveCookieName, readCookie, serializeLiveCookie } from './cookies.js';
import type { LiveProxyDeps } from './deps.js';
import { filterResponseHeaders, forwardRequestHeaders, liveSecurityHeaders } from './headers.js';
import { parseLivePath, upstreamPathOf, type LivePath } from './paths.js';
import type { LiveGrant } from './types.js';

/**
 * Live host routes (spec sections 9.2 step 3 and 9.3): ticket redemption, and the HTTP proxy of
 * /s/<sid>/* to podEndpoint(sid, 8080) without the /s/<sid> prefix. `scope` is the live scope of
 * buildApp, so all routes get the host constraint config.liveUrl.host.
 */
export function registerLiveHostRoutes(scope: FastifyInstance, deps: LiveProxyDeps): void {
  // The proxy streams request bodies to the pod: no body parsing in this scope.
  scope.removeAllContentTypeParsers();
  scope.addContentTypeParser('*', (_request, payload, done) => {
    done(null, payload);
  });

  // The headers of the live origin on each response of this scope (spec section 6.8).
  const securityHeaders = liveSecurityHeaders(deps.config);
  scope.addHook('onSend', async (_request, reply, payload) => {
    reply.headers(securityHeaders);
    return payload;
  });

  scope.all('/s/:sid/*', async (request, reply) => {
    const target = parseLivePath(request.url);
    if (target === null) throw new HydraError('not_found', 'Not found.');
    const ticket = new URLSearchParams(target.search).get('ticket');
    if (request.method === 'GET' && target.path === '/' && ticket !== null) {
      return redeem(deps, target.sessionId, ticket, request, reply);
    }
    const cookie = readCookie(request.headers.cookie, liveCookieName(target.sessionId));
    const grant = deps.live.validateGrant(target.sessionId, cookie);
    if (grant === null) {
      throw new HydraError(
        'unauthenticated',
        'No live grant for this session. Open the live view again.',
      );
    }
    return proxy(deps, grant, target, request, reply);
  });
}

function redeem(
  deps: LiveProxyDeps,
  sessionId: string,
  ticket: string,
  request: FastifyRequest,
  reply: FastifyReply,
): FastifyReply {
  const { cookieValue, displayName } = deps.live.redeemTicket(sessionId, ticket, {
    ip: request.ip,
  });
  const client = new URL(`/s/${sessionId}/`, deps.config.liveUrl);
  // pwd=x is a dummy: it only makes the legacy Neko client log in automatically (spec section 9.2).
  const location = `${client.href}?embed=1&usr=${encodeURIComponent(displayName)}&pwd=x`;
  return reply
    .header('set-cookie', serializeLiveCookie(sessionId, cookieValue))
    .header('cache-control', 'no-store')
    .redirect(location, 303);
}

async function proxy(
  deps: LiveProxyDeps,
  grant: LiveGrant,
  target: LivePath,
  request: FastifyRequest,
  reply: FastifyReply,
): Promise<FastifyReply> {
  let response: Dispatcher.ResponseData;
  try {
    // String concatenation, not new URL(path, base): a path like //other.host stays a path.
    const base = await deps.podEndpoints.endpoint(grant.sessionId, NEKO_PORT);
    const endpoint = base.replace(/\/+$/, '');
    const displayName = deps.live.displayNameOf(grant.userId) ?? '';
    const patch = await deps.live.nekoLogin.forHttp({ grant, displayName, endpoint });
    response = await undiciRequest(`${endpoint}${upstreamPathOf(target, patch.query)}`, {
      method: request.method,
      headers: { ...forwardRequestHeaders(request.headers), ...patch.headers },
      // The catch-all content type parser of this scope gives the raw request stream.
      body: request.body instanceof Readable ? request.body : null,
    });
  } catch (error) {
    request.log.warn(
      { err: error, sessionId: grant.sessionId },
      'live proxy: the pod is not reachable',
    );
    return reply
      .code(502)
      .type('text/plain; charset=utf-8')
      .send('The live view is not reachable.');
  }
  return reply
    .code(response.statusCode)
    .headers(filterResponseHeaders(response.headers))
    .send(response.body);
}
```

**Files:**

How it works (Node built-ins only; no WebSocket library, because the proxy never parses frames):
- `attachLiveUpgrade(server, deps)` listens to `'upgrade'` on the Node HTTP server. Node then sends every upgrade request of every host to this listener (Verified fact 11), so an upgrade for another host, or for a path that is not `/s/<sid>/…`, gets `404`. The public host has no WebSocket routes.
- The listener checks the grant of the `sid` in the path (else `401`), registers the WebSocket with the grant at once (`openSocket`), gets the pod address, asks the strategy for the query values (`username`, `password`), and sends the upgrade request to the pod with `http.request({ agent: false, timeout: 10 s })`. The request headers of Task 1 are removed (the pod never gets the grant cookie), and `Connection: Upgrade` and `Upgrade` are set.
- On the pod's `101`, it writes the filtered 101 head to the browser (no `Set-Cookie`), passes the first bytes of both sides, sets no timeout and `noDelay` on both sockets, and pipes them. A pod error, a pod `close`, a browser `close`, or a grant end destroys both sockets. `pipe()` forwards the end of each direction.
- A failed pod connection gives `502`. The connect timeout applies only until the `101` (Verified fact 13).

**Interfaces:**
- Consumes: `LiveProxyDeps` (Task 4), `LiveService.validateGrant/openSocket/displayNameOf/nekoLogin` (Tasks 2 to 4), `parseLivePath`, `upstreamPathOf`, `readCookie`, `liveCookieName`, `forwardRequestHeaders`, `upgradeResponseHead` (Task 1), `NEKO_PORT`, `UPSTREAM_CONNECT_TIMEOUT_MS`.
- Produces: `attachLiveUpgrade(server: import('node:http').Server, deps: LiveProxyDeps): void`; test helpers `clientTextFrame(text)`, `openLiveWebSocket(options): Promise<TestWebSocket>`, `TestWebSocket { statusCode; headers; socket; received(); closed }`, `waitFor(condition, timeoutMs?)`.

```ts
/** An unmasked text frame (server to client), payload shorter than 126 bytes. */
export function serverTextFrame(text: string): Buffer {
  const payload = Buffer.from(text);
  return Buffer.concat([Buffer.from([0x81, payload.length]), payload]);
}

/** A masked text frame (client to server), payload shorter than 126 bytes. */
export function clientTextFrame(text: string): Buffer {
  const payload = Buffer.from(text);
  const mask = randomBytes(4);
  const masked = Buffer.from(payload.map((byte, index) => byte ^ (mask[index % 4] ?? 0)));
  return Buffer.concat([Buffer.from([0x81, 0x80 | payload.length]), mask, masked]);
}

/**
 * A fake Neko server (HTTP and WebSocket) for the live proxy tests.
 * - GET / and GET /?…: an HTML page with the headers that the proxy must remove.
 * - Other HTTP requests: JSON echo of { method, url, headers, body }.
 * - WebSocket upgrade: records path, query, and headers, answers 101 (with a Set-Cookie header that
 *   the proxy must remove), sends the text frame "hello", and then echoes all bytes unparsed.
 */
export async function startFakeNeko(): Promise<FakeNeko> {
  const upgrades: FakeNekoUpgrade[] = [];
  const sockets = new Set<Socket>();
  const server = createServer((request, response) => {
    let body = '';
    request.setEncoding('utf8');
    request.on('data', (chunk: string) => {
      body += chunk;
    });
    request.on('end', () => {
      if (request.url === '/' || request.url?.startsWith('/?') === true) {
        response.writeHead(200, {
          'content-type': 'text/html; charset=utf-8',
          'set-cookie': 'NEKO_SESSION=abc; Path=/',
          'content-security-policy': "default-src 'none'",
          'x-frame-options': 'DENY',
          'strict-transport-security': 'max-age=1',
          'referrer-policy': 'unsafe-url',
          'x-neko': 'fake',
        });
        response.end('<!doctype html><title>neko</title>');
        return;
      }
      response.writeHead(200, { 'content-type': 'application/json' });
      response.end(
        JSON.stringify({
          method: request.method,
          url: request.url,
          headers: request.headers,
          body,
        }),
      );
    });
  });
  server.on('connection', (socket) => {
    sockets.add(socket);
    socket.on('close', () => sockets.delete(socket));
  });
  server.on('upgrade', (request, socket) => {
    const url = new URL(request.url ?? '/', 'http://neko.invalid');
    upgrades.push({ path: url.pathname, query: url.searchParams, headers: request.headers });
    const accept = createHash('sha1')
      .update(`${String(request.headers['sec-websocket-key'])}${WS_GUID}`)
      .digest('base64');
    socket.write(
      [
        'HTTP/1.1 101 Switching Protocols',
        'Upgrade: websocket',
        'Connection: Upgrade',
        `Sec-WebSocket-Accept: ${accept}`,
        'Set-Cookie: NEKO_SESSION=abc; Path=/',
        '',
        '',
      ].join('\r\n'),
    );
    socket.write(serverTextFrame('hello'));
    socket.on('data', (chunk: Buffer) => socket.write(chunk));
    socket.on('end', () => socket.end());
    socket.on('error', () => socket.destroy());
  });
  await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve));
  const { port } = server.address() as AddressInfo;
  return {
    url: `http://127.0.0.1:${String(port)}`,
    upgrades,
    stop: async () => {
      for (const socket of sockets) socket.destroy();
      await new Promise<void>((resolve) => {
        server.close(() => {
          resolve();
        });
      });
    },
  };
}

export interface TestWebSocket {
  statusCode: number;
  headers: IncomingHttpHeaders;
  /** The upgraded socket, or null when the gateway refused the upgrade. */
  socket: Socket | null;
  /** All bytes received after the handshake. */
  received(): Buffer;
  /** Resolves when the socket closes. */
  closed: Promise<void>;
}

/** Opens a WebSocket to the gateway (handshake only, no frame parsing) with this Host header. */
export function openLiveWebSocket(options: {
  port: number;
  host: string;
  path: string;
  cookie?: string;
}): Promise<TestWebSocket> {
  return new Promise((resolve, reject) => {
    const request = httpRequest({
      host: '127.0.0.1',
      port: options.port,
      path: options.path,
      headers: {
        host: options.host,
        connection: 'Upgrade',
        upgrade: 'websocket',
        'sec-websocket-version': '13',
        'sec-websocket-key': randomBytes(16).toString('base64'),
        ...(options.cookie === undefined ? {} : { cookie: options.cookie }),
      },
    });
    request.on('upgrade', (response, socket, head) => {
      const chunks: Buffer[] = [head];
      socket.on('data', (chunk: Buffer) => chunks.push(chunk));
      socket.on('error', () => socket.destroy());
      const closed = new Promise<void>((done) => {
        socket.once('close', () => {
          done();
        });
      });
      resolve({
        statusCode: response.statusCode ?? 0,
        headers: response.headers,
        socket,
        received: () => Buffer.concat(chunks),
        closed,
      });
    });
    request.on('response', (response) => {
      response.resume();
      resolve({
        statusCode: response.statusCode ?? 0,
        headers: response.headers,
        socket: null,
        received: () => Buffer.alloc(0),
        closed: Promise.resolve(),
      });
    });
    request.on('error', reject);
    request.end();
  });
}

/** Polls the condition every 10 ms until it is true. Fails after the timeout. */
export async function waitFor(condition: () => boolean, timeoutMs = 2_000): Promise<void> {
  const deadline = Date.now() + timeoutMs;
  while (!condition()) {
    if (Date.now() > deadline) throw new Error('waitFor: condition not met in time');
    await new Promise((resolve) => setTimeout(resolve, 10));
  }
}
```

```ts
import {
  request as httpRequest,
  STATUS_CODES,
  type ClientRequest,
  type IncomingMessage,
  type Server,
} from 'node:http';
import { Socket } from 'node:net';
import type { Duplex } from 'node:stream';
import { NEKO_PORT, UPSTREAM_CONNECT_TIMEOUT_MS } from './constants.js';
import { liveCookieName, readCookie } from './cookies.js';
import type { LiveProxyDeps } from './deps.js';
import { forwardRequestHeaders, upgradeResponseHead } from './headers.js';
import { parseLivePath, upstreamPathOf } from './paths.js';

/**
 * The WebSocket proxy of the live host (spec section 9.3). It listens to the 'upgrade' event of the
 * Node HTTP server, so every upgrade request comes here: other hosts and paths get 404. It connects
 * the browser socket and the pod socket without parsing frames and without a timeout.
 */
export function attachLiveUpgrade(server: Server, deps: LiveProxyDeps): void {
  server.on('upgrade', (request: IncomingMessage, socket: Duplex, head: Buffer) => {
    handleUpgrade(deps, request, socket, head).catch((error: unknown) => {
      deps.logger.warn({ err: error }, 'live proxy: WebSocket to the pod failed');
      refuse(socket, 502);
    });
  });
}

async function handleUpgrade(
  deps: LiveProxyDeps,
  request: IncomingMessage,
  socket: Duplex,
  head: Buffer,
): Promise<void> {
  socket.on('error', () => socket.destroy());
  const isLiveHost = request.headers.host === deps.config.liveUrl.host;
  const target = isLiveHost ? parseLivePath(request.url ?? '') : null;
  if (target === null) {
    refuse(socket, 404);
    return;
  }
  const cookie = readCookie(request.headers.cookie, liveCookieName(target.sessionId));
  const grant = deps.live.validateGrant(target.sessionId, cookie);
  if (grant === null) {
    refuse(socket, 401);
    return;
  }

  // The pod side, once it exists. A grant end destroys both sides at once.
  const pod: { request?: ClientRequest; socket?: Duplex } = {};
  const destroyAll = (): void => {
    pod.request?.destroy();
    pod.socket?.destroy();
    socket.destroy();
  };
  // The WebSocket counts as open from here, also while the connection to the pod opens.
  const release = deps.live.openSocket(grant, { close: destroyAll });
  socket.once('close', () => {
    release();
    destroyAll();
  });

  const endpoint = new URL(await deps.podEndpoints.endpoint(grant.sessionId, NEKO_PORT));
  const displayName = deps.live.displayNameOf(grant.userId) ?? '';
  const patch = await deps.live.nekoLogin.forUpgrade({
    grant,
    displayName,
    endpoint: endpoint.origin,
  });
  if (socket.destroyed) return;

  const upstreamRequest = httpRequest({
    hostname: endpoint.hostname.replace(/^\[(.*)\]$/, '$1'),
    port: endpoint.port,
    method: 'GET',
    path: upstreamPathOf(target, patch.query),
    headers: {
      ...forwardRequestHeaders(request.headers),
      ...patch.headers,
      connection: 'Upgrade',
      upgrade: request.headers.upgrade ?? 'websocket',
    },
    agent: false,
    timeout: UPSTREAM_CONNECT_TIMEOUT_MS,
  });
  pod.request = upstreamRequest;
  upstreamRequest.on('timeout', () => {
    upstreamRequest.destroy(new Error('connect timeout'));
  });
  upstreamRequest.on('error', (error) => {
    if (!socket.destroyed) {
      deps.logger.warn(
        { err: error, sessionId: grant.sessionId },
        'live proxy: WebSocket to the pod failed',
      );
    }
    refuse(socket, 502);
  });
  upstreamRequest.on('response', (response) => {
    response.resume();
    refuse(socket, 502);
  });
  upstreamRequest.on('upgrade', (response, upstream, upstreamHead) => {
    pod.socket = upstream;
    if (socket.destroyed) {
      upstream.destroy();
      return;
    }
    connect(socket, upstream, { response, head, upstreamHead, destroyAll });
  });
  upstreamRequest.end();
}

/** Sends the filtered 101 head to the browser, then connects the sockets without parsing frames. */
function connect(
  browser: Duplex,
  pod: Duplex,
  input: { response: IncomingMessage; head: Buffer; upstreamHead: Buffer; destroyAll: () => void },
): void {
  for (const side of [browser, pod]) {
    if (side instanceof Socket) {
      side.setTimeout(0); // no timeout on open WebSockets (spec section 9.3)
      side.setNoDelay(true);
    }
  }
  browser.write(upgradeResponseHead(input.response));
  if (input.upstreamHead.length > 0) browser.write(input.upstreamHead);
  if (input.head.length > 0) pod.write(input.head);
  pod.on('error', input.destroyAll);
  pod.on('close', input.destroyAll);
  // pipe() also forwards the end of each direction (TCP FIN) to the other socket.
  browser.pipe(pod);
  pod.pipe(browser);
}

/** Answers an upgrade request with an HTTP error and closes the socket. */
function refuse(socket: Duplex, status: 401 | 404 | 502): void {
  if (socket.destroyed || !socket.writable) {
    socket.destroy();
    return;
  }
  socket.once('finish', () => socket.destroy());
  const reason = STATUS_CODES[status] ?? '';
  socket.end(
    `HTTP/1.1 ${String(status)} ${reason}\r\nConnection: close\r\nContent-Length: 0\r\n\r\n`,
  );
}
```
