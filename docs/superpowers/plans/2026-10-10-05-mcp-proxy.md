# Hydra Browsers v1 — Plan 05: MCP Proxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the MCP endpoint `POST/GET/DELETE /s/:sid/mcp`: bearer check, session state check, rate and body limits, JSON-RPC inspection with the tool deny list, audit records with redacted arguments, a streaming proxy to the Playwright MCP sidecar, the MCP stream registry with its close rules, and the agent activity summary for the dashboard.

**Architecture:** `src/mcp-proxy/` has small pure modules (JSON-RPC parser, incremental SSE parser, header rules, deny list, stream registry, activity tracker) and two stateful parts: `McpExchange` writes the audit records of one proxied request from a copy of the response, and `routes.ts` runs the checks in a Fastify `onRequest` hook (so the order is 401, 503, 429, then 413 from the body parser), takes the raw body in its own encapsulated scope, and then hijacks the reply and pipes the pod response through a `Transform` that feeds the exchange before each chunk goes to the client. `src/audit/redaction.ts` holds one redaction rule for each of the 72 tools of `@playwright/mcp` 0.0.83. The `ActivityTracker` reads the `mcp.*` audit events from the bus and publishes `session.activity`.

**Tech Stack:** TypeScript 6.0.3 (strict, ESM), Node.js 24.21.0, Fastify 5.12.5, undici 8.11.2, `@playwright/mcp` 0.0.83 (sidecar and tests), `@modelcontextprotocol/sdk` 1.32.0 (tests only), Vitest 5.0.3.

**Spec:** `docs/superpowers/specs/2026-10-10-hydra-browsers-design.md` — sections 6.6 (rate limit), 8.1 to 8.7, 9.4 and 10.2 (the `agentActivity` data), 14 (SIGTERM), 15.1 and 15.2 (MCP proxy tests).

**Index:** `docs/superpowers/plans/2026-10-10-00-index.md` — conventions (sections 2 and 3), file ownership (section 4), contracts 5.7 (`redactArguments`), 5.11 (plan 05 part), 5.12 (`startPlaywrightMcp`).

## Global Constraints

- No commits (`AGENTS.md` rule 1). Each task ends with the Checkpoint step of index section 3. The spec is not edited (`AGENTS.md` rule 2).
- Endpoint: `<HYDRA_PUBLIC_URL>/s/<sid>/mcp` with the MCP Streamable HTTP transport (`POST`, `GET`, `DELETE`). v1 does not support the old SSE transport (`/sse`).
- Principal: if the token is missing, not valid, or for a different session: 401 with `WWW-Authenticate: Bearer realm="hydra"`. The token is accepted only in the `Authorization: Bearer` header.
- Session state: if `state` is not `running`: 503 with the body `{"jsonrpc":"2.0","error":{"code":-32000,"message":"Session is not running. Start it in the dashboard."},"id":null}`.
- Limits: 20 requests per second for each token (429 `rate_limited`). Maximum body 1 MiB (413).
- Proxy with `undici` to `podEndpoint(sid, 8931)` + `/mcp`. Remove `Authorization`, `Cookie`, and hop-by-hop headers. Set `Host: localhost:8931`. Send `Mcp-Session-Id`, `Accept`, `Content-Type`, and `MCP-Protocol-Version` without changes.
- Response: `application/json` or `text/event-stream`, sent to the client immediately, without a buffer, and without a timeout on open MCP streams. A copy of the response completes the audit records. The pod 404 for an old `Mcp-Session-Id` goes to the client without changes.
- Audit: `mcp.connect` when an `initialize` response succeeds (`mcpSessionId`, `clientInfo` (name, version), `ip`). `mcp.tool_call` with `status = pending` before the request goes to the pod, then `ok` or `error` (`error` max 500 characters; `"stream closed"` if the MCP stream closes first). Data fields: `mcpSessionId`, `rpcId`, `tool`, `arguments` (after redaction), `durationMs`, `error`. No records for tool results, `tools/list`, `ping`, or disconnects.
- Redaction: typing text becomes `"[redacted: N chars]"`; the code of `browser_evaluate` is kept; each string is cut to 2,000 characters and the whole `arguments` object to 8 KiB; one table in `audit/redaction.ts` with a unit test for each tool.
- Deny list in `mcp-proxy/tool-policy.ts`: the tools that run code in the MCP server process instead of the page. A denied call gets a JSON-RPC error and does not go to the pod.
- Registry: close at once on `token.revoked`, on a `session.state` other than `starting` or `running`, and on `rights.changed` when the creator lost `token.create`. Every 60 s, close the MCP streams of tokens that are no longer valid (spec section 6.6).
- Activity: `activeAgentCount` = MCP sessions with activity in the last 60 s; `lastToolCall` = `{ tool, status, durationMs, startedAt }` without arguments; `session.activity` on each change and from a timer when the count goes down.
- SIGTERM: close open MCP streams after 10 s (spec section 14).
- Exact versions: `undici` `8.11.2` and `@modelcontextprotocol/sdk` `1.32.0` (the newest releases on or before 2026-10-03, also in plan 01's table), `@playwright/mcp` `0.0.83` (fixed by the spec).
- Code rules (index section 2): strict TypeScript, ESM, `.js` import extensions, `erasableSyntaxOnly` (no `enum`, no constructor parameter properties), `deps` objects, time only from `Clock`, services throw `HydraError`. Prettier: `printWidth` 100, `singleQuote`, `semi`, `trailingComma: all`. The code blocks of this plan are formatted with Prettier 3.9.9 and pass plan 01's ESLint config (and also typescript-eslint `strictTypeChecked`), with TypeScript 6.0.3 and 7.0.2.
- Commands run from the repository root. One test file: `pnpm --filter @hydra/server exec vitest run <path below packages/server>`.

## Review Focus

1. **An agent cancels a running tool call** (the client closes the POST stream before the result, for example Esc in Claude Code): the record must become `error` with `"stream closed"`, the registry entry must go away, and the pod request must be aborted. Task 11 test `marks a tool call "stream closed" and aborts the pod request when the agent cancels it`.
2. **The pod dies or restarts in the middle of an open MCP stream**: the client stream must end with an error (not hang), the pending call must become `"stream closed"`, and the next request with the old `Mcp-Session-Id` must get the pod's 404 unchanged. Task 11 test `ends the client stream and marks the call "stream closed" when the pod dies during the stream`; Task 12 test `passes the 404 of an unknown Mcp-Session-Id without changes (pod restart)`.
3. **A large tool result in one SSE event** (a full-page screenshot is several MiB of base64): it must pass byte for byte without a buffer limit, and the audit must still record `ok`. Task 11 test `passes a 5 MiB result event byte for byte and records ok`.
4. **An MCP stream that is idle longer than undici's default timeouts** (300 s for headers and body) or longer than a server `connectionTimeout`: it must stay open. Task 11 test `uses no headers timeout and no body timeout for the requests to the pod` (the dispatcher options), and `proxyToPod` clears the socket timeout.
5. **Two agents on one session, and an agent that leaves without `DELETE`**: `activeAgentCount` must be 2 (the dashboard warning of spec section 8.4) and must go down to 0 after 60 s through the timer, with a `session.activity` event. Task 7 test `publishes from the timer when the count goes down`; Task 13 test `counts two agents, and the count goes down 60 s after their last activity`.

## Spec deviations

None.

Interpretations (not deviations), so that reviewers can check them:

1. **Deny list name.** The spec names `browser_run_code` as an example. `@playwright/mcp` 0.0.83 calls this tool `browser_run_code_unsafe` (renamed in 0.0.78; 0.0.60 and 0.0.70 use the old name). The list has both names.
2. **Host check.** Playwright MCP 0.0.83 compares the full `host:port`: with `--host 0.0.0.0 --port 8931` it accepts only `Host: localhost:8931`, which is the value of spec section 8.2. The test server listens on a random port, so the test helper starts it with `--allowed-hosts localhost:8931`. This also proves the rewrite: any other `Host` gets 403.
3. **Request headers as an allowlist.** The proxy sends only `Accept`, `Content-Type`, `Mcp-Session-Id`, `MCP-Protocol-Version`, `Last-Event-ID`, and `Host: localhost:8931`. This removes `Authorization`, `Cookie`, and the hop-by-hop headers as the spec asks, and also `Accept-Encoding` (the audit copy must be plain text), `Origin`, and `X-Forwarded-*`. Pod responses lose their hop-by-hop headers and `Set-Cookie` (the dashboard origin must not get pod cookies).
4. **Bodies that the spec does not fix.** 401 and 429 use the API error format (`unauthenticated`, `rate_limited`) through `HydraError`. 413, 400 (parse error, batch over 100 messages), and 502 (pod not reachable) use a JSON-RPC error body, like the 503 of spec section 8.2. A denied `tools/call` gets the JSON-RPC error code `-32602` (MCP uses it for an unknown tool). A batch with a denied call is rejected as a whole; each request in it gets an error, and each `tools/call` in it gets an `mcp.tool_call` record with `status = error`.
5. **Batch limit.** The proxy rejects a batch of more than 100 messages (400). A 1 MiB batch could hold about 10,000 `tools/call` messages, which would be 10,000 audit records for one request.
6. **Redaction beyond the two named typing tools.** The spec says "Read the current tool list of the pinned Playwright MCP version". In 0.0.83, these values also carry typed text or secrets, so they are redacted too: single characters of `browser_press_key` (named keys such as `Enter` stay), `browser_handle_dialog` `promptText`, the values of `browser_drop` `data`, the `value` of `browser_cookie_set`, `browser_localstorage_set`, `browser_sessionstorage_set`, and `browser_verify_value`. A tool that is not in the table (a WebMCP tool that a page registers, or a tool of a newer version) gets all its strings redacted.
7. **`lastToolCall` expiry.** Spec section 8.5 says "all values expire after 60 s". `lastToolCall` becomes `null` 60 s after the call finished; a pending call stays visible until it finishes or its stream closes.
8. **Activity source.** The tracker counts an MCP session as active for 60 s after its last `mcp.connect` or `mcp.tool_call` event ("from the `mcp.*` events", spec section 8.5). Heartbeat pings and `tools/list` are not activity.

- **Tools.** 72 tools can be exposed over MCP: 25 by default (capabilities `core`, `core-navigation`, `core-input`, `core-tabs`) and 47 with `--caps config,devtools,network,pdf,storage,testing,vision`. 11 more tools are CLI-only (`skillOnly`). `browser_run_code_unsafe` has the capability `core`, so it is on by default; it runs the agent's code with `node:vm` in the MCP process, with `fetch`, `Buffer`, and the Playwright `page`. `browser_evaluate` runs its code in the page. The full list is in Task 3.
- **Host check.** The allowed host is `localhost:<port>` (`0.0.0.0` and `127.0.0.1` are normalized to `localhost`). Another `Host` gets `403` with the body `Access is only allowed at localhost:8931`. `--allowed-hosts` replaces the list.
- **Streamable HTTP of the pod.** A POST with requests answers `200`, `content-type: text/event-stream`, `mcp-session-id`, `cache-control: no-cache`. SSE framing: `event: message\ndata: <one JSON-RPC message>\n\n`, no `id:` lines. A fast response has a `content-length`; a long tool call sends the headers at once and the body later (chunked). A POST with only notifications or responses answers `202` (`text/plain`, empty body). A JSON array (batch) is accepted. `GET` answers `200 text/event-stream` (`cache-control: no-cache, no-transform`) at once; `GET` without `Mcp-Session-Id` answers `400 Invalid request`; `DELETE` answers `200`. An unknown `Mcp-Session-Id` answers `404 Session not found` without a content type, also after a restart of the MCP process. An unknown tool gives a result with `isError: true` (not a JSON-RPC error).
- **Heartbeat.** After the first tool call, and while a GET stream is open, the pod sends a `ping` request every 3 s. Without an answer within 5 s it closes the MCP session.
- **Fastify 5.12.5.** `reply.send(stream)` sends the headers only with the first chunk, so the proxy uses `reply.hijack()` and `flushHeaders()`. A child scope error handler can rethrow to the parent handler. A `'*'` content-type parser with `parseAs: 'buffer'` also gets bodies without a content type; its `bodyLimit` raises `FST_ERR_CTP_BODY_TOO_LARGE` (413) for a `content-length` body and for a chunked body. Headers set with `reply.header()` before an error stay (only `content-type` and `content-length` are removed). With `app.inject`, `reply.raw.setTimeout()` throws and `close` comes with `writableFinished === false`, so the proxy clears the socket timeout only if the socket has `setTimeout`, and checks `writableEnded`.
- **undici 8.11.2.** `request()` accepts a `host` header; `fetch()` ignores it. The global `fetch` of Node.js 24 cannot use an undici 8 `Agent` (`invalid onRequestStart method`). An `Agent` with a `connect` override (`buildConnector`) keeps the URL host as `Host` and connects to `127.0.0.1:<port>`; the tests use it to send `Host: hydra.localhost`.
- **MCP SDK 1.32.0 client.** Options `fetch`, `requestInit`, `reconnectionOptions`. It opens the GET stream after the `202` of `notifications/initialized`. Its dependency tree (96 packages, with undici 8.11.2) has no install scripts.
- **Chromium.** `playwright-mcp install-browser --no-shell chromium` downloads Chrome for Testing 155.0.8059.12 (playwright `chromium-1247`) and FFmpeg 1011. `--headless --remote-debugging-port=0` prints `DevTools listening on ws://127.0.0.1:<port>/devtools/browser/<id>` after about 3 s. `pnpm --filter @hydra/mcp-sidecar exec playwright-mcp …` works in a pnpm workspace, and the helper's `createRequire` chain resolves `@playwright/mcp` and its `playwright-core` through the pnpm store links.

### Task 1: Preconditions and the JSON-RPC parser

**Files:**
- Create: `packages/server/src/mcp-proxy/jsonrpc.ts`
- Test: `packages/server/src/mcp-proxy/jsonrpc.test.ts`

**Interfaces:**
- Consumes: nothing (a pure module).
- Produces:
  - `type JsonRpcId = string | number`
  - `interface JsonRpcErrorObject { code: number; message: string; data?: unknown }`
  - `type JsonRpcMessage = { kind: 'request'; id; method; params } | { kind: 'notification'; method; params } | { kind: 'response'; id: JsonRpcId | null; result: unknown; error: JsonRpcErrorObject | null } | { kind: 'invalid'; method: string | null; params: unknown }`
  - `type ParsedBody = { ok: true; batch: boolean; messages: JsonRpcMessage[] } | { ok: false; reason: 'invalid_utf8' | 'invalid_json' }`
  - `classifyMessage(value: unknown): JsonRpcMessage`, `parseJsonRpcBody(raw: Uint8Array): ParsedBody`, `parseServerPayload(text: string): JsonRpcMessage[] | null`, `idKey(id: JsonRpcId): string`, `toolCallName(message: JsonRpcMessage): string | null`, `toolCallArguments(message: JsonRpcMessage): unknown`, `jsonRpcError(id: JsonRpcId | null, code: number, message: string): Record<string, unknown>`, `jsonRpcErrorBody(id, code, message): string`

`toolCallName` also reads the name of a notification and of an invalid message: the deny check must not depend on a valid `id`.

```ts
// JSON-RPC 2.0 parsing for the MCP proxy (spec section 8.2 step 4).

export type JsonRpcId = string | number;

export interface JsonRpcErrorObject {
  code: number;
  message: string;
  data?: unknown;
}

export type JsonRpcMessage =
  | { kind: 'request'; id: JsonRpcId; method: string; params: unknown }
  | { kind: 'notification'; method: string; params: unknown }
  | { kind: 'response'; id: JsonRpcId | null; result: unknown; error: JsonRpcErrorObject | null }
  | { kind: 'invalid'; method: string | null; params: unknown };

export type ParsedBody =
  | { ok: true; batch: boolean; messages: JsonRpcMessage[] }
  | { ok: false; reason: 'invalid_utf8' | 'invalid_json' };

const utf8 = new TextDecoder('utf-8', { fatal: true });

function isObject(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

function isId(value: unknown): value is JsonRpcId {
  return typeof value === 'string' || (typeof value === 'number' && Number.isInteger(value));
}

function errorObject(value: unknown): JsonRpcErrorObject | null {
  if (!isObject(value)) return null;
  const code = typeof value.code === 'number' ? value.code : 0;
  const message = typeof value.message === 'string' ? value.message : '';
  return value.data === undefined ? { code, message } : { code, message, data: value.data };
}

/** Classifies one decoded JSON value. A value that is not valid JSON-RPC 2.0 is 'invalid'. */
export function classifyMessage(value: unknown): JsonRpcMessage {
  if (!isObject(value)) return { kind: 'invalid', method: null, params: undefined };
  const method = typeof value.method === 'string' ? value.method : null;
  if (value.jsonrpc !== '2.0') return { kind: 'invalid', method, params: value.params };
  if (method !== null) {
    if (!('id' in value)) return { kind: 'notification', method, params: value.params };
    if (isId(value.id)) return { kind: 'request', id: value.id, method, params: value.params };
    return { kind: 'invalid', method, params: value.params };
  }
  if ('result' in value || 'error' in value) {
    const id = isId(value.id) ? value.id : null;
    return { kind: 'response', id, result: value.result, error: errorObject(value.error) };
  }
  return { kind: 'invalid', method: null, params: undefined };
}

/** Parses an MCP request body: one JSON-RPC message or a batch (JSON array). */
export function parseJsonRpcBody(raw: Uint8Array): ParsedBody {
  let text: string;
  try {
    text = utf8.decode(raw);
  } catch {
    return { ok: false, reason: 'invalid_utf8' };
  }
  let value: unknown;
  try {
    value = JSON.parse(text);
  } catch {
    return { ok: false, reason: 'invalid_json' };
  }
  if (Array.isArray(value)) return { ok: true, batch: true, messages: value.map(classifyMessage) };
  return { ok: true, batch: false, messages: [classifyMessage(value)] };
}

/** Parses one server payload (the data of an SSE event, or a JSON response body). Null if it is not JSON. */
export function parseServerPayload(text: string): JsonRpcMessage[] | null {
  let value: unknown;
  try {
    value = JSON.parse(text);
  } catch {
    return null;
  }
  return Array.isArray(value) ? value.map(classifyMessage) : [classifyMessage(value)];
}

/** Map key for an id: 1 and "1" are different ids. */
export function idKey(id: JsonRpcId): string {
  return `${typeof id}:${String(id)}`;
}

/** The tool name of a tools/call message (any kind), or null. */
export function toolCallName(message: JsonRpcMessage): string | null {
  if (message.kind === 'response' || message.method !== 'tools/call') return null;
  const params = message.params;
  return isObject(params) && typeof params.name === 'string' ? params.name : null;
}

/** The arguments of a tools/call message. */
export function toolCallArguments(message: JsonRpcMessage): unknown {
  if (message.kind === 'response') return undefined;
  const params = message.params;
  return isObject(params) ? params.arguments : undefined;
}

export function jsonRpcError(
  id: JsonRpcId | null,
  code: number,
  message: string,
): Record<string, unknown> {
  return { jsonrpc: '2.0', error: { code, message }, id };
}

export function jsonRpcErrorBody(id: JsonRpcId | null, code: number, message: string): string {
  return JSON.stringify(jsonRpcError(id, code, message));
}
```

```ts
// Incremental parser for text/event-stream (WHATWG HTML, "Parsing an event stream").

export interface SseEvent {
  event: string;
  data: string;
  id: string | null;
}

export const DEFAULT_MAX_EVENT_CHARS = 64 * 1024 * 1024;
const NUL = String.fromCharCode(0);

export class SseParser {
  readonly #decoder = new TextDecoder('utf-8');
  readonly #maxEventChars: number;
  #started = false;
  #skipLineFeed = false;
  #partialLine = '';
  #eventType = '';
  #data = '';
  #hasData = false;
  #lastEventId: string | null = null;
  #overflowed = false;

  constructor(options: { maxEventChars?: number } = {}) {
    this.#maxEventChars = options.maxEventChars ?? DEFAULT_MAX_EVENT_CHARS;
  }

  /** True after one event was larger than maxEventChars. The parser then ignores all input. */
  get overflowed(): boolean {
    return this.#overflowed;
  }

  push(chunk: Uint8Array | string): SseEvent[] {
    if (this.#overflowed) return [];
    const text = typeof chunk === 'string' ? chunk : this.#decoder.decode(chunk, { stream: true });
    return this.#feed(text);
  }

  /** Call at the end of the stream. An event without its final blank line is discarded (as the spec says). */
  end(): SseEvent[] {
    if (this.#overflowed) return [];
    const events = this.#feed(this.#decoder.decode());
    this.#partialLine = '';
    this.#data = '';
    this.#hasData = false;
    this.#eventType = '';
    return events;
  }

  #feed(input: string): SseEvent[] {
    const events: SseEvent[] = [];
    let text = input;
    if (!this.#started) {
      if (text.length === 0) return events;
      this.#started = true;
      if (text.charCodeAt(0) === 0xfeff) text = text.slice(1);
    }
    let start = 0;
    if (this.#skipLineFeed && text.length > 0) {
      this.#skipLineFeed = false;
      if (text.charCodeAt(0) === 10) start = 1;
    }
    for (let i = start; i < text.length; i++) {
      const code = text.charCodeAt(i);
      if (code !== 10 && code !== 13) continue;
      const line = this.#partialLine + text.slice(start, i);
      this.#partialLine = '';
      if (code === 13) {
        if (i + 1 < text.length) {
          if (text.charCodeAt(i + 1) === 10) i++;
        } else {
          this.#skipLineFeed = true;
        }
      }
      start = i + 1;
      const event = this.#line(line);
      if (event) events.push(event);
      if (this.#overflowed) return events;
    }
    this.#partialLine += text.slice(start);
    if (this.#partialLine.length + this.#data.length > this.#maxEventChars) this.#overflow();
    return events;
  }

  #line(line: string): SseEvent | null {
    if (line === '') return this.#dispatch();
    if (line.charCodeAt(0) === 58) return null; // ':' comment
    const colon = line.indexOf(':');
    const field = colon === -1 ? line : line.slice(0, colon);
    let value = colon === -1 ? '' : line.slice(colon + 1);
    if (value.charCodeAt(0) === 32) value = value.slice(1);
    switch (field) {
      case 'event':
        this.#eventType = value;
        break;
      case 'data':
        this.#data += value + '\n';
        this.#hasData = true;
        if (this.#data.length > this.#maxEventChars) this.#overflow();
        break;
      case 'id':
        if (!value.includes(NUL)) this.#lastEventId = value;
        break;
      default:
        break; // 'retry' and unknown fields do not matter for the audit copy
    }
    return null;
  }

  #dispatch(): SseEvent | null {
    const hasData = this.#hasData;
    const data = this.#data.endsWith('\n') ? this.#data.slice(0, -1) : this.#data;
    const event = this.#eventType === '' ? 'message' : this.#eventType;
    this.#data = '';
    this.#hasData = false;
    this.#eventType = '';
    if (!hasData) return null;
    return { event, data, id: this.#lastEventId };
  }

  #overflow(): void {
    this.#overflowed = true;
    this.#partialLine = '';
    this.#data = '';
  }
}
```

```ts
// Redaction of tool call arguments for the audit log (spec section 8.6).
//
// REDACTION_RULES has one entry for each tool that @playwright/mcp 0.0.83 can expose over MCP: the 25 default
// tools (capabilities core, core-navigation, core-input, core-tabs) and the opt-in tools of --caps config,
// network, storage, devtools, vision, pdf, and testing (72 tools). The CLI-only ("skillOnly") tools of
// playwright-core are not callable over MCP and are not in the table.
//
// Order: redact, then cut each string to MAX_STRING_CHARS, then cut the whole object to MAX_ARGUMENTS_BYTES.

export const MAX_STRING_CHARS = 2000;
export const MAX_ARGUMENTS_BYTES = 8 * 1024;
const MAX_DEPTH = 20;

export interface RedactionRule {
  /**
   * Paths of values that become "[redacted: N chars]":
   * "text" = top-level key, "fields[].value" = key "value" of each element of the array "fields",
   * "data.*" = each value of the object "data", "**" = every string value (tools without a rule).
   */
  readonly redact: readonly string[];
  /** Redact only values of one character (browser_press_key: "a" is text, "Enter" is a key name). */
  readonly singleCharactersOnly?: boolean;
}

const KEEP: RedactionRule = { redact: [] };

export function ruleFor(tool: string): RedactionRule {
  return Object.hasOwn(REDACTION_RULES, tool)
    ? (REDACTION_RULES[tool] ?? UNKNOWN_TOOL_RULE)
    : UNKNOWN_TOOL_RULE;
}

function isPlainObject(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

function mapObject(
  value: Record<string, unknown>,
  fn: (child: unknown, key: string) => unknown,
): Record<string, unknown> {
  return Object.fromEntries(Object.entries(value).map(([key, child]) => [key, fn(child, key)]));
}

function redactValue(value: unknown, singleCharactersOnly: boolean): unknown {
  if (value === null || value === undefined) return value;
  if (typeof value === 'string') {
    const chars = Array.from(value).length;
    if (singleCharactersOnly && chars !== 1) return value;
    return `[redacted: ${String(chars)} chars]`;
  }
  return '[redacted]';
}

function redactAllStrings(value: unknown, depth: number): unknown {
  if (typeof value === 'string') return redactValue(value, false);
  if (depth >= MAX_DEPTH) return '[redacted]';
  if (Array.isArray(value)) return value.map((child) => redactAllStrings(child, depth + 1));
  if (isPlainObject(value)) return mapObject(value, (child) => redactAllStrings(child, depth + 1));
  return value;
}

function redactPath(
  value: unknown,
  segments: readonly string[],
  singleCharactersOnly: boolean,
): unknown {
  const [segment, ...rest] = segments;
  if (segment === undefined) return redactValue(value, singleCharactersOnly);
  if (segment === '[]') {
    return Array.isArray(value)
      ? value.map((child) => redactPath(child, rest, singleCharactersOnly))
      : value;
  }
  if (segment === '*') {
    return isPlainObject(value)
      ? mapObject(value, (child) => redactPath(child, rest, singleCharactersOnly))
      : value;
  }
  if (!isPlainObject(value) || !Object.hasOwn(value, segment)) return value;
  return mapObject(value, (child, key) =>
    key === segment ? redactPath(child, rest, singleCharactersOnly) : child,
  );
}

function pathSegments(path: string): string[] {
  return path
    .split('.')
    .flatMap((part) => (part.endsWith('[]') ? [part.slice(0, -2), '[]'] : [part]));
}

/** Cuts a string to at most maxChars characters. The end shows the original length. */
export function truncateString(value: string, maxChars: number = MAX_STRING_CHARS): string {
  if (value.length <= maxChars) return value;
  const suffix = `… [cut, ${String(value.length)} chars]`;
  let head = value.slice(0, Math.max(0, maxChars - suffix.length));
  const last = head.charCodeAt(head.length - 1);
  if (last >= 0xd800 && last <= 0xdbff) head = head.slice(0, -1); // do not split a surrogate pair
  return head + suffix;
}

function truncateStrings(value: unknown, depth: number): unknown {
  if (typeof value === 'string') return truncateString(value);
  if (depth >= MAX_DEPTH) return '[too deep]';
  if (Array.isArray(value)) return value.map((child) => truncateStrings(child, depth + 1));
  if (isPlainObject(value)) return mapObject(value, (child) => truncateStrings(child, depth + 1));
  return value;
}

function byteLength(value: unknown): number {
  return Buffer.byteLength(JSON.stringify(value), 'utf8');
}

function limitSize(value: Record<string, unknown>): Record<string, unknown> {
  if (byteLength(value) <= MAX_ARGUMENTS_BYTES) return value;
  const json = JSON.stringify(value);
  const marker = (preview: string): Record<string, unknown> => ({
    $truncated: true,
    $json: preview,
  });
  let low = 0;
  let high = Math.min(json.length, MAX_ARGUMENTS_BYTES);
  while (low < high) {
    const mid = Math.ceil((low + high) / 2);
    if (byteLength(marker(json.slice(0, mid))) <= MAX_ARGUMENTS_BYTES) low = mid;
    else high = mid - 1;
  }
  return marker(json.slice(0, low));
}

/** Returns the arguments of a tool call in the form that the audit log stores (spec section 8.6). */
export function redactArguments(tool: string, args: unknown): Record<string, unknown> {
  if (args === undefined || args === null) return {};
  if (!isPlainObject(args)) return { $invalid: Array.isArray(args) ? 'array' : typeof args };
  const rule = ruleFor(tool);
  let redacted: unknown = args;
  if (rule.redact.includes('**')) {
    redacted = redactAllStrings(args, 0);
  } else {
    for (const path of rule.redact)
      redacted = redactPath(redacted, pathSegments(path), rule.singleCharactersOnly === true);
  }
  return limitSize(truncateStrings(redacted, 0) as Record<string, unknown>);
}
```

```ts
// Header rules of the MCP proxy (spec section 8.2 step 5).
import type { IncomingHttpHeaders } from 'node:http';

/** Playwright MCP accepts only this Host (its default host check: "localhost:<port>"; spec section 7.4). */
export const UPSTREAM_HOST = 'localhost:8931';

/**
 * Request headers that go to the pod, without changes. All other client headers stay at the gateway:
 * Authorization, Cookie, hop-by-hop headers, and also Accept-Encoding (the audit copy needs plain bytes),
 * Origin, and X-Forwarded-*.
 */
export const FORWARDED_REQUEST_HEADERS = [
  'accept',
  'content-type',
  'mcp-session-id',
  'mcp-protocol-version',
  'last-event-id',
] as const;

const HOP_BY_HOP = new Set([
  'connection',
  'keep-alive',
  'proxy-connection',
  'transfer-encoding',
  'te',
  'trailer',
  'upgrade',
  'proxy-authenticate',
  'proxy-authorization',
]);

/** Spec section 6.8, "Both origins". The proxy writes the raw response, so it sets them itself. */
export const SECURITY_HEADERS: Readonly<Record<string, string>> = {
  'strict-transport-security': 'max-age=31536000',
  'x-content-type-options': 'nosniff',
  'referrer-policy': 'no-referrer',
};

export function upstreamRequestHeaders(incoming: IncomingHttpHeaders): Record<string, string> {
  const headers: Record<string, string> = { host: UPSTREAM_HOST };
  for (const name of FORWARDED_REQUEST_HEADERS) {
    const value = incoming[name];
    if (typeof value === 'string') headers[name] = value;
  }
  return headers;
}

function connectionTokens(value: string | string[] | undefined): Set<string> {
  const joined = Array.isArray(value) ? value.join(',') : (value ?? '');
  return new Set(
    joined
      .split(',')
      .map((token) => token.trim().toLowerCase())
      .filter((token) => token !== ''),
  );
}

/** Response headers that go to the client: all pod headers except hop-by-hop headers and Set-Cookie. */
export function clientResponseHeaders(
  upstream: Record<string, string | string[] | undefined>,
): Record<string, string | string[]> {
  const listed = connectionTokens(upstream.connection);
  const headers: Record<string, string | string[]> = {};
  for (const [rawName, value] of Object.entries(upstream)) {
    const name = rawName.toLowerCase();
    if (value === undefined || HOP_BY_HOP.has(name) || listed.has(name) || name === 'set-cookie')
      continue;
    headers[name] = value;
  }
  return headers;
}
```

```ts
// Registry of open MCP requests and MCP streams (spec section 8.3).

export interface StreamOwner {
  tokenId: string;
  userId: string;
  sessionId: string;
}

export interface StreamEntry extends StreamOwner {
  abort(reason: string): void;
}

export class StreamRegistry {
  readonly #entries = new Set<StreamEntry>();

  /** Adds an open request or stream. The returned function removes it (call it when the response ends). */
  register(entry: StreamEntry): () => void {
    this.#entries.add(entry);
    return () => {
      this.#entries.delete(entry);
    };
  }

  /** Removes and aborts each entry that matches. Returns the number of aborted entries. */
  closeWhere(predicate: (entry: StreamOwner) => boolean, reason: string): number {
    const matched = [...this.#entries].filter((entry) =>
      predicate({ tokenId: entry.tokenId, userId: entry.userId, sessionId: entry.sessionId }),
    );
    for (const entry of matched) {
      this.#entries.delete(entry);
      try {
        entry.abort(reason);
      } catch {
        // An abort must not stop the other closes.
      }
    }
    return matched.length;
  }

  size(): number {
    return this.#entries.size;
  }
}
```

```ts
// Agent activity summary for each session, from the mcp.* audit events (spec section 8.5).
import type { AgentActivity, AuditEvent } from '@hydra/shared';
import type { Clock } from '../lib/clock.js';
import type { EventBus } from '../events/index.js';
import type { ActivityProvider } from '../sessions/index.js';

/** An MCP session counts as an active agent for 60 s after its last mcp.* event. */
export const ACTIVITY_WINDOW_MS = 60_000;
/** How often the timer checks for expired values. */
export const SWEEP_INTERVAL_MS = 1_000;

type ToolCallStatus = 'pending' | 'ok' | 'error';

interface LastToolCall {
  auditId: number;
  tool: string;
  status: ToolCallStatus;
  durationMs: number | null;
  startedAt: number;
  changedAt: number;
}

interface SessionActivity {
  agents: Map<string, number>; // mcpSessionId -> time of the last mcp.* event
  last: LastToolCall | null;
  published: string; // JSON of the last summary on the bus
}

const EMPTY: AgentActivity = { activeAgentCount: 0, lastToolCall: null };
const EMPTY_JSON = JSON.stringify(EMPTY);

function isStatus(value: unknown): value is ToolCallStatus {
  return value === 'pending' || value === 'ok' || value === 'error';
}

export class ActivityTracker implements ActivityProvider {
  readonly #bus: EventBus;
  readonly #clock: Clock;
  readonly #sessions = new Map<string, SessionActivity>();
  #unsubscribe: (() => void) | null = null;
  #timer: NodeJS.Timeout | null = null;

  constructor(deps: { bus: EventBus; clock: Clock }) {
    this.#bus = deps.bus;
    this.#clock = deps.clock;
  }

  /** Subscribes to the audit events and starts the timer for the 60 s decay. */
  start(): void {
    if (this.#unsubscribe !== null) return;
    this.#unsubscribe = this.#bus.subscribe('audit', (event) => {
      this.#record(event.event);
    });
    this.#timer = setInterval(() => {
      this.sweep();
    }, SWEEP_INTERVAL_MS);
    this.#timer.unref();
  }

  stop(): void {
    this.#unsubscribe?.();
    this.#unsubscribe = null;
    if (this.#timer !== null) clearInterval(this.#timer);
    this.#timer = null;
  }

  get(sessionId: string): AgentActivity {
    const state = this.#sessions.get(sessionId);
    return state ? this.#summary(state, this.#clock.now()) : { ...EMPTY };
  }

  /** Removes expired values and publishes session.activity for each summary that changed (the timer calls it). */
  sweep(): void {
    const now = this.#clock.now();
    for (const [sessionId, state] of this.#sessions) {
      for (const [mcpSessionId, at] of state.agents) {
        if (now - at >= ACTIVITY_WINDOW_MS) state.agents.delete(mcpSessionId);
      }
      if (state.last !== null && !this.#lastIsVisible(state.last, now)) state.last = null;
      this.#publishIfChanged(sessionId, state, now);
      if (state.agents.size === 0 && state.last === null) this.#sessions.delete(sessionId);
    }
  }

  #record(event: AuditEvent): void {
    if (event.kind !== 'mcp.connect' && event.kind !== 'mcp.tool_call') return;
    if (event.sessionId === null) return;
    const now = this.#clock.now();
    let state = this.#sessions.get(event.sessionId);
    if (state === undefined) {
      state = { agents: new Map(), last: null, published: EMPTY_JSON };
      this.#sessions.set(event.sessionId, state);
    }
    const mcpSessionId = event.data.mcpSessionId;
    if (typeof mcpSessionId === 'string' && mcpSessionId !== '')
      state.agents.set(mcpSessionId, now);
    const tool = event.data.tool;
    if (
      event.kind === 'mcp.tool_call' &&
      typeof tool === 'string' &&
      (state.last === null || event.id >= state.last.auditId)
    ) {
      const durationMs = event.data.durationMs;
      state.last = {
        auditId: event.id,
        tool,
        status: isStatus(event.status) ? event.status : 'pending',
        durationMs: typeof durationMs === 'number' ? durationMs : null,
        startedAt: event.ts,
        changedAt: now,
      };
    }
    this.#publishIfChanged(event.sessionId, state, now);
  }

  #lastIsVisible(last: LastToolCall, now: number): boolean {
    return last.status === 'pending' || now - last.changedAt < ACTIVITY_WINDOW_MS;
  }

  #summary(state: SessionActivity, now: number): AgentActivity {
    let activeAgentCount = 0;
    for (const at of state.agents.values()) if (now - at < ACTIVITY_WINDOW_MS) activeAgentCount++;
    const last = state.last;
    const lastToolCall =
      last !== null && this.#lastIsVisible(last, now)
        ? {
            tool: last.tool,
            status: last.status,
            durationMs: last.durationMs,
            startedAt: last.startedAt,
          }
        : null;
    return { activeAgentCount, lastToolCall };
  }

  #publishIfChanged(sessionId: string, state: SessionActivity, now: number): void {
    const summary = this.#summary(state, now);
    const json = JSON.stringify(summary);
    if (json === state.published) return;
    state.published = json;
    this.#bus.publish({ type: 'session.activity', sessionId, agentActivity: summary });
  }
}
```

Flow: `begin()` writes a pending `mcp.tool_call` for each `tools/call` request (it throws if the audit write fails; then nothing goes to the pod) and remembers `initialize` requests. `response()` picks the mode: SSE (`text/event-stream`), JSON (`application/json`), or other. `data()` reads the copy: each JSON-RPC response with a known id finishes its call (`ok`, or `error` with the JSON-RPC error message or the text of an `isError` result, cut to 500 characters); a successful `initialize` result writes `mcp.connect` with the `mcp-session-id` response header. `end()` finishes the rest: `HTTP <status>: <body>` for a status of 400 or more, else `"stream closed"`. `close()` gives `"stream closed"` to all pending calls. Audit update errors are logged, not thrown, because they happen while the response streams.

```ts
// Audit records of one proxied MCP request (spec section 8.6).
import { redactArguments, truncateString, type AuditWriter } from '../audit/index.js';
import type { Clock } from '../lib/clock.js';
import type { Logger } from '../lib/logger.js';
import type { AgentPrincipal } from '../tokens/index.js';
import {
  idKey,
  parseServerPayload,
  toolCallArguments,
  toolCallName,
  type JsonRpcErrorObject,
  type JsonRpcMessage,
} from './jsonrpc.js';
import { SseParser } from './sse.js';

export const MAX_ERROR_CHARS = 500;
export const STREAM_CLOSED = 'stream closed';
const MAX_JSON_BODY_CHARS = 64 * 1024 * 1024;
const MAX_ERROR_BODY_CHARS = 2_000;
const MAX_CLIENT_INFO_CHARS = 200;

export interface ExchangeDeps {
  audit: Pick<AuditWriter, 'write' | 'update'>;
  clock: Clock;
  logger: Logger;
}

export interface ExchangeContext {
  principal: AgentPrincipal;
  /** The Mcp-Session-Id header of the request (null for initialize). */
  mcpSessionId: string | null;
  ip: string;
}

interface PendingCall {
  auditId: number;
  startedAt: number;
  data: Record<string, unknown>;
}

interface ClientInfo {
  name: string | null;
  version: string | null;
}

function isObject(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value);
}

function clientInfoOf(params: unknown): ClientInfo {
  const info = isObject(params) && isObject(params.clientInfo) ? params.clientInfo : {};
  const text = (value: unknown): string | null =>
    typeof value === 'string' ? truncateString(value, MAX_CLIENT_INFO_CHARS) : null;
  return { name: text(info.name), version: text(info.version) };
}

function rpcErrorText(error: JsonRpcErrorObject): string {
  return truncateString(
    error.message !== '' ? error.message : `JSON-RPC error ${String(error.code)}`,
    MAX_ERROR_CHARS,
  );
}

/** The error text of a tool result with isError = true, else null. */
function toolErrorText(result: unknown): string | null {
  if (!isObject(result) || result.isError !== true) return null;
  const content = Array.isArray(result.content) ? result.content : [];
  const text = content
    .filter(
      (part): part is { type: 'text'; text: string } =>
        isObject(part) && part.type === 'text' && typeof part.text === 'string',
    )
    .map((part) => part.text)
    .join('\n')
    .trim();
  return truncateString(text !== '' ? text : 'Tool returned an error', MAX_ERROR_CHARS);
}

export class McpExchange {
  readonly #deps: ExchangeDeps;
  readonly #context: ExchangeContext;
  readonly #calls = new Map<string, PendingCall>();
  readonly #initializes = new Map<string, ClientInfo>();
  readonly #decoder = new TextDecoder('utf-8');
  #mode: 'sse' | 'json' | 'other' = 'other';
  #status = 0;
  #responseSessionId: string | null = null;
  #sse: SseParser | null = null;
  #json = '';
  #jsonTooLarge = false;
  #otherBody = '';
  #done = false;

  constructor(deps: ExchangeDeps, context: ExchangeContext) {
    this.#deps = deps;
    this.#context = context;
  }

  /** Number of tool calls without a final status. */
  get pendingCalls(): number {
    return this.#calls.size;
  }

  /**
   * Writes the pending mcp.tool_call record of each tools/call request, and remembers initialize requests.
   * Call it before the request goes to the pod. It throws if the audit write fails; then the request must not go out.
   */
  begin(messages: readonly JsonRpcMessage[]): void {
    for (const message of messages) {
      if (message.kind !== 'request') continue;
      if (message.method === 'initialize') {
        this.#initializes.set(idKey(message.id), clientInfoOf(message.params));
        continue;
      }
      const tool = toolCallName(message);
      if (tool === null) continue;
      const data: Record<string, unknown> = {
        mcpSessionId: this.#context.mcpSessionId,
        rpcId: message.id,
        tool,
        arguments: redactArguments(tool, toolCallArguments(message)),
        durationMs: null,
        error: null,
      };
      const event = this.#deps.audit.write({
        kind: 'mcp.tool_call',
        actorType: 'token',
        actorId: this.#context.principal.tokenId,
        sessionId: this.#context.principal.sessionId,
        status: 'pending',
        data,
      });
      this.#calls.set(idKey(message.id), {
        auditId: event.id,
        startedAt: this.#deps.clock.now(),
        data,
      });
    }
  }

  /** The status line and the headers of the pod response. */
  response(status: number, headers: Record<string, string | string[] | undefined>): void {
    this.#status = status;
    const sessionHeader = headers['mcp-session-id'];
    this.#responseSessionId = typeof sessionHeader === 'string' ? sessionHeader : null;
    const contentTypeHeader = headers['content-type'];
    const contentType = (
      typeof contentTypeHeader === 'string' ? contentTypeHeader : ''
    ).toLowerCase();
    const success = status >= 200 && status < 300;
    if (success && contentType.startsWith('text/event-stream')) {
      this.#mode = 'sse';
      this.#sse = new SseParser();
    } else if (success && contentType.startsWith('application/json')) {
      this.#mode = 'json';
    } else {
      this.#mode = 'other';
    }
  }

  /** A chunk of the response body. The proxy calls it before the chunk goes to the client. */
  data(chunk: Uint8Array): void {
    if (this.#done) return;
    if (this.#sse !== null) {
      for (const event of this.#sse.push(chunk)) this.#serverPayload(event.data);
      return;
    }
    const text = this.#decoder.decode(chunk, { stream: true });
    if (this.#mode === 'json') {
      if (this.#jsonTooLarge) return;
      this.#json += text;
      if (this.#json.length > MAX_JSON_BODY_CHARS) {
        this.#jsonTooLarge = true;
        this.#json = '';
      }
      return;
    }
    if (this.#otherBody.length < MAX_ERROR_BODY_CHARS) this.#otherBody += text;
  }

  /** The response body ended normally. */
  end(): void {
    if (this.#done) return;
    if (this.#sse !== null) {
      for (const event of this.#sse.end()) this.#serverPayload(event.data);
    } else if (this.#mode === 'json') {
      this.#json += this.#decoder.decode();
      if (!this.#jsonTooLarge) this.#serverPayload(this.#json);
    } else {
      this.#otherBody += this.#decoder.decode();
    }
    const body = this.#otherBody.trim();
    let reason = STREAM_CLOSED;
    if (this.#status >= 400)
      reason =
        body === '' ? `HTTP ${String(this.#status)}` : `HTTP ${String(this.#status)}: ${body}`;
    else if (this.#sse?.overflowed === true || this.#jsonTooLarge)
      reason = 'response too large to inspect';
    this.#finishAll(reason);
  }

  /** The stream closed before its end (client, pod, or registry). Pending calls get the given error. */
  close(reason: string = STREAM_CLOSED): void {
    if (this.#done) return;
    this.#finishAll(reason);
  }

  #serverPayload(text: string): void {
    const messages = parseServerPayload(text);
    if (messages === null) return;
    for (const message of messages) {
      if (message.kind === 'response' && message.id !== null)
        this.#serverResponse(idKey(message.id), message);
    }
  }

  #serverResponse(key: string, message: Extract<JsonRpcMessage, { kind: 'response' }>): void {
    const call = this.#calls.get(key);
    if (call !== undefined) {
      this.#calls.delete(key);
      const error =
        message.error !== null ? rpcErrorText(message.error) : toolErrorText(message.result);
      this.#finish(call, error === null ? 'ok' : 'error', error);
    }
    const clientInfo = this.#initializes.get(key);
    if (clientInfo !== undefined) {
      this.#initializes.delete(key);
      if (message.error === null && message.result !== undefined) this.#connect(clientInfo);
    }
  }

  #connect(clientInfo: ClientInfo): void {
    try {
      this.#deps.audit.write({
        kind: 'mcp.connect',
        actorType: 'token',
        actorId: this.#context.principal.tokenId,
        sessionId: this.#context.principal.sessionId,
        data: { mcpSessionId: this.#responseSessionId, clientInfo, ip: this.#context.ip },
      });
    } catch (err) {
      this.#deps.logger.error({ err }, 'mcp.connect audit write failed');
    }
  }

  #finish(call: PendingCall, status: 'ok' | 'error', error: string | null): void {
    const durationMs = Math.max(0, this.#deps.clock.now() - call.startedAt);
    try {
      this.#deps.audit.update(call.auditId, { status, data: { ...call.data, durationMs, error } });
    } catch (err) {
      this.#deps.logger.error({ err, auditId: call.auditId }, 'mcp.tool_call audit update failed');
    }
  }

  #finishAll(reason: string): void {
    this.#done = true;
    const error = truncateString(reason, MAX_ERROR_CHARS);
    for (const call of this.#calls.values()) this.#finish(call, 'error', error);
    this.#calls.clear();
    this.#initializes.clear();
  }
}
```

```ts
// When the gateway closes MCP streams (spec section 8.3).
import type { AppDeps } from '../app.js';
import type { EventBus } from '../events/index.js';
import type { Logger } from '../lib/logger.js';
import type { TokensService } from '../tokens/index.js';
import type { StreamRegistry } from './stream-registry.js';

export interface CloserDeps {
  bus: EventBus;
  tokens: Pick<TokensService, 'isValid'>;
  mcpStreams: StreamRegistry;
}

/** Subscribes to the bus events that close MCP streams. Returns the unsubscribe function. */
export function subscribeStreamClosers(deps: CloserDeps): () => void {
  const unsubscribes = [
    deps.bus.subscribe('token.revoked', (event) => {
      deps.mcpStreams.closeWhere((entry) => entry.tokenId === event.tokenId, 'token revoked');
    }),
    deps.bus.subscribe('session.state', (event) => {
      if (event.state === 'starting' || event.state === 'running') return;
      deps.mcpStreams.closeWhere(
        (entry) => entry.sessionId === event.sessionId,
        `session ${event.state}`,
      );
    }),
    deps.bus.subscribe('rights.changed', (event) => {
      deps.mcpStreams.closeWhere(
        (entry) => entry.userId === event.userId && !deps.tokens.isValid(entry.tokenId),
        'rights changed',
      );
    }),
  ];
  return () => {
    for (const unsubscribe of unsubscribes) unsubscribe();
  };
}

/** One pass of the connection check: closes the MCP streams of tokens that are not valid now. */
export function runMcpConnectionCheck(deps: Pick<CloserDeps, 'tokens' | 'mcpStreams'>): number {
  const valid = new Map<string, boolean>();
  return deps.mcpStreams.closeWhere((entry) => {
    let ok = valid.get(entry.tokenId);
    if (ok === undefined) {
      ok = deps.tokens.isValid(entry.tokenId);
      valid.set(entry.tokenId, ok);
    }
    return !ok;
  }, 'token no longer valid');
}

export const MCP_CONNECTION_CHECK_MS = 60_000;

/** Runs the connection check every 60 s. Returns the stop function. */
export function startMcpConnectionCheck(deps: AppDeps): () => void {
  const timer = setInterval(() => {
    try {
      const closed = runMcpConnectionCheck(deps);
      if (closed > 0) deps.logger.info({ closed }, 'mcp connection check closed streams');
    } catch (err) {
      deps.logger.error({ err }, 'mcp connection check failed');
    }
  }, MCP_CONNECTION_CHECK_MS);
  timer.unref();
  return () => {
    clearInterval(timer);
  };
}

/** Spec section 14: on SIGTERM, the open MCP streams get 10 s before the gateway closes them. */
export const MCP_SHUTDOWN_GRACE_MS = 10_000;

/** Closes all MCP streams after the grace time. Returns a function that cancels the timer. */
export function scheduleMcpStreamShutdown(
  deps: { mcpStreams: StreamRegistry; logger: Logger },
  graceMs: number = MCP_SHUTDOWN_GRACE_MS,
): () => void {
  const timer = setTimeout(() => {
    const closed = deps.mcpStreams.closeWhere(() => true, 'gateway shutting down');
```

How the route works:
- `registerMcpRoutes` creates the rate limiter (20 per 1 s, key = token id), one undici `Agent` with `headersTimeout: 0, bodyTimeout: 0`, and the bus closers (Task 10); the scope's `onClose` hook removes the subscriptions and destroys the agent.
- It registers its own encapsulated scope with a `'*'` raw-body parser (`parseAs: 'buffer'`, `bodyLimit` 1 MiB), so the JSON parser of the dashboard API does not change and the proxy sends the exact bytes. The scope's error handler answers `FST_ERR_CTP_BODY_TOO_LARGE` with 413 and rethrows everything else to the parent handler.
- The route has the host constraint `config.publicUrl.host` (also if plan 03's public scope adds it). Its `onRequest` hook runs before the body is read: principal (401), `isSessionRunning` (503), rate limit (429). There is no CSRF hook on this route (index section 5.9).
- The handler parses a POST body (400 for a parse error or more than 100 messages), answers a body with a denied `tools/call` (Task 4) without the pod, writes the pending records (`McpExchange.begin`), and then calls `proxyToPod`.
- `proxyToPod` hijacks the reply, clears the socket timeout, registers the request in the `StreamRegistry` (`abort` = abort the undici request and destroy the client socket), sends the request with `upstreamRequestHeaders`, writes the status and `SECURITY_HEADERS` + `clientResponseHeaders`, flushes the headers at once, and pipes the body through a `Transform` that calls `exchange.data()` before it passes each chunk (and `exchange.end()` in `flush`, before the end goes to the client). A client close or an upstream error ends in `exchange.close("stream closed")`. A pod that does not answer gives 502.

```ts
/** Calls check until it does not throw (every 50 ms, at most timeoutMs). */
export async function eventually(check: () => void, timeoutMs = 10_000): Promise<void> {
  const end = Date.now() + timeoutMs;
  for (;;) {
    try {
      check();
      return;
    } catch (err) {
      if (Date.now() > end) throw err;
    }
    await new Promise((resolve) => setTimeout(resolve, 50));
  }
}

/** Reads an SSE response body until an event matches. */
export function readSseUntil(
  body: Dispatcher.ResponseData['body'],
  match: (event: SseEvent) => boolean,
  timeoutMs = 10_000,
): Promise<SseEvent> {
  const parser = new SseParser();
  return new Promise((resolve, reject) => {
    const cleanup = (): void => {
      clearTimeout(timer);
      body.off('data', onData);
      body.off('end', onEnd);
      body.off('error', onEnd);
    };
    const onData = (chunk: Buffer): void => {
      for (const event of parser.push(chunk)) {
        if (match(event)) {
          cleanup();
          resolve(event);
          return;
        }
      }
    };
    const onEnd = (): void => {
      cleanup();
      reject(new Error('the SSE stream ended before the event'));
    };
    const timer = setTimeout(() => {
      cleanup();
      reject(new Error(`no matching SSE event in ${String(timeoutMs)} ms`));
    }, timeoutMs);
    body.on('data', onData);
    body.on('end', onEnd);
    body.on('error', onEnd);
  });
}
```

```ts
// POST, GET, DELETE /s/:sid/mcp (spec sections 8.1 and 8.2).
import type { Socket } from 'node:net';
import { Transform } from 'node:stream';
import { pipeline } from 'node:stream/promises';
import type { FastifyError, FastifyInstance, FastifyReply, FastifyRequest } from 'fastify';
import { Agent, request as undiciRequest, type Dispatcher } from 'undici';
import { MESSAGES } from '@hydra/shared';
import type { AppDeps } from '../app.js';
import { redactArguments } from '../audit/index.js';
import { RateLimiter } from '../auth/index.js';
import { HydraError } from '../lib/errors.js';
import type { AgentPrincipal } from '../tokens/index.js';
import { subscribeStreamClosers } from './closers.js';
import { McpExchange, STREAM_CLOSED } from './exchange.js';
import { SECURITY_HEADERS, clientResponseHeaders, upstreamRequestHeaders } from './headers.js';
import {
  jsonRpcError,
  jsonRpcErrorBody,
  parseJsonRpcBody,
  toolCallArguments,
  toolCallName,
  type JsonRpcMessage,
} from './jsonrpc.js';
import { isSessionRunning } from './session-state.js';
import {
  BATCH_REJECTED_MESSAGE,
  DENIED_TOOL_ERROR_CODE,
  deniedToolMessage,
  isToolDenied,
} from './tool-policy.js';

export const MCP_PATH = '/s/:sid/mcp';
export const MCP_POD_PORT = 8931;
export const MAX_BODY_BYTES = 1024 * 1024;
export const MAX_BATCH_MESSAGES = 100;
export const RATE_LIMIT_PER_SECOND = 20;
export const RATE_LIMIT_WINDOW_MS = 1_000;
/** No timeout while the pod sends the headers or the body of an MCP stream (spec section 8.2 step 6). */
export const POD_DISPATCHER_OPTIONS = { headersTimeout: 0, bodyTimeout: 0 } as const;

/** Spec section 8.2 step 2, byte for byte. */
export const SESSION_NOT_RUNNING_BODY = jsonRpcErrorBody(null, -32000, MESSAGES.sessionNotRunning);
export const BODY_TOO_LARGE_BODY = jsonRpcErrorBody(
  null,
  -32600,
  'Request body is larger than 1 MiB.',
);
export const PARSE_ERROR_BODY = jsonRpcErrorBody(null, -32700, 'Parse error');
export const BATCH_TOO_LARGE_BODY = jsonRpcErrorBody(
  null,
  -32600,
  `A batch can contain at most ${String(MAX_BATCH_MESSAGES)} messages.`,
);
export const POD_UNREACHABLE_BODY = jsonRpcErrorBody(
  null,
  -32000,
  'The MCP server of the session is not reachable.',
);
const INVALID_TOKEN_MESSAGE = 'Missing or invalid agent token.';

interface McpRoute {
  Params: { sid: string };
}

type ProxyDeps = Pick<AppDeps, 'audit' | 'clock' | 'logger' | 'mcpStreams' | 'podEndpoints'>;

function mcpSessionIdOf(request: FastifyRequest): string | null {
  const value = request.headers['mcp-session-id'];
  return typeof value === 'string' ? value : null;
}

function deniedTool(message: JsonRpcMessage): string | null {
  const tool = toolCallName(message);
  return tool !== null && isToolDenied(tool) ? tool : null;
}

/** Answers a body with a denied tools/call (spec section 8.7). Nothing goes to the pod. */
function rejectDeniedCalls(
  deps: Pick<AppDeps, 'audit'>,
  principal: AgentPrincipal,
  request: FastifyRequest,
  reply: FastifyReply,
  messages: readonly JsonRpcMessage[],
  batch: boolean,
): FastifyReply {
  const responses: Record<string, unknown>[] = [];
  for (const message of messages) {
    if (message.kind !== 'request') continue;
    const denied = deniedTool(message);
    const error = denied !== null ? deniedToolMessage(denied) : BATCH_REJECTED_MESSAGE;
    responses.push(jsonRpcError(message.id, DENIED_TOOL_ERROR_CODE, error));
    const tool = toolCallName(message);
    if (tool === null) continue;
    deps.audit.write({
      kind: 'mcp.tool_call',
      actorType: 'token',
      actorId: principal.tokenId,
      sessionId: principal.sessionId,
      status: 'error',
      data: {
        mcpSessionId: mcpSessionIdOf(request),
        rpcId: message.id,
        tool,
        arguments: redactArguments(tool, toolCallArguments(message)),
        durationMs: 0,
        error,
      },
    });
  }
  if (responses.length === 0) return reply.code(202).send();
  return reply
    .code(200)
    .type('application/json')
    .send(JSON.stringify(batch ? responses : responses[0]));
}

/** Sends the request to the pod and streams the response to the client (spec section 8.2 steps 5 to 7). */
async function proxyToPod(
  deps: ProxyDeps,
  dispatcher: Dispatcher,
  principal: AgentPrincipal,
  request: FastifyRequest,
  reply: FastifyReply,
  body: Buffer | undefined,
  exchange: McpExchange,
): Promise<void> {
  reply.hijack();
  const res = reply.raw;
  // No idle timeout on an open MCP stream, also if the server has a connectionTimeout.
  const socket = request.raw.socket as Socket | undefined;
  if (typeof socket?.setTimeout === 'function') socket.setTimeout(0);
  const controller = new AbortController();
  let registered = true;
  const unregister = deps.mcpStreams.register({
    tokenId: principal.tokenId,
    userId: principal.userId,
    sessionId: principal.sessionId,
    abort: (reason) => {
      request.log.info({ reason, sessionId: principal.sessionId }, 'gateway closed an MCP stream');
      exchange.close(STREAM_CLOSED);
      controller.abort(new Error(reason));
      res.destroy();
    },
  });
  const finish = (): void => {
    if (!registered) return;
    registered = false;
    unregister();
  };
  res.once('close', () => {
    finish();
    if (!res.writableEnded) {
      exchange.close(STREAM_CLOSED);
      controller.abort(new Error('client closed the connection'));
    }
  });

  let upstream: Dispatcher.ResponseData;
  try {
    const endpoint = await deps.podEndpoints.endpoint(principal.sessionId, MCP_POD_PORT);
    upstream = await undiciRequest(new URL('/mcp', endpoint), {
      method: request.method,
      headers: upstreamRequestHeaders(request.headers),
      body,
      signal: controller.signal,
      dispatcher,
    });
  } catch (err) {
    if (controller.signal.aborted) return;
    request.log.warn({ err, sessionId: principal.sessionId }, 'MCP request to the pod failed');
    exchange.close('MCP server not reachable');
    if (!res.headersSent && !res.destroyed) {
      res.writeHead(502, { ...SECURITY_HEADERS, 'content-type': 'application/json' });
      res.end(POD_UNREACHABLE_BODY);
    }
    finish();
    return;
  }

  exchange.response(upstream.statusCode, upstream.headers);
  res.writeHead(upstream.statusCode, {
    ...SECURITY_HEADERS,
    ...clientResponseHeaders(upstream.headers),
  });
  res.flushHeaders();
  // The audit reads a copy: each chunk is inspected before it goes to the client, and flush() runs
  // before the end of the body goes to the client.
  const tap = new Transform({
    transform(chunk: Buffer, _encoding, callback) {
      exchange.data(chunk);
      callback(null, chunk);
    },
    flush(callback) {
      exchange.end();
      callback();
    },
  });
  try {
    await pipeline(upstream.body, tap, res);
  } catch {
    exchange.close(STREAM_CLOSED);
  } finally {
    finish();
  }
}

export function registerMcpRoutes(scope: FastifyInstance, deps: AppDeps): void {
  const limiter = new RateLimiter({
    limit: RATE_LIMIT_PER_SECOND,
    windowMs: RATE_LIMIT_WINDOW_MS,
    clock: deps.clock,
  });
  const dispatcher = new Agent(POD_DISPATCHER_OPTIONS);
  const principals = new WeakMap<FastifyRequest, AgentPrincipal>();
  const unsubscribe = subscribeStreamClosers(deps);
  scope.addHook('onClose', async () => {
    unsubscribe();
    await dispatcher.destroy();
  });

  // Own encapsulated scope: the raw-body parser must not change the JSON parser of the dashboard API.
  void scope.register((mcp, _options, done) => {
    mcp.removeAllContentTypeParsers();
    mcp.addContentTypeParser(
      '*',
      { parseAs: 'buffer', bodyLimit: MAX_BODY_BYTES },
      (_request, rawBody, parsed) => {
        parsed(null, rawBody);
      },
    );
    mcp.setErrorHandler((error: FastifyError, _request, reply) => {
      if (error.code === 'FST_ERR_CTP_BODY_TOO_LARGE') {
        return reply.code(413).type('application/json').send(BODY_TOO_LARGE_BODY);
      }
      throw error; // the parent error handler (api/errors.ts) formats HydraError and other errors
    });

    mcp.route<McpRoute>({
      method: ['POST', 'GET', 'DELETE'],
      url: MCP_PATH,
      constraints: { host: deps.config.publicUrl.host },
      // Runs before the body is read: the order is 401, 503, 429, then 413 (spec section 8.2).
      onRequest: (request, reply, next) => {
        const { sid } = request.params;
        const principal = deps.tokens.resolve(request.headers.authorization, sid, request.ip);
        if (principal === null) {
          reply.header('www-authenticate', 'Bearer realm="hydra"');
          next(new HydraError('unauthenticated', INVALID_TOKEN_MESSAGE));
          return;
        }
        if (!isSessionRunning(deps.db, principal.sessionId)) {
          void reply.code(503).type('application/json').send(SESSION_NOT_RUNNING_BODY);
          return;
        }
        if (!limiter.take(principal.tokenId)) {
          reply.header('retry-after', '1');
          const limit = String(RATE_LIMIT_PER_SECOND);
          next(new HydraError('rate_limited', `More than ${limit} requests per second.`));
          return;
        }
        principals.set(request, principal);
        next();
      },
      handler: async (request, reply) => {
        const principal = principals.get(request);
        if (principal === undefined) throw new HydraError('unauthenticated', INVALID_TOKEN_MESSAGE);
        const body = Buffer.isBuffer(request.body) ? request.body : undefined;
        let messages: JsonRpcMessage[] = [];
        if (request.method === 'POST') {
          const parsed = parseJsonRpcBody(body ?? Buffer.alloc(0));
          if (!parsed.ok) return reply.code(400).type('application/json').send(PARSE_ERROR_BODY);
          if (parsed.messages.length > MAX_BATCH_MESSAGES) {
            return reply.code(400).type('application/json').send(BATCH_TOO_LARGE_BODY);
          }
          if (parsed.messages.some((message) => deniedTool(message) !== null)) {
            return rejectDeniedCalls(
              deps,
              principal,
              request,
              reply,
              parsed.messages,
              parsed.batch,
            );
          }
          messages = parsed.messages;
        }
        const exchange = new McpExchange(deps, {
          principal,
          mcpSessionId: mcpSessionIdOf(request),
          ip: request.ip,
        });
        exchange.begin(messages); // pending records before the request goes to the pod (spec 8.6)
        await proxyToPod(deps, dispatcher, principal, request, reply, body, exchange);
        return reply;
      },
    });
    done();
  });
}
```

```ts
async function startTap(target: string, timeline: string[]): Promise<Tap> {
  const records: TapRecord[] = [];

    const chunks: Buffer[] = [];
    req.on('data', (chunk: Buffer) => chunks.push(chunk));
    req.on('end', () => {
      const body = Buffer.concat(chunks);
      const text = body.toString('utf8');
      records.push({ method: req.method ?? '', headers: req.headers, body: text });

        { method: req.method, headers: req.headers },

          res.writeHead(up.statusCode ?? 502, up.headers);
          res.flushHeaders();
          up.pipe(res);
        },
      );
      upstream.on('error', () => res.destroy());
      res.on('close', () => upstream.destroy());
      upstream.end(body);
    });
  });

    url: `http://127.0.0.1:${String((server.address() as AddressInfo).port)}`,

    close: () =>

        server.closeAllConnections();
```

```ts
function waitForOutput(
  child: ChildProcess,
  pattern: RegExp,
  timeoutMs: number,
  name: string,
): Promise<RegExpExecArray> {
  return new Promise((resolve, reject) => {
    let output = '';
    const stream = child.stderr;
    if (stream === null) {
      reject(new Error(`${name}: no stderr pipe`));
      return;
    }
    const cleanup = (): void => {
      clearTimeout(timer);
      stream.off('data', onData);
      child.off('exit', onExit);
      stream.resume(); // keep reading, so that a full pipe cannot block the child
    };
    const onData = (data: Buffer): void => {
      output += data.toString('utf8');
      const match = pattern.exec(output);
      if (match !== null) {
        cleanup();
        resolve(match);
      }
    };
    const onExit = (code: number | null): void => {
      cleanup();
      reject(new Error(`${name} exited with code ${String(code)}:\n${output}`));
    };
    const timer = setTimeout(() => {
      cleanup();
      reject(new Error(`${name} did not start in ${String(timeoutMs)} ms:\n${output}`));
    }, timeoutMs);
    stream.on('data', onData);
    child.once('exit', onExit);
  });
}

async function stopProcess(child: ChildProcess): Promise<void> {
  if (child.exitCode !== null || child.signalCode !== null) return;
  const exited = new Promise<void>((resolve) => {
    child.once('exit', () => {
      resolve();
    });
  });
  child.kill('SIGTERM');
  const timer = setTimeout(() => {
    child.kill('SIGKILL');
  }, 5_000);
  await exited;
  clearTimeout(timer);
}

export async function startPlaywrightMcp(
  options: { caps?: readonly string[] } = {},
): Promise<PlaywrightMcp> {
  const executable = await chromiumExecutable();
  const workDir = mkdtempSync(path.join(tmpdir(), 'hydra-playwright-mcp-'));
  const children: ChildProcess[] = [];
  const stop = async (): Promise<void> => {
    for (const child of children.reverse()) await stopProcess(child);
    rmSync(workDir, { recursive: true, force: true });
  };
  try {
    const chromium = spawn(
      executable,
      [
        '--headless',
        '--no-sandbox',
        '--remote-debugging-address=127.0.0.1',
        '--remote-debugging-port=0',
        `--user-data-dir=${path.join(workDir, 'profile')}`,
        '--no-first-run',
        '--no-default-browser-check',
        'about:blank',
      ],
      { stdio: ['ignore', 'ignore', 'pipe'] },
    );
    children.push(chromium);
    const devtools = await waitForOutput(
      chromium,
      /DevTools listening on ws:\/\/127\.0\.0\.1:(\d+)\//,
      60_000,
      'Chromium',
    );
    const cdpEndpoint = `http://127.0.0.1:${devtools[1] ?? ''}`;

    const caps = options.caps ?? [];
    const mcp = spawn(
      process.execPath,
      [
        MCP_CLI,
        '--cdp-endpoint',
        cdpEndpoint,
        '--host',
        '127.0.0.1',
        '--port',
        '0',
        '--allowed-hosts',
        POD_HOST,
        '--output-dir',
        path.join(workDir, 'output'),
        ...(caps.length > 0 ? ['--caps', caps.join(',')] : []),
      ],
      { cwd: workDir, stdio: ['ignore', 'ignore', 'pipe'] },
    );
    children.push(mcp);
    const listening = await waitForOutput(
      mcp,
      /Listening on http:\/\/localhost:(\d+)\r?\n/,
      30_000,
      'playwright-mcp',
    );
    return { url: `http://127.0.0.1:${listening[1] ?? ''}`, stop };
  } catch (err) {
    await stop();
    throw err;
  }
}
```

```ts
// Sharing rules around the MCP proxy (spec sections 6.5, 8.3, 8.5, 15.2) against a real Playwright MCP.
import type { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { SessionActivityEventSchema, type AgentActivity } from '@hydra/shared';
import { request } from 'undici';
import { afterAll, afterEach, beforeAll, beforeEach, describe, expect, it } from 'vitest';
import { loginAs, seedUser } from '../helpers/seed.js';
import {
  apiRequest,
  createAgentToken,
  eventually,
  mcpClient,
  mcpPost,
  readSseUntil,
  seedOwnerSession,
  startGateway,
  type Gateway,
  type SeededOwner,
} from '../helpers/mcp-gateway.js';
import { startPlaywrightMcp, type PlaywrightMcp } from '../helpers/playwright-mcp.js';

const PAGE = 'data:text/html,<title>Hydra access test</title><p>Hello</p>';

describe('MCP proxy and session sharing', { timeout: 60_000 }, () => {
  let pw: PlaywrightMcp;
  let gw: Gateway;
  let owner: SeededOwner;
  const clients: Client[] = [];

  async function addMember(email: string, role: 'operator' | 'viewer') {
    const member = await seedUser(gw.deps, { email });
    const res = await apiRequest(
      gw,
      owner.cookie,
      'POST',
      `/api/sessions/${owner.sessionId}/members`,
      {
        email,
        role,
      },
    );
    expect(res.statusCode).toBeLessThan(300);
    const cookie = await loginAs(gw.app, email, member.password);
    return { userId: member.user.id, cookie };
  }

  async function connectAgent(secret: string) {
    const agent = mcpClient(gw, owner.sessionId, secret);
    clients.push(agent.client);
    await agent.client.connect(agent.transport);
    return agent;
  }

  beforeAll(async () => {
    pw = await startPlaywrightMcp();
  }, 600_000);

  afterAll(async () => {
    await pw.stop();
  });

  beforeEach(async () => {
    gw = await startGateway(pw.url);
    owner = await seedOwnerSession(gw);
  });

  afterEach(async () => {
    for (const client of clients.splice(0)) await client.close().catch(() => undefined);
    await gw.close();
  });

  it('closes the MCP streams of the tokens of a removed member at once, and keeps the others', async () => {
    const member = await addMember('member@example.com', 'operator');
    const memberToken = await createAgentToken(gw, member.cookie, owner.sessionId);
    const ownerToken = await createAgentToken(gw, owner.cookie, owner.sessionId);
    const memberAgent = await connectAgent(memberToken.secret);
    const ownerAgent = await connectAgent(ownerToken.secret);
    await eventually(() => {
      expect(gw.deps.mcpStreams.size()).toBe(2); // the GET stream of each agent
    });

    const removed = await apiRequest(
      gw,
      owner.cookie,
      'DELETE',
      `/api/sessions/${owner.sessionId}/members/${member.userId}`,
      {},
    );
    expect(removed.statusCode).toBeLessThan(300);

    expect(gw.deps.mcpStreams.size()).toBe(1);
    await expect(memberAgent.client.listTools()).rejects.toThrow();
    const { tools } = await ownerAgent.client.listTools();
    expect(tools.length).toBeGreaterThan(0);
    const after = await mcpPost(gw, owner.sessionId, memberToken.secret, {
      jsonrpc: '2.0',
      id: 1,
      method: 'ping',
    });
    expect(after.statusCode).toBe(401);
    await after.body.text();
  });

  it('gives a viewer the agent activity without arguments, but 403 on the audit log', async () => {
    const viewer = await addMember('viewer@example.com', 'viewer');
    const token = await createAgentToken(gw, owner.cookie, owner.sessionId);
    const { client } = await connectAgent(token.secret);
    await client.callTool({ name: 'browser_navigate', arguments: { url: PAGE } });

    const res = await apiRequest(gw, viewer.cookie, 'GET', `/api/sessions/${owner.sessionId}`);
    expect(res.statusCode).toBe(200);
    const resource = res.json<{ myRole: string; agentActivity: unknown }>();
    expect(resource.myRole).toBe('viewer');
    expect(resource.agentActivity).toEqual({
      activeAgentCount: 1,
      lastToolCall: {
        tool: 'browser_navigate',
        status: 'ok',
        durationMs: expect.any(Number) as unknown,
        startedAt: expect.any(Number) as unknown,
      },
    });

    const audit = await apiRequest(
      gw,
      viewer.cookie,
      'GET',
      `/api/sessions/${owner.sessionId}/audit`,
    );
    expect(audit.statusCode).toBe(403);
    expect(audit.json()).toMatchObject({ error: { code: 'forbidden' } });
  });

  it('sends session.activity to a viewer on GET /api/events after a tool call', async () => {
    const viewer = await addMember('viewer2@example.com', 'viewer');
    const token = await createAgentToken(gw, owner.cookie, owner.sessionId);
    const controller = new AbortController();
    try {
      const events = request(gw.url('/api/events'), {
        dispatcher: gw.dispatcher,
        headers: { cookie: viewer.cookie, accept: 'text/event-stream' },
        signal: controller.signal,
      });
      events.catch(() => undefined); // the finally block aborts the request
      await new Promise((resolve) => setTimeout(resolve, 200)); // the SSE route subscribes to the bus
      const { client } = await connectAgent(token.secret);
      await client.callTool({ name: 'browser_navigate', arguments: { url: PAGE } });
      const res = await events;
      res.body.on('error', () => undefined); // abort() in the finally block destroys the body
      expect(res.statusCode).toBe(200);
      const event = await readSseUntil(res.body, (candidate) => {
        if (candidate.event !== 'session.activity') return false;
        const data = SessionActivityEventSchema.parse(JSON.parse(candidate.data));
        return (
          data.sessionId === owner.sessionId &&
          data.agentActivity.lastToolCall?.tool === 'browser_navigate' &&
          data.agentActivity.lastToolCall.status === 'ok'
        );
      });
      const data = SessionActivityEventSchema.parse(JSON.parse(event.data));
      expect(data.agentActivity.activeAgentCount).toBe(1);
    } finally {
      controller.abort();
    }
  });

  it('counts two agents, and the count goes down 60 s after their last activity', async () => {
    const first = await createAgentToken(gw, owner.cookie, owner.sessionId);
    const second = await createAgentToken(gw, owner.cookie, owner.sessionId);
    await connectAgent(first.secret);
    await connectAgent(second.secret);
    const res = await apiRequest(gw, owner.cookie, 'GET', `/api/sessions/${owner.sessionId}`);
    expect(res.json<{ agentActivity: AgentActivity }>().agentActivity.activeAgentCount).toBe(2);

    const published: AgentActivity[] = [];
    gw.deps.bus.subscribe('session.activity', (event) => {
      if (event.sessionId === owner.sessionId) published.push(event.agentActivity);
    });
    gw.clock.advance(60_000);
    gw.deps.activity.sweep();
    expect(published).toEqual([{ activeAgentCount: 0, lastToolCall: null }]);
    const later = await apiRequest(gw, owner.cookie, 'GET', `/api/sessions/${owner.sessionId}`);
    expect(later.json<{ agentActivity: AgentActivity }>().agentActivity.activeAgentCount).toBe(0);
  });
});
```
