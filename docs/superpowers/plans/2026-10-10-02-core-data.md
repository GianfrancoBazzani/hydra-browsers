# Hydra Browsers v1 — Plan 02: Core Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@hydra/shared` (constants, error codes, messages, and the zod v4 API schemas) and the
server core: `lib/`, `config/`, `crypto/`, `db/` (schema, migrations, open, backups), `events/`, and
the audit writer and retention job, with the test helpers `clock`, `config`, and `db`.

**Architecture:** `@hydra/shared` is browser-safe TypeScript (zod and `Intl` only). The server modules
are small, synchronous where SQLite is involved, and get their dependencies as arguments (no global
singletons, time only from `Clock`). The database is SQLite through Drizzle with migrations that
drizzle-kit generates into `packages/server/drizzle/`. The registrable-domain check of the
configuration uses a vendored, generated copy of the Public Suffix List, so no runtime dependency is
added.

**Tech Stack:** TypeScript (strict, ESM), zod 4.6.5, drizzle-orm 0.45.3, drizzle-kit 0.31.11,
better-sqlite3 13.0.3, @node-rs/argon2 2.2.1, pino 10.4.0, Vitest (from plan 01), Node.js 24.21.0,
pnpm 12.9.0.

**Spec:** `docs/superpowers/specs/2026-10-10-hydra-browsers-design.md`. This plan covers sections 3.3,
4, 5.1, 6.1, 6.2, 6.3 (the password hash only), 6.4 (the dummy verify only), 6.6 (the token format
only), 6.7, 7.1 (sid and name), 7.2 (setting validation), 8.6 (the audit writer only), 12.2, 13, 14
(log redaction), and 15.1 (`crypto/` and `config/`). Read the spec sections of a task before you start
the task.

**Index:** `docs/superpowers/plans/2026-10-10-00-index.md`, sections 2 (conventions), 3 (checkpoint),
4 (file ownership), 5.1 to 5.7 and 5.12 (contracts).

**Not in this plan:** `audit/redaction.ts` (plan 05), password rules (plan 03), the start-time dry-run
check of `HYDRA_MEDIA_PORT_RANGE` against the node port range (plan 04, `KubeClient.dryRunNodePorts`),
the scheduling of the daily jobs (plan 03, `main.ts`), and the cleanup of expired login sessions and
live grants (plan 03).

## Review Focus

1. **Timezone names differ between JavaScript engines.** The spec default `UTC` and current IANA names
   such as `Europe/Kyiv` must pass on the server, although `Intl.supportedValuesOf('timeZone')` of
   Node.js 24.21 contains neither (it lists `Europe/Kiev`). A name with the wrong case
   (`europe/berlin`) must fail, because the `TZ` variable of the pod is case-sensitive. Pinned in
   Task 4 (`TimezoneSchema` tests) and Task 6 (default `UTC`).
2. **Allowlist entries pasted as URLs.** People paste `https://example.com/login`, `example.com:443`,
   `*.example.com`, or ` Example.COM `. The issue must point at the index of the bad entry, harmless
   differences (case, spaces) are normalized, and a duplicate after normalization is reported. Pinned
   in Task 4 (`AllowlistSchema` tests).
3. **Values from Kubernetes ConfigMaps and Secrets.** An empty value or only spaces counts as missing,
   a key file ends with a newline, and several variables can be wrong at once. The error names each
   variable, one per line. Pinned in Task 6.
4. **A data folder from an older deployment or a restore.** The folder can be `0755` and the file
   `0644`; the gateway corrects them. Backup rotation keeps exactly 10 backups and never deletes a file
   that is not a backup. Pinned in Task 10 (modes) and Task 11 (rotation).
5. **A failed migration during an upgrade.** The backup exists before the migration, the migration
   transaction rolls back, and `openDb` rejects so that the gateway stops. Pinned in Task 11.

## Spec deviations

Deviations (the plan does not follow the spec text exactly):

1. **No backup of a new database.** Spec 5.1 and 11.8: the gateway makes a backup before it runs the
   migrations. `openDb` skips the backup when the database has no tables yet (the first start), because
   there is nothing to protect.
2. **Mode errors are warnings.** Spec 5.1: `HYDRA_DATA_DIR` has mode `0700` and `hydra.db` mode `0600`.
   `openSqlite` sets both. If `chmod` fails (for example a volume folder that root owns, while the
   gateway runs as non-root under Pod Security `restricted`), it logs a warning and continues instead of
   stopping. The file and the backups are created by the gateway, so their modes are always set. Plan 08
   decides the folder ownership of the `gateway-data` volume.
3. **Allowlist host format is narrower than Chrome's** (spec 7.2): lowercase ASCII labels, IDNs only
   in punycode (`xn--…`), IPv4 addresses, an optional leading dot. No IPv6 literals and no trailing
   dot. Reason: one deterministic check that gives the same result in Node.js and in the browsers
   without IDN tables.

Stricter readings and choices where the spec is silent (no change of meaning intended):

4. "The two URLs must be different" is checked on the **hostname**, because cookies do not separate
   ports (RFC 6265 section 8.5).
5. "Same registrable domain" also compares the **scheme**, because browsers use schemeful same-site
   for `SameSite` cookies (the reason that spec 4 gives).
6. `HYDRA_PUBLIC_URL` and `HYDRA_LIVE_URL` must be **origins**: no path, query, fragment, credentials,
   or trailing dot.
7. `HYDRA_SESSION_IMAGE` and `HYDRA_MCP_IMAGE` must have the form `name:tag@sha256:<64 hex>` (spec 4:
   "with tag and digest").
8. Setting both `HYDRA_SECRET_KEY` and `HYDRA_SECRET_KEY_FILE` is an error. Values are trimmed, and an
   empty value counts as missing.
9. Foreign keys without cascade are added for `session_members.session_id`, `session_members.user_id`,
   `live_grants.user_id`, and `live_grants.session_id` (spec 13.1 names these columns without a foreign
   key; sessions and users are never deleted in v1).
10. Token names are 1 to 64 characters of `[A-Za-z0-9_-]`, because the name is also the MCP server name
    in the `claude mcp add` command of spec 10.2. Display names are 1 to 64 characters after trimming.
11. `LanguageSchema` returns the canonical BCP 47 form (`en-us` → `en-US`).

## Index issues

1. **`openDb` is asynchronous** (index 5.5 shows a synchronous return). It returns
   `Promise<OpenedDb>` with `OpenedDb = { db: Db; sqlite: Sqlite; close(): void }`, because the SQLite
   online backup API of better-sqlite3 (`Database#backup`) is asynchronous and spec 5.1 requires it.
   `main.ts` and the CLI (plan 03) must `await openDb(...)`.
2. **`createTestDb` stays synchronous** and makes no backup. It also returns `clock` and
   `backup(): Promise<string>` (extra fields).
3. **Extra `db/` exports:** `openSqlite(dataDir, logger?)` (folder, file, pragmas; no migrations),
   `createDb(sqlite)`, `migrateDb(db)`, `migrationsFolder()`, `DB_FILE`, `BACKUP_DIR`, `BACKUPS_KEPT`,
   `pruneBackups()`, the types `Sqlite` and `OpenedDb`, and the row types `UserRow`, `LoginSessionRow`,
   `SessionRow`, `SessionMemberRow`, `AgentTokenRow`, `LiveGrantRow`, `AuditEventRow`. `hydra db backup`
   (plan 03) should use `openSqlite` + `backupDb`, so that it does not run migrations next to the
   running gateway.
4. **Timezone check** (index 5.1 says "with `Intl.supportedValuesOf('timeZone')`"): that list does not
   contain `UTC` (the spec default) and uses older names in Node.js 24.21. `isValidTimezone` accepts
   `UTC`, the listed names, and IANA-shaped names that `Intl.DateTimeFormat` accepts; it rejects names
   that differ from a listed name only in case.
5. **`AuditWriter.update`** merges `patch.data` into the stored data (top-level keys) and publishes
   `{ type: 'audit', event }` with the updated event (same `id`), like `write`. SSE clients and the
   activity tracker (plan 05) must upsert by `id`. `AuditEvent.actorName` is the user display name
   (`actorType: 'user'`), the token name (`'token'`), or `null` (`'system'` or an unknown ID).
   `toAuditEvent(row, actorName)` and `actorNameOf(db, actorType, actorId)` are exported for the audit
   route of plan 03.
6. **`ConfigError`** has the constructor `(variable: string, message: string)`. `loadConfig` puts one
   line `VARIABLE: problem` for each wrong variable into the message; `variable` is the first one.
7. **Additions to `@hydra/shared`:** the types `DesiredState`, `Screen`, `TokenExpiryDays`, `SseEvent`;
   the constants `DEFAULT_SCREEN`, `SCREEN_FPS`, `DEFAULT_TOKEN_EXPIRY_DAYS`, `ACTOR_TYPES`/`ActorType`,
   `AUDIT_STATUSES`/`AuditStatus`, `AUDIT_PAGE_DEFAULT_LIMIT` (50), `AUDIT_PAGE_MAX_LIMIT` (200),
   `LOG_CONTAINERS`/`LogContainer`, `SESSION_NAME_MAX_LENGTH`, `ALLOWLIST_MAX_ENTRIES`; the schemas
   `TimestampSchema`, `UlidSchema`, `SidSchema`, `EmailSchema`, `DisplayNameSchema`, `SessionNameSchema`,
   `TimezoneSchema`, `LanguageSchema`, `ScreenSchema`, `TokenNameSchema`, `TokenExpiryDaysSchema`,
   `ListSessionsQuerySchema` (`?all=1` → `{ all: boolean }`), and `LogsQuerySchema`; the functions
   `isValidHostPattern`, `isValidTimezone`, and `canonicalLanguage`.
8. **Response schemas are loose:** `SessionSettingsSchema` (inside `SessionResourceSchema`) checks only
   the shape. The value rules are in the request schemas and in the field schemas above, so that a
   browser with another `Intl` data set cannot reject a server response.
9. **Optional fields and defaults:** `CreateTokenRequestSchema.expiresInDays` has `.default(30)` (input
   optional, output required, as in the index type). `CreateSessionRequest.start`, `timezone`,
   `language`, and `screen` stay optional; the service applies the defaults (`true`, the config
   defaults, `DEFAULT_SCREEN`). `AuditQuery.limit` stays optional; the server uses
   `AUDIT_PAGE_DEFAULT_LIMIT`.
10. **Extra server exports:** `lib`: `Semaphore`, `loggerOptions`, `REDACT_PATHS`; `config`:
    `CONFIG_DEFAULTS`, `LOG_LEVELS`, `SESSION_TRANSPORTS`, `isLocalhostName`, `isPinnedImage`,
    `publicSuffix`, `registrableDomain`, `siteOf`; `crypto`: `SUBKEY_LABELS`, `ARGON2_PARAMS`,
    `DEFAULT_MAX_PARALLEL`, `AGENT_TOKEN_PATTERN`, `AGENT_TOKEN_PREFIX`, `SID_LENGTH`, `ulidTime`;
    `events`: `HydraEventType`.
11. **File ownership:** Task 1 also changes `pnpm-workspace.yaml` (`allowBuilds`) and
    `pnpm-lock.yaml` (install). Index section 4 lists them only for plan 01.
12. **Generated migration metadata and Prettier:** drizzle-kit writes `drizzle/meta/*.json` in a style
    that `prettier --check` rejects. This plan formats them after generation. Later plans that generate
    a migration must run `pnpm exec prettier --write packages/server/drizzle/meta` too (or plan 01 adds
    the folder to `.prettierignore`).
13. **Production package:** the server needs `packages/server/drizzle/` at run time. If the server
    `package.json` has a `files` field, it must list `drizzle` (Task 1 adds it). `migrationsFolder()`
    finds the folder from `src/` and from the build output.
14. **Test helper location (index 5.12) needs two settings of plan 01:** unit tests in `src/` import
    `test/helpers/*.ts`, so the server `tsconfig.json` must include `test` (also for type-aware ESLint)
    without `rootDir: "src"`, and the Vitest configs must set `ssr.resolve.conditions:
    ['@hydra/source']` (Vitest 5 does not apply `resolve.conditions` to the Node.js test runner).

## Verified facts (scratch checks on 2026-10-10)

- pnpm 12.9.0 with the `pnpm-workspace.yaml` of spec 3.4.3 installs all versions above.
  better-sqlite3 13.0.3 ships prebuilt Node-API binaries for darwin, linux (glibc and musl), and win32
  inside the package and has no install script; it loads under Node.js 24.21.0 (SQLite 3.53.4). The
  spec entry `better-sqlite3: true` therefore has no effect today; the plan keeps it.
- drizzle-kit 0.31.11 pulls esbuild 0.18.20 and 0.25.12 (and tsx with esbuild 0.28.2). Without an
  `allowBuilds` entry, `pnpm install` fails with `ERR_PNPM_IGNORED_BUILDS`. With `esbuild: false`,
  drizzle-kit works (the binary comes from the `@esbuild/<platform>` optional package).
- drizzle-orm 0.45.3: `drizzle({ client, schema })`; `migrate(db, { migrationsFolder })` from
  `drizzle-orm/better-sqlite3/migrator` is synchronous, reads `meta/_journal.json`, and runs all pending
  migrations in one transaction with `ROLLBACK` on error. drizzle-kit 0.31.11 generates from CLI flags
  without a config file, in an ESM package, when `schema.ts` imports only types from `@hydra/shared`.
  The generated partial index (`WHERE "sessions"."media_port" IS NOT NULL`) works in SQLite.
- @node-rs/argon2 2.2.1 declares `Algorithm` and `Version` as ambient const enums (`TS2748` under
  `verbatimModuleSyntax`), so the code uses the defaults (Argon2id, version 0x13) and checks the PHC
  prefix. `hash` accepts `salt` and `secret`; `parseOptions` parses a PHC string; `verify` throws for a
  malformed PHC string. One hash with m = 64 MiB, t = 3 takes about 70 ms on an M-series Mac.
- Node.js 24.21: `Intl.supportedValuesOf('timeZone')` has 418 names, no `UTC`, and `Europe/Kiev`
  instead of `Europe/Kyiv`; `Intl.DateTimeFormat` accepts `UTC`, `Europe/Kyiv`, and offsets such as
  `+01:00`. `Intl.getCanonicalLocales('en-us')` returns `en-US`.
- pino 10.4.0 (with `@pinojs/redact`) supports paths such as `*.*.password`; `*.password` also matches
  objects inside arrays.
- Public Suffix List at commit `6cd82aff889e3d64e5e03bc5c1f43da1934a960a` (2026-10-01): 10,333 rules,
  file SHA-256 `102b252c18b5f87f4c81f017e75282a82c18e00cd0c2e601b5b02a0f7a601f2c`. The algorithm of
  Task 5 passes all 73 applicable vectors of the list's `tests/test_psl.txt`.
- TypeScript 6.0.3 and 7.0.2 both type-check all code of this plan. A `tsc` build to `dist/` runs
  `openDb` and `loadConfig` from `dist`.

```ts
// Validation helpers (spec section 7.2)

const HOST_LABEL = /^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?$/;
const IPV4_PART = /^(?:0|[1-9][0-9]{0,2})$/;

function isIPv4(host: string): boolean {
  const parts = host.split('.');
  return parts.length === 4 && parts.every((part) => IPV4_PART.test(part) && Number(part) <= 255);
}

/**
 * One allowlist entry in the Chrome URL filter format for hosts: `example.com` (the host and all
 * its subdomains) or `.example.com` (only this host). Lowercase ASCII only (write an IDN in
 * punycode). No scheme, port, path, or wildcard. An IPv4 address is a valid host.
 */
export function isValidHostPattern(entry: string): boolean {
  const host = entry.startsWith('.') ? entry.slice(1) : entry;
  if (host.length === 0 || host.length > 253) return false;
  const labels = host.split('.');
  if (!labels.every((label) => HOST_LABEL.test(label))) return false;
  // As in the URL standard: a host that ends in a number must be an IPv4 address.
  const last = labels[labels.length - 1] ?? '';
  return /^[0-9]+$/.test(last) ? isIPv4(host) : true;
}

const IANA_NAME = /^[A-Z][A-Za-z0-9_+-]*(?:\/[A-Z][A-Za-z0-9_+-]*)+$/;
let knownZones: { exact: Set<string>; lower: Set<string> } | undefined;

function zones(): { exact: Set<string>; lower: Set<string> } {
  if (!knownZones) {
    const list = Intl.supportedValuesOf('timeZone');
    knownZones = { exact: new Set(list), lower: new Set(list.map((zone) => zone.toLowerCase())) };
  }
  return knownZones;
}

/**
 * An IANA timezone name. `Intl.supportedValuesOf('timeZone')` is the main list. It does not
 * contain `UTC`, and some engines list an older name (`Europe/Kiev` for `Europe/Kyiv`), so the
 * check also accepts `UTC` and IANA-shaped names that `Intl.DateTimeFormat` accepts. A name that
 * differs from a listed name only in case is rejected (the `TZ` variable is case-sensitive).
 */
export function isValidTimezone(name: string): boolean {
  const known = zones();
  if (name === 'UTC' || known.exact.has(name)) return true;
  if (!IANA_NAME.test(name) || known.lower.has(name.toLowerCase())) return false;
  try {
    new Intl.DateTimeFormat('en-US', { timeZone: name });
    return true;
  } catch {
    return false;
  }
}

/** The canonical form of a BCP 47 language tag (`en-us` → `en-US`), or null if it is not valid. */
export function canonicalLanguage(tag: string): string | null {
  try {
    return Intl.getCanonicalLocales(tag)[0] ?? null;
  } catch {
    return null;
  }
}

const NAME_MESSAGE = `Name must have 1 to ${String(SESSION_NAME_MAX_LENGTH)} characters`;

  'Use a host such as example.com or .example.com (no scheme, port, path, or wildcard)';

export const SessionNameSchema = z
  .string()
  .trim()
  .min(1, NAME_MESSAGE)
  .max(SESSION_NAME_MAX_LENGTH, NAME_MESSAGE);

/** 1 to 100 host patterns, or exactly `["*"]`. Entries are trimmed and lowercased. */
export const AllowlistSchema = z
  .array(z.string().trim().toLowerCase())
  .min(1, 'Add at least one host')
  .max(ALLOWLIST_MAX_ENTRIES, `Use at most ${String(ALLOWLIST_MAX_ENTRIES)} hosts`)
  .superRefine((entries, ctx) => {
    if (entries.includes('*')) {
      if (entries.length > 1) {
        ctx.addIssue({
          code: 'custom',
          message: '"*" must be the only entry',
          path: [entries.indexOf('*')],
        });
      }
      return;
    }
    const seen = new Set<string>();
    entries.forEach((entry, index) => {
      if (!isValidHostPattern(entry)) {
        ctx.addIssue({ code: 'custom', message: HOST_MESSAGE, path: [index] });
      } else if (seen.has(entry)) {
        ctx.addIssue({ code: 'custom', message: 'Duplicate host', path: [index] });
      }
      seen.add(entry);
    });
  });

export const TimezoneSchema = z
  .string()
  .trim()
  .refine(isValidTimezone, 'Use an IANA timezone such as Europe/Berlin');

/** A BCP 47 language tag. The output is the canonical form. */
export const LanguageSchema = z
  .string()
  .trim()
  .transform((tag, ctx) => {
    const canonical = canonicalLanguage(tag);
    if (canonical === null) {
      ctx.addIssue({ code: 'custom', message: 'Use a BCP 47 language tag such as en-US' });
      return z.NEVER;
    }
    return canonical;
  });
```

### Task 5: Public Suffix List and the site of an origin

Spec section 4 (same registrable domain), 9.2 (why the same site is needed).

Why a vendored list: Node.js has no Public Suffix List API, and index 2.3 forbids new runtime
dependencies. A rule such as "the last two labels" is wrong for `co.uk`, `github.io`, and many others.
The plan generates `src/config/public-suffix-list.ts` from a pinned commit of the official list
(SHA-256 checked), with the labels converted to punycode, and implements the algorithm of
https://publicsuffix.org/list/ in about 40 lines. The default rule `*` gives exactly the localhost
behavior of spec 4: `hydra.localhost` and `live.hydra.localhost` share the site `hydra.localhost`, and
`localhost` and `live.localhost` do not share a site. The list is MPL-2.0; the generated file keeps
the license notice. To update the list later, repeat Step 3 with a newer commit and its SHA-256.

```ts
import { isIP } from 'node:net';
import { PUBLIC_SUFFIX_RULES } from './public-suffix-list.js';

interface SuffixRules {
  exact: Set<string>;
  wildcards: Set<string>; // "ck" for the rule "*.ck"
  exceptions: Set<string>; // "www.ck" for the rule "!www.ck"
}

let cached: SuffixRules | undefined;

function rules(): SuffixRules {
  if (cached) return cached;
  const parsed: SuffixRules = { exact: new Set(), wildcards: new Set(), exceptions: new Set() };
  for (const rule of PUBLIC_SUFFIX_RULES.split('\n')) {
    if (rule === '') continue;
    if (rule.startsWith('!')) parsed.exceptions.add(rule.slice(1));
    else if (rule.startsWith('*.')) parsed.wildcards.add(rule.slice(2));
    else parsed.exact.add(rule);
  }
  cached = parsed;
  return parsed;
}

/**
 * The public suffix of a hostname, with the algorithm of https://publicsuffix.org/list/.
 * `hostname` must be in the form of `URL.hostname`: lowercase, ASCII (punycode).
 */
export function publicSuffix(hostname: string): string {
  const { exact, wildcards, exceptions } = rules();
  const labels = hostname.split('.');
  // An exception rule wins over all other rules. Its public suffix drops the leftmost label.
  for (let i = 0; i < labels.length; i++) {
    if (exceptions.has(labels.slice(i).join('.'))) return labels.slice(i + 1).join('.');
  }
  // Otherwise the matching rule with the most labels wins.
  for (let i = 0; i < labels.length; i++) {
    const suffix = labels.slice(i).join('.');
    if (exact.has(suffix)) return suffix;
    if (i + 1 < labels.length && wildcards.has(labels.slice(i + 1).join('.'))) return suffix;
  }
  // No rule matches: the default rule "*" makes the last label the public suffix.
  return labels[labels.length - 1] ?? hostname;
}

/** The public suffix plus one label, or null if the hostname is a public suffix itself. */
export function registrableDomain(hostname: string): string | null {
  const suffix = publicSuffix(hostname);
  if (suffix === hostname) return null;
  const labels = hostname.split('.');
  return labels.slice(labels.length - suffix.split('.').length - 1).join('.');
}

/** The "site" of an origin (HTML standard): scheme plus registrable domain, or the host itself. */
export function siteOf(url: URL): string {
  const host = url.hostname;
  const bare = host.startsWith('[') ? host.slice(1, -1) : host;
  const domain = isIP(bare) === 0 ? (registrableDomain(host) ?? host) : host;
  return `${url.protocol}//${domain}`;
}
```

```ts
/** Adds a validation issue. `variable` is needed only in the object-level checks. */
function addIssue(ctx: Ctx, message: string, variable?: string): void {
  ctx.addIssue({ code: 'custom', message, ...(variable ? { path: [variable] } : {}) });
}

export function isLocalhostName(hostname: string): boolean {
  return hostname === 'localhost' || hostname.endsWith('.localhost');
}

/** An origin with https, or http for localhost names (browsers treat them as secure contexts). */
function parseOrigin(value: string, ctx: Ctx): URL {
  let url: URL;
  try {
    url = new URL(value);
  } catch {
    addIssue(ctx, 'must be a URL such as https://hydra.example.com');
    return z.NEVER;
  }
  if (url.username || url.password || url.pathname !== '/' || url.search || url.hash) {
    addIssue(ctx, 'must be an origin (scheme, host, port) without path, query, or credentials');
    return z.NEVER;
  }
  if (url.hostname.endsWith('.')) {
    addIssue(ctx, 'must not end with a dot');
    return z.NEVER;
  }
  const secure =
    url.protocol === 'https:' || (url.protocol === 'http:' && isLocalhostName(url.hostname));
  if (!secure) {
    addIssue(ctx, 'must use https (http only for localhost and *.localhost)');
    return z.NEVER;
  }
  return new URL(url.origin);
}

function parseInteger(min: number, max: number) {
  return (value: string, ctx: Ctx): number => {
    const number = /^\d+$/.test(value) ? Number(value) : Number.NaN;
    if (!Number.isSafeInteger(number) || number < min || number > max) {
      addIssue(ctx, `must be an integer from ${String(min)} to ${String(max)}`);
      return z.NEVER;
    }
    return number;
  };
}

function parsePortRange(value: string, ctx: Ctx): { first: number; last: number } {
  const match = /^(\d{1,5})-(\d{1,5})$/.exec(value);
  const first = Number(match?.[1]);
  const last = Number(match?.[2]);
  if (!match || first < 1 || last > 65535 || first > last) {
    addIssue(ctx, 'must be "<first>-<last>" with 1 <= first <= last <= 65535');
    return z.NEVER;
  }
  return { first, last };
}

function isIpOrCidr(entry: string): boolean {
  const [address = '', prefix, ...rest] = entry.split('/');
  const version = isIP(address);
  if (version === 0 || rest.length > 0) return false;
  if (prefix === undefined) return true;
  return /^\d{1,3}$/.test(prefix) && Number(prefix) <= (version === 4 ? 32 : 128);
}

function parseProxies(value: string, ctx: Ctx): string[] {
  const entries = value
    .split(',')
    .map((entry) => entry.trim())
    .filter((entry) => entry !== '');
  if (entries.length === 0 || !entries.every(isIpOrCidr)) {
    addIssue(ctx, 'must be a comma-separated list of IP addresses or CIDR ranges');
    return z.NEVER;
  }
  return entries;
}

/** `name:tag@sha256:<digest>`: the image rule of spec section 3.4.1 (tag and digest). */
export function isPinnedImage(reference: string): boolean {
  const at = reference.indexOf('@');
  if (at < 0 || !/^sha256:[a-f0-9]{64}$/.test(reference.slice(at + 1))) return false;
  const nameAndTag = reference.slice(0, at);
  const colon = nameAndTag.lastIndexOf(':');
  if (colon <= nameAndTag.lastIndexOf('/')) return false;
  const name = nameAndTag.slice(0, colon);
  const tag = nameAndTag.slice(colon + 1);
  return /^[a-z0-9]+(?:[._/:-]+[a-z0-9]+)*$/.test(name) && /^\w[\w.-]{0,127}$/.test(tag);
}

/** The decoded root key, or null after an issue for `variable`. */
function decodeSecretKey(text: string, variable: string, ctx: Ctx): Buffer | null {
  if (!/^[A-Za-z0-9+/]+={0,2}$/.test(text) || text.length % 4 !== 0) {
    addIssue(ctx, 'must be base64 (hydra keygen prints a valid key)', variable);
    return null;
  }
  const key = Buffer.from(text, 'base64');
  if (key.length < 32) {
    addIssue(ctx, `must decode to 32 bytes or more, not ${String(key.length)}`, variable);
    return null;
  }
  return key;
}

/** The root key from HYDRA_SECRET_KEY, or from the file in HYDRA_SECRET_KEY_FILE. */
function readSecretKey(inline: string | undefined, file: string | undefined, ctx: Ctx): Buffer {
  if (inline !== undefined && file !== undefined) {
    addIssue(
      ctx,
      'set HYDRA_SECRET_KEY or HYDRA_SECRET_KEY_FILE, not both',
      'HYDRA_SECRET_KEY_FILE',
    );
    return Buffer.alloc(0);
  }
  if (file !== undefined) {
    let text: string;
    try {
      text = readFileSync(file, 'utf8').trim();
    } catch (error) {
      const reason = error instanceof Error ? error.message : String(error);
      addIssue(ctx, `cannot read the file: ${reason}`, 'HYDRA_SECRET_KEY_FILE');
      return Buffer.alloc(0);
    }
    return decodeSecretKey(text, 'HYDRA_SECRET_KEY_FILE', ctx) ?? Buffer.alloc(0);
  }
  if (inline === undefined) {
    addIssue(ctx, 'is required (or set HYDRA_SECRET_KEY_FILE)', 'HYDRA_SECRET_KEY');
    return Buffer.alloc(0);
  }
  return decodeSecretKey(inline, 'HYDRA_SECRET_KEY', ctx) ?? Buffer.alloc(0);
}

const image = required.refine(isPinnedImage, 'must be "name:tag@sha256:<64 hex digits>"');

const envSchema = z
  .object({
    HYDRA_DATA_DIR: required.transform((dir) => resolve(dir)),
    HYDRA_SECRET_KEY: z.string().optional(),
    HYDRA_SECRET_KEY_FILE: z.string().optional(),
    HYDRA_PUBLIC_URL: required.transform(parseOrigin),
    HYDRA_LIVE_URL: required.transform(parseOrigin),
    HYDRA_PUBLIC_IP: required.refine((ip) => isIP(ip) !== 0, 'must be an IP address'),
    HYDRA_MEDIA_PORT_RANGE: required.transform(parsePortRange),
    HYDRA_MAX_RUNNING: required.transform(parseInteger(1, 65535)),
    HYDRA_SESSION_NAMESPACE: required.regex(
      /^[a-z0-9](?:[-a-z0-9]{0,61}[a-z0-9])?$/,
      'must be a Kubernetes namespace name',
    ),
    HYDRA_SESSION_TRANSPORT: z.enum(SESSION_TRANSPORTS, {
      error: 'must be cluster-dns or port-forward',
    }),
    HYDRA_SESSION_IMAGE: image,
    HYDRA_MCP_IMAGE: image,
    HYDRA_TRUSTED_PROXIES: required.transform(parseProxies),
    HYDRA_DEFAULT_TIMEZONE: required.pipe(TimezoneSchema),
    HYDRA_DEFAULT_LANGUAGE: required.pipe(LanguageSchema),
    HYDRA_AUDIT_RETENTION_DAYS: required.transform(parseInteger(1, 36500)),
    HYDRA_LOG_LEVEL: z.enum(LOG_LEVELS, { error: `must be one of ${LOG_LEVELS.join(', ')}` }),
    PORT: required.transform(parseInteger(1, 65535)),
  })
  .transform((env, ctx): Config => {
    const secretKey = readSecretKey(env.HYDRA_SECRET_KEY, env.HYDRA_SECRET_KEY_FILE, ctx);

    const publicUrl = env.HYDRA_PUBLIC_URL;
    const liveUrl = env.HYDRA_LIVE_URL;
    if (publicUrl.hostname === liveUrl.hostname) {
      addIssue(ctx, 'must use another hostname than HYDRA_PUBLIC_URL', 'HYDRA_LIVE_URL');
    } else if (siteOf(publicUrl) !== siteOf(liveUrl)) {
      // The SameSite=Strict live grant cookie needs the same site (spec section 9.2).
      addIssue(
        ctx,
        `must be on the same site (scheme and registrable domain) as HYDRA_PUBLIC_URL: ` +
          `${siteOf(liveUrl)} is not ${siteOf(publicUrl)}`,
        'HYDRA_LIVE_URL',
      );
    }

    const range = env.HYDRA_MEDIA_PORT_RANGE;
    const size = range.last - range.first + 1;
    if (size < env.HYDRA_MAX_RUNNING) {
      addIssue(
        ctx,
        `has ${String(size)} ports, fewer than HYDRA_MAX_RUNNING ` +
          `(${String(env.HYDRA_MAX_RUNNING)})`,
        'HYDRA_MEDIA_PORT_RANGE',
      );
    }

    const localUrls = isLocalhostName(publicUrl.hostname) && isLocalhostName(liveUrl.hostname);
    if (env.HYDRA_SESSION_TRANSPORT === 'port-forward' && !localUrls) {
      addIssue(
        ctx,
        'port-forward is permitted only if both URLs use localhost hostnames',
        'HYDRA_SESSION_TRANSPORT',
      );
    }

    return {
      dataDir: env.HYDRA_DATA_DIR,
      secretKey,
      publicUrl,
      liveUrl,
      publicIp: env.HYDRA_PUBLIC_IP,
      mediaPortRange: range,
      maxRunning: env.HYDRA_MAX_RUNNING,
      sessionNamespace: env.HYDRA_SESSION_NAMESPACE,
      sessionTransport: env.HYDRA_SESSION_TRANSPORT,
      sessionImage: env.HYDRA_SESSION_IMAGE,
      mcpImage: env.HYDRA_MCP_IMAGE,
      trustedProxies: env.HYDRA_TRUSTED_PROXIES,
      defaultTimezone: env.HYDRA_DEFAULT_TIMEZONE,
      defaultLanguage: env.HYDRA_DEFAULT_LANGUAGE,
      auditRetentionDays: env.HYDRA_AUDIT_RETENTION_DAYS,
      logLevel: env.HYDRA_LOG_LEVEL,
      port: env.PORT,
    };
  });

/**
 * Reads and validates the configuration (spec section 4). Values are trimmed, and an empty value
 * counts as missing. Throws ConfigError; its message has one line for each wrong variable.
 */
export function loadConfig(env: Record<string, string | undefined>): Config {
  const values: Record<string, string | undefined> = {};
  for (const name of VARIABLES) {
    const value = env[name]?.trim();
    values[name] = value === '' ? undefined : value;
  }
  for (const [name, fallback] of Object.entries(CONFIG_DEFAULTS)) values[name] ??= fallback;

  const result = envSchema.safeParse(values);
  if (result.success) return result.data;
  const problems = result.error.issues.map((zodIssue) => ({
    variable: typeof zodIssue.path[0] === 'string' ? zodIssue.path[0] : 'configuration',
    message: zodIssue.message,
  }));
  throw new ConfigError(
    problems[0]?.variable ?? 'configuration',
    problems.map((problem) => `${problem.variable}: ${problem.message}`).join('\n'),
  );
}
```

```ts
export class Semaphore {
  readonly #max: number;
  readonly #waiting: (() => void)[] = [];
  #active = 0;

  constructor(max: number) {
    if (!Number.isInteger(max) || max < 1) throw new RangeError('max must be a positive integer');
    this.#max = max;
  }

  get active(): number {
    return this.#active;
  }

  get waiting(): number {
    return this.#waiting.length;
  }

  async run<T>(task: () => Promise<T>): Promise<T> {
    await this.#acquire();
    try {
      return await task();
    } finally {
      this.#release();
    }
  }

  #acquire(): Promise<void> {
    if (this.#active < this.#max) {
      this.#active += 1;
      return Promise.resolve();
    }
    return new Promise((resolve) => this.#waiting.push(resolve));
  }

  #release(): void {
    const next = this.#waiting.shift();
    // The slot goes directly to the next task, so #active does not change.
    if (next) next();
    else this.#active -= 1;
  }
}
```

```ts
  loginSession: 'hydra/login-session/v1',
  liveGrant: 'hydra/live-grant/v1',

export interface Subkeys {
  passwordPepper: Buffer;
  loginSession: Buffer;
  liveGrant: Buffer;
  agentToken: Buffer;
  neko: Buffer;
}

const SUBKEY_BYTES = 32;

function derive(rootKey: Buffer, label: string): Buffer {
  // HKDF-SHA256 without a salt (RFC 5869: a zero-length salt acts as HashLen zero bytes).
  return Buffer.from(hkdfSync('sha256', rootKey, Buffer.alloc(0), label, SUBKEY_BYTES));

    agentToken: derive(rootKey, SUBKEY_LABELS.agentToken),
    neko: derive(rootKey, SUBKEY_LABELS.neko),
  };
```

```ts
const BASE62_ALPHABET = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz';

export const AGENT_TOKEN_PATTERN = /^hyd_[0-9A-Za-z]{43}$/;

/**
 * Agent token (spec section 6.6): `hyd_` + base62 of 32 random bytes, always 43 digits.
 * `prefix` is what the UI shows after creation: `hyd_` + the first 8 digits + `…`.
 */
export function newAgentToken(): { token: string; prefix: string } {

  let body = '';
  for (let i = 0; i < TOKEN_BODY_LENGTH; i++) {
    body = BASE62_ALPHABET.charAt(Number(value % 62n)) + body;
    value /= 62n;
  }
```

```ts
import { randomBytes } from 'node:crypto';
import type { Clock } from '../lib/clock.js';

const ENCODING = '0123456789ABCDEFGHJKMNPQRSTVWXYZ'; // Crockford base32, in ASCII order
const MAX_TIME = 2 ** 48 - 1;

/**
 * A ULID: 10 characters of time (ms) and 16 characters of randomness. IDs sort by time.
 * IDs of the same millisecond are not ordered (monotonic mode is not needed).
 */
export function newUlid(clock: Clock): string {
  let time = clock.now();
  if (!Number.isSafeInteger(time) || time < 0 || time > MAX_TIME) {
    throw new RangeError(`Cannot encode the time ${String(time)} in a ULID`);
  }
  let timePart = '';
  for (let i = 0; i < 10; i++) {
    timePart = ENCODING.charAt(time % 32) + timePart;
    time = Math.floor(time / 32);
  }
  let random = BigInt(`0x${randomBytes(10).toString('hex')}`);
  let randomPart = '';
  for (let i = 0; i < 16; i++) {
    randomPart = ENCODING.charAt(Number(random & 31n)) + randomPart;
    random >>= 5n;
  }
  return timePart + randomPart;
}

/** The time (ms) in a ULID. */
export function ulidTime(id: string): number {
  let time = 0;
  for (const char of id.slice(0, 10)) {
    const value = ENCODING.indexOf(char);
    if (value < 0) throw new RangeError(`Not a ULID: ${id}`);
    time = time * 32 + value;
  }
  return time;
}
```

```ts
 */
const DUMMY_HASH =
  `${PHC_PREFIX}m=${String(ARGON2_PARAMS.memoryCost)},t=${String(ARGON2_PARAMS.timeCost)},` +
  `p=${String(ARGON2_PARAMS.parallelism)}` +
  `$${unpaddedBase64(Buffer.alloc(ARGON2_PARAMS.saltLength, 0x5a))}` +
  `$${unpaddedBase64(Buffer.alloc(ARGON2_PARAMS.outputLen, 0xa5))}`;

/** Argon2id password hashes (PHC strings) with the pepper as the Argon2 secret. */
export class PasswordHasher {
  readonly #pepper: Buffer;
  readonly #semaphore: Semaphore;

  constructor(pepper: Buffer, options?: { maxParallel?: number }) {
    this.#pepper = pepper;
    // Each operation uses 64 MiB of memory. Other operations wait in a queue.
    this.#semaphore = new Semaphore(options?.maxParallel ?? DEFAULT_MAX_PARALLEL);
  }

  hash(password: string): Promise<string> {
    const salt = randomBytes(ARGON2_PARAMS.saltLength);
    return this.#semaphore.run(() =>
      hash(password, {
        memoryCost: ARGON2_PARAMS.memoryCost,
        timeCost: ARGON2_PARAMS.timeCost,
        parallelism: ARGON2_PARAMS.parallelism,
        outputLen: ARGON2_PARAMS.outputLen,
        salt,
        secret: this.#pepper,
      }),
    );
  }

  /** False for a wrong password, and for a stored value that is not a valid PHC string. */
  async verify(phc: string, password: string): Promise<boolean> {
    try {
      parseOptions(phc);
    } catch {
      return this.verifyDummy(password);
    }
    return this.#semaphore.run(() => verify(phc, password, { secret: this.#pepper }));
  }

  /** A verify with the same cost against a fixed dummy hash. Always false. */
  async verifyDummy(password: string): Promise<false> {
    await this.#semaphore.run(() => verify(DUMMY_HASH, password, { secret: this.#pepper }));
    return false;
  }

  /** True if the hash does not use the current algorithm, version, and parameters. */
  needsRehash(phc: string): boolean {
    if (!phc.startsWith(PHC_PREFIX)) return true;
    try {
      const options = parseOptions(phc);
      return (
        options.memoryCost !== ARGON2_PARAMS.memoryCost ||
        options.timeCost !== ARGON2_PARAMS.timeCost ||
        options.parallelism !== ARGON2_PARAMS.parallelism ||
        options.outputLen !== ARGON2_PARAMS.outputLen ||
        options.saltLen !== ARGON2_PARAMS.saltLength
      );
    } catch {
      return true;
    }
  }
}
```

```ts
import { chmodSync, mkdirSync, readdirSync, rmSync } from 'node:fs';
import { join } from 'node:path';
import type Database from 'better-sqlite3';
import type { Clock } from '../lib/clock.js';

export const BACKUP_DIR = 'backups';
export const BACKUPS_KEPT = 10;
const BACKUP_NAME = /^hydra-\d{8}T\d{9}Z\.db$/;

/** 2026-10-10T12:00:00.123Z → 20261010T120000123Z. Fixed width, so names sort by time. */
function stamp(ms: number): string {
  return new Date(ms).toISOString().replace(/[-:.]/g, '');
}

/**
 * Copies the database with the SQLite online backup API to `backups/hydra-<timestamp>.db`
 * (mode 0600) and keeps the 10 newest backups (spec section 5.1). Returns the file path.
 * A second backup in the same millisecond replaces the first one.
 */
export async function backupDb(
  sqlite: Database.Database,
  dataDir: string,
  clock: Clock,
): Promise<string> {
  const folder = join(dataDir, BACKUP_DIR);
  mkdirSync(folder, { recursive: true, mode: 0o700 });
  chmodSync(folder, 0o700);
  const file = join(folder, `hydra-${stamp(clock.now())}.db`);
  await sqlite.backup(file);
  chmodSync(file, 0o600);
  pruneBackups(folder);
  return file;
}

/** Deletes all backups except the `keep` newest. Other files in the folder stay. */
export function pruneBackups(folder: string, keep: number = BACKUPS_KEPT): string[] {
  const names = readdirSync(folder)
    .filter((name) => BACKUP_NAME.test(name))
    .sort()
    .reverse();
  const removed = names.slice(keep);
  for (const name of removed) rmSync(join(folder, name), { force: true });
  return removed;
}
```

```ts
import type { AgentActivity, AuditEvent, SessionState } from '@hydra/shared';
import type { Logger } from '../lib/logger.js';

/** Events of spec section 3.1. The module that causes an event publishes it. */
export type HydraEvent =
  | {
      type: 'session.state';
      sessionId: string;
      state: SessionState;
      previous: SessionState;
      errorReason: string | null;
    }
  | { type: 'session.activity'; sessionId: string; agentActivity: AgentActivity }
  | { type: 'token.revoked'; tokenId: string; sessionId: string }
  | { type: 'rights.changed'; userId: string }
  | { type: 'login.ended'; userId: string; loginSessionIds: string[] }
  | { type: 'audit'; event: AuditEvent };

export type HydraEventType = HydraEvent['type'];
type Handler<T extends HydraEventType> = (event: Extract<HydraEvent, { type: T }>) => void;

/** In-process event bus. Handlers run synchronously, in the order of subscription. */
export class EventBus {
  readonly #logger: Logger;
  readonly #handlers = new Map<HydraEventType, Set<(event: HydraEvent) => void>>();

  constructor(logger: Logger) {
    this.#logger = logger;
  }

  /** Calls each handler of the event type. A handler error is logged, not thrown. */
  publish(event: HydraEvent): void {
    const handlers = this.#handlers.get(event.type);
    if (!handlers) return;
    for (const handler of [...handlers]) {
      try {
        handler(event);
      } catch (error) {
        this.#logger.error({ err: error, eventType: event.type }, 'event handler failed');
      }
    }
  }

  /** Returns the function that removes the subscription. */
  subscribe<T extends HydraEventType>(type: T, handler: Handler<T>): () => void {
    const wrapped = handler as (event: HydraEvent) => void;
    let handlers = this.#handlers.get(type);
    if (!handlers) {
      handlers = new Set();
      this.#handlers.set(type, handlers);
    }
    handlers.add(wrapped);
    return () => {
      this.#handlers.get(type)?.delete(wrapped);
    };
  }
}
```

```ts
import type { ActorType, AuditEvent, AuditKind, AuditStatus } from '@hydra/shared';
import { eq } from 'drizzle-orm';
import type { Db } from '../db/open.js';
import { agentTokens, auditEvents, users, type AuditEventRow } from '../db/schema.js';
import type { EventBus } from '../events/bus.js';
import type { Clock } from '../lib/clock.js';
import { HydraError } from '../lib/errors.js';

export interface AuditInput {
  kind: AuditKind;
  actorType: ActorType;
  actorId: string | null;
  sessionId: string | null;
  status?: AuditStatus | null;
  data: Record<string, unknown>;
}

/**
 * The display name of an actor: the user display name for 'user', the token name for 'token',
 * and null for 'system' or for an ID that does not exist.
 */
export function actorNameOf(db: Db, actorType: ActorType, actorId: string | null): string | null {
  if (actorId === null) return null;
  if (actorType === 'user') {
    const row = db
      .select({ name: users.displayName })
      .from(users)
      .where(eq(users.id, actorId))
      .get();
    return row?.name ?? null;
  }
  if (actorType === 'token') {
    const row = db
      .select({ name: agentTokens.name })
      .from(agentTokens)
      .where(eq(agentTokens.id, actorId))
      .get();
    return row?.name ?? null;
  }
  return null;
}

/** The API shape of an audit row. */
export function toAuditEvent(row: AuditEventRow, actorName: string | null): AuditEvent {
  return {
    id: row.id,
    ts: row.ts,
    kind: row.kind,
    actorType: row.actorType,
    actorId: row.actorId,
    actorName,
    sessionId: row.sessionId,
    status: row.status,
    data: row.data,
  };
}

/**
 * Writes audit events and publishes each written or updated event on the bus at once. Inside a
 * database transaction, call write() after the commit, or the bus can announce a row that a
 * rollback removes.
 */
export class AuditWriter {
  readonly #db: Db;
  readonly #bus: EventBus;
  readonly #clock: Clock;

  constructor(deps: { db: Db; bus: EventBus; clock: Clock }) {
    this.#db = deps.db;
    this.#bus = deps.bus;
    this.#clock = deps.clock;
  }

  /** Inserts the event (ts = clock time), then publishes { type: 'audit' }. */
  write(input: AuditInput): AuditEvent {
    const row = this.#db
      .insert(auditEvents)
      .values({
        ts: this.#clock.now(),
        kind: input.kind,
        actorType: input.actorType,
        actorId: input.actorId,
        sessionId: input.sessionId,
        status: input.status ?? null,
        data: input.data,
      })
      .returning()
      .get();
    return this.#publish(row);
  }

  /**
   * Changes the status and merges `patch.data` into the stored data (top-level keys), for
   * example when the response of a pending `mcp.tool_call` arrives. Publishes the updated event.
   */
  update(
    id: number,
    patch: { status?: 'ok' | 'error'; data?: Record<string, unknown> },
  ): AuditEvent {
    const row = this.#db.transaction((tx) => {
      const current = tx.select().from(auditEvents).where(eq(auditEvents.id, id)).get();
      if (!current) throw new HydraError('not_found', `Audit event ${String(id)} not found`);
      return tx
        .update(auditEvents)
        .set({
          status: patch.status ?? current.status,
          data: patch.data ? { ...current.data, ...patch.data } : current.data,
        })
        .where(eq(auditEvents.id, id))
        .returning()
        .get();
    });
    return this.#publish(row);
  }

  #publish(row: AuditEventRow): AuditEvent {
    const event = toAuditEvent(row, actorNameOf(this.#db, row.actorType, row.actorId));
    this.#bus.publish({ type: 'audit', event });
    return event;
  }
}
```
