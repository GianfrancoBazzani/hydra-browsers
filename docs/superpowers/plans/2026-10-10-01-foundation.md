# Plan 01 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the pnpm workspace with exact toolchain pins, the four package skeletons, the repository check, the cluster version pins, Renovate, the base CI workflow, and the README, so that plans 02 to 10 start from a green `pnpm lint && pnpm typecheck && pnpm test`.

**Architecture:** One pnpm 12.9.0 workspace (`packages/*`). Node.js 24.21.0 is pinned in `.node-version`, `devEngines.runtime`, and `nodeVersion`. TypeScript is strict ESM. Internal packages export their source under the `@hydra/source` condition (tests, development) and `dist/` by default (production). `scripts/check-repo.ts` uses only Node.js built-ins, runs with the type stripping of Node.js 24 before `pnpm install`, and enforces spec section 3.4.7.

**Tech Stack:** pnpm 12.9.0, Node.js 24.21.0, TypeScript 6.0.3, Vitest 5.0.3 with Vite 8.3.2, ESLint 10.12.0 with typescript-eslint 8.71.0, Prettier 3.9.9, tsx 4.23.15, GitHub Actions, Renovate.

**Spec:** `docs/superpowers/specs/2026-10-10-hydra-browsers-design.md`, sections 3, 3.4 (all of it), and 15.4 (base CI). Also read `docs/superpowers/plans/2026-10-10-00-index.md` (sections 2 to 5) and `AGENTS.md`.

## Global Constraints

- Do not commit (AGENTS.md rule 1). Do not edit the spec (AGENTS.md rule 2). Each task ends with the Checkpoint step of index section 3.
- pnpm `12.9.0` in `packageManager`. Node.js `24.21.0` in `devEngines.runtime` (`"onFail": "download"`), in `nodeVersion` of `pnpm-workspace.yaml`, and in `.node-version`.
- Each version is exact. No `^`, `~`, `*`, `x`, `latest`, or other ranges in a `package.json`. The only exception is `workspace:*` for internal packages.
- Each container image reference has a tag and a digest: `name:tag@sha256:<digest>`. Our own images (`hydra-gateway`, `hydra-session`, `hydra-mcp`, `hydra-testsite`) get their digests from CI.
- Each GitHub Action uses a full 40-character commit SHA, with the version in a comment. Runners use `ubuntu-24.04`, never `ubuntu-latest`.
- Minimum release age: 7 days (`minimumReleaseAge: 10080`). A new pin is the newest release published on or before 2026-10-03, unless the spec fixes the version (see "Index issues" item 2 for the exceptions).
- No dependency from a git repository or a tarball URL. No install scripts, except for the `allowBuilds` entries, each with a reason comment.
- `pnpm-lock.yaml` is committed. CI installs with `--frozen-lockfile`.
- `@playwright/mcp` is exactly `0.0.83` (spec section 3.4.4).
- TypeScript strict ESM with the `tsconfig.base.json` options of index section 2.1. `scripts/*.ts` use erasable syntax only and run with `node scripts/<name>.ts`. `scripts/check-repo.ts` imports only `node:` modules.
- Prettier: `printWidth` 100, `singleQuote` true, `semi` true, `trailingComma` `all`.
- Do not run `npm` commands inside the repository. npm enforces `devEngines.runtime` and fails with `EBADDEVENGINES` unless the shell runs Node.js 24.21.0. Use `pnpm exec`, or run npm from a temporary folder.

## Review Focus

1. **CRLF line endings.** A workflow, Dockerfile, or manifest with CRLF line endings must not hide a violation from `check-repo.ts`. Test: Task 3, `describe('line endings')`.
2. **Multi-arch Dockerfiles.** `FROM --platform=$BUILDPLATFORM node:…@sha256:…` must pass, because the `$` is in a flag, not in the image name. Test: Task 3, the first test of `describe('container images')`.
3. **Old `dist/` folders.** After `pnpm build`, the tests must still load the TypeScript source, not the build output. Test: Task 2, Step 11 runs `pnpm test` while `dist/` exists.
4. **Allow-list entries for packages that are not installed yet.** pnpm prunes undecided `allowBuilds` entries. `better-sqlite3: true` (plan 02 installs better-sqlite3) must stay in `pnpm-workspace.yaml`. Test: Task 1, Step 12.
5. **Node.js updates by Renovate.** One Renovate pull request must change all Node.js pins (`.node-version`, `devEngines.runtime`, `nodeVersion`), else `check-repo.ts` fails CI. Test: Task 4, Step 7 (Renovate extract dry run).

## Spec deviations

1. **Distroless Node.js image (spec section 3.4.7, "the Dockerfile tags").** The tags of `gcr.io/distroless/nodejs24-debian12` are only `latest`, `nonroot`, `debug`, `debug-nonroot` (with architecture suffixes) and commit SHAs. They carry no Node.js version (registry tag list, 2026-10-10). Thus `check-repo.ts` compares the full version only for official `node:<version>…` tags, and compares only the major version (`nodejs24`) for distroless images. The digest pins the exact build. Plan 08 should check the Node.js version in the distroless image when it records the digest.
**Checked, no deviation: the place of the `install.sh` SHA-256 (spec section 3.4.5).** The spec says that `setup-k3s.sh` compares the SHA-256 "with a value in the script". Thus the value is in `scripts/setup-k3s.sh` (plan 08), not in `scripts/versions.sh`. When Renovate changes `K3S_VERSION`, `setup-k3s.sh` stops at the hash compare until a person reads the new `install.sh` and updates the value (README, section "Update k3s").

**Checked, no deviation: the settings of spec section 3.4.3 in pnpm 12.9.0.** pnpm 12 fails with `ERR_PNPM_UNRECOGNIZED_WORKSPACE_SETTINGS` when `pnpm-workspace.yaml` has a key that it does not know and the project pins the running pnpm version (pnpm 12.0.0 release notes). The exact file of the spec installs without an error, and Task 1 Step 12 repeats the proof with a misspelled key.

## Index issues

1. **Files that the ownership table (index section 4) does not list.** Plan 01 also creates: the root `tsconfig.json` (typechecks `scripts/**/*.ts` and all `vitest.config.ts` files with Node.js types); `.prettierignore` (keeps `pnpm-workspace.yaml` in the exact text of spec section 3.4.3, which Prettier would change to single quotes, and skips `pnpm-lock.yaml` and Markdown); `packages/server/src/workspace.test.ts` (the source-condition smoke test); and `packages/mcp-sidecar/src/index.test.ts` (the `@playwright/mcp` pin test). `packages/server/src/index.ts` is not only `export {}`: it also has `import '@hydra/shared';`, which the CI `build` job uses. Plan 02 can rewrite `packages/shared/src/index.ts` freely: the smoke test compares module identity and needs no export.
2. **"Newest version" rule (index section 2.3).** The newest TypeScript on or before 2026-10-03 is 7.0.2 (the native compiler, 2026-07-08). typescript-eslint 8.71.0, the newest, requires `typescript >=4.8.4 <6.1.0`, and TypeScript 7 has no compatible JavaScript API. Plan 01 pins TypeScript 6.0.3, the newest version that the toolchain supports. `@types/node` is 24.19.1 (the newest 24.x, for the Node.js 24 runtime), not 26.6.4 (the types of Node.js 26). Suggested rule: "the newest release published on or before 2026-10-03 that the other pins support".
3. **`vite` at the root.** Vitest 5.0.3 has a required peer dependency on `vite` (`^6.4.0 || ^7.0.0 || ^8.0.0`). The root pins `vite` 8.3.2, the newest on or before 2026-10-03. Plan 07 must use the same `vite` version in `@hydra/web`.
4. **Test layout.** The root `vitest.config.ts` runs the projects `packages/*/vitest.config.ts` and a `scripts` project. A package's tests run in `pnpm test` only if the package has a `vitest.config.ts`. Plan 07 keeps `packages/web/vitest.config.ts`. Plan 10's `@hydra/e2e` (Playwright) must not have one. Vite's `resolve.conditions` alone does not reach node-environment tests: node tests need `ssr.resolve.conditions`, jsdom tests need `resolve.conditions` (both verified, jsdom 30.1.1). `packages/web/vitest.config.ts` sets both; plan 07 keeps both lines when it switches to `jsdom`. `vitest run` in a package without test files fails ("No test files found"), so plans 02 and 07 add tests before they run `pnpm --filter <package> test`.
5. **ESLint for the dashboard.** Plan 07 cannot change the root `eslint.config.js`. ESLint 10 uses the config file nearest to each linted file (verified). Thus plan 07 adds `packages/web/eslint.config.js`, which spreads the root config and adds `eslint-plugin-react-hooks`, for example `export default defineConfig(root, reactHooksConfig)` with `import root from '../../eslint.config.js'`.
6. **Root scripts.** No later plan may change the root `package.json`. `pnpm dev` runs `pnpm --parallel --filter @hydra/server --filter @hydra/web run dev`. `pnpm e2e` runs `pnpm --filter @hydra/e2e --fail-if-no-match run test`. `pnpm build` runs `pnpm -r run build`. Thus: `@hydra/server` needs a `dev` script (plan 03), `@hydra/web` needs `dev` and `build` scripts (plan 07), and `@hydra/e2e` needs a `test` script (plan 10). The k3d part of spec section 11.7 (scale the in-cluster gateway to 0, `KUBECONFIG` of the k3d cluster, `HYDRA_SESSION_TRANSPORT=port-forward`, the other variables) has no owner. The index should give it to plan 08, for example as a script that the server `dev` script calls.
7. **`scripts/versions.sh` (no contract in section 5).** POSIX `sh` assignments, read with `. scripts/versions.sh`: `K3S_VERSION` (`v1.36.5+k3s1`), `K3S_IMAGE` (`rancher/k3s:v1.36.5-k3s1@sha256:…`), and `K3D_VERSION` (`v5.9.0`). `k3d version` prints `k3d version v5.9.0`. The SHA-256 of `install.sh` is not in this file: spec section 3.4.5 puts it in `setup-k3s.sh` (plan 08), and "Pinned versions" gives the verified value for `v1.36.5+k3s1`. Plan 08 can add variables. 8. **`check-repo.ts` rules for plans 08 to 10.** Each Dockerfile in the repository (also under `spikes/`): `FROM` names the image literally (no build argument) with a tag and a digest; each `pnpm@<version>` equals `packageManager`; official `node` tags start with the exact Node.js version (`node:24.21.0-slim`). 9. **`.gitignore`.** Spec section 3.4.4 says that `dev-cluster.sh` writes generated files into the `dev` overlay, which are not committed. Only plan 01 owns `.gitignore`. Plan 08 needs permission to add its generated paths.
10. **CI and builds.** `ci.yml` has the jobs `check-repo`, `audit`, `lint`, `typecheck`, `test`, and `build`. ## Behaviors seen in the dry run (2026-10-10, macOS arm64)

Know these before you start. They are normal:

- The installed pnpm 10.33.2 switches to pnpm 12.9.0 by itself (`packageManager`). The first command takes a few seconds longer.
- pnpm 12 downloads Node.js 24.21.0 into `node_modules/.bin/node` and runs the scripts of the project with it. `pnpm exec node --version` prints `v24.21.0`, also when the shell has another Node.js 24.
- `pnpm-lock.yaml` has two YAML documents: the first one pins pnpm 12.9.0 (`packageManagerDependencies`), the second one is the dependency lockfile with `node@runtime:24.21.0`.
- The first `pnpm install` stops with `ERR_PNPM_IGNORED_BUILDS` (esbuild only), but it still writes `pnpm-lock.yaml` and `node_modules`. pnpm does not change `pnpm-workspace.yaml`.
- TypeScript 6 no longer adds `@types/*` packages by itself: Node.js packages need `"types": ["node"]`.
- Prettier formats `package.json` files like `JSON.stringify` (each object on several lines).
- Some checks copy files into a folder from `mktemp -d`. Leave these folders: the system removes its temporary files, and an `rm -rf "$tmp"` can be refused by agent safety checks.

```ts
// Run: node scripts/check-repo.ts
// Node.js 24 runs this file with type stripping. Thus: erasable TypeScript syntax only, and only
// Node.js built-in modules, because CI runs the check before `pnpm install`.

import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';

export interface Problem {
  /** Path relative to the repository root, with "/" separators. */
  file: string;
  message: string;

export interface ImageRef {
  name: string;
  tag: string | null;
  digest: string | null;
}

/** Our own images. CI builds them and writes their digests into the overlays (spec section 3.4.4). */
export const OWN_IMAGES: ReadonlySet<string> = new Set([
  'hydra-gateway',
  'hydra-session',
  'hydra-mcp',
  'hydra-testsite',
]);

const SKIPPED_DIRS = new Set(['.git', 'node_modules', 'dist', 'coverage']);
const DEPENDENCY_FIELDS = [
  'dependencies',
  'devDependencies',
  'optionalDependencies',
  'peerDependencies',
] as const;
const EXACT_VERSION = /^\d+\.\d+\.\d+(?:-[0-9A-Za-z.-]+)?(?:\+[0-9A-Za-z.-]+)?$/;
const FULL_SHA = /^[0-9a-f]{40}$/;
const DIGEST = /^sha256:[0-9a-f]{64}$/;
const TAG = /^[A-Za-z0-9_][A-Za-z0-9_.-]{0,127}$/;
const DOCKERFILE = /(?:^|\/)(?:Dockerfile(?:\.[^/]+)?|[^/]+\.[Dd]ockerfile)$/;
const YAML = /\.ya?ml$/;
const IMAGE_FORMAT = 'an image needs a tag and a digest (name:tag@sha256:<digest>)';

/** All files below `root`, sorted, without .git, node_modules, dist, and coverage folders. */
export function listFiles(root: string): string[] {
  const files: string[] = [];
  const walk = (dir: string, prefix: string): void => {
    for (const entry of readdirSync(dir, { withFileTypes: true })) {
      if (entry.isDirectory() && !SKIPPED_DIRS.has(entry.name)) {
        walk(join(dir, entry.name), `${prefix}${entry.name}/`);
      } else if (entry.isFile()) {
        files.push(`${prefix}${entry.name}`);
      }
    }
  };
  walk(root, '');
  return files.sort();
}

/** Splits `registry/name:tag@sha256:digest`. A registry port is not a tag. */
export function parseImage(reference: string): ImageRef {
  let rest = reference;
  let digest: string | null = null;
  const at = rest.indexOf('@');
  if (at !== -1) {
    digest = rest.slice(at + 1);
    rest = rest.slice(0, at);
  }
  let tag: string | null = null;
  const colon = rest.lastIndexOf(':');
  if (colon > rest.lastIndexOf('/')) {
    tag = rest.slice(colon + 1);
    rest = rest.slice(0, colon);
  }
  return { name: rest, tag, digest };
}

/**
 * The entry point timeouts of a Traefik HelmChartConfig: each YAML key path or command-line flag
 * that contains "timeout" (any case), with its value.
 */
export function traefikTimeouts(text: string): Map<string, string> {
  const timeouts = new Map<string, string>();
  const parents: Array<{ indent: number; key: string }> = [];
  for (const rawLine of lines(text)) {
    const line = stripComment(rawLine);
    const trimmed = line.trim();
    if (trimmed === '') continue;
    const flag = /^-\s+["']?--([\w.-]+)=([^"']*)["']?$/.exec(trimmed);
    if (flag) {
      if (/timeout/i.test(flag[1]!)) timeouts.set(flag[1]!, flag[2]!);
      continue;
    }
    const entry = /^(?:-\s+)?([\w.-]+):(?:\s+(.*))?$/.exec(trimmed);
    if (!entry) continue;
    const indent = line.length - line.trimStart().length;
    while (parents.length > 0 && parents[parents.length - 1]!.indent >= indent) parents.pop();
    const key = entry[1]!;
    const value = unquote(entry[2] ?? '');
    if (value === '' || /^[|>][-+]?$/.test(value)) {
      parents.push({ indent, key });
      continue;
    }
    const path = [...parents.map((parent) => parent.key), key].join('.');
    if (/timeout/i.test(path)) timeouts.set(path, value);
  }
  return timeouts;
}

function checkPackageManifests(root: string, files: string[]): Problem[] {
  const problems: Problem[] = [];
  for (const file of files.filter((path) => /(?:^|\/)package\.json$/.test(path))) {
    const add = (message: string): void => {
      problems.push({ file, message });
    };
    const manifest = readJson(root, file);
    if (manifest === null) {
      add('is not valid JSON');
      continue;
    }
    for (const field of DEPENDENCY_FIELDS) {
      const dependencies = manifest[field];
      if (typeof dependencies !== 'object' || dependencies === null) continue;
      for (const [name, spec] of Object.entries(dependencies)) {
        if (!isExactSpec(spec)) add(`${field}.${name}: "${String(spec)}" is not an exact version`);
      }
    }
    const packageManager = manifest.packageManager;
    if (packageManager !== undefined && !/^pnpm@\d+\.\d+\.\d+$/.test(String(packageManager))) {
      add(`packageManager: "${String(packageManager)}" is not an exact pnpm version`);
    }
  }
  return problems;
}

function checkImages(root: string, files: string[]): Problem[] {
  const problems: Problem[] = [];
  for (const file of files) {
    const add = (message: string): void => {
      problems.push({ file, message });
    };
    if (DOCKERFILE.test(file)) {
      const stages = new Set<string>();
      for (const { image, stage } of fromLines(read(root, file))) {
        if (image.includes('$')) {
          add(`FROM ${image}: write the image name, not a build argument`);
        } else if (image !== 'scratch' && !stages.has(image.toLowerCase()) && !isPinned(image)) {
          add(`FROM ${image}: ${IMAGE_FORMAT}`);
        }
        if (stage !== null) stages.add(stage.toLowerCase());
      }
    } else if (YAML.test(file) && (file.startsWith('deploy/') || file.startsWith('.github/'))) {
      for (const line of lines(read(root, file))) {
        const match = /^\s*(?:-\s+)?image:\s*(.*)$/.exec(stripComment(line));
        const image = unquote(match?.[1] ?? '');
        if (image !== '' && !isPinned(image)) add(`image ${image}: ${IMAGE_FORMAT}`);
      }
    } else if (file === 'scripts/versions.sh') {
      for (const line of lines(read(root, file))) {
        const match = /^\s*(?:export\s+)?(\w*IMAGE\w*)=(.*)$/.exec(stripComment(line));
        const image = unquote(match?.[2] ?? '');
        if (match && !isPinned(image)) add(`${match[1]}=${image}: ${IMAGE_FORMAT}`);
      }
    }
  }
  return problems;
}

function checkWorkflows(root: string, files: string[]): Problem[] {
  const problems: Problem[] = [];
  for (const file of files.filter((path) => path.startsWith('.github/') && YAML.test(path))) {
    const add = (message: string): void => {
      problems.push({ file, message });
    };
    for (const line of lines(read(root, file))) {
      const uses = /^\s*(?:-\s+)?uses:\s*(\S+)(.*)$/.exec(line);
      if (uses) {
        const target = unquote(uses[1]!);
        const ref = target.includes('@') ? target.slice(target.lastIndexOf('@') + 1) : '';
        if (target.startsWith('./')) {
          // A local action of this repository.
        } else if (target.startsWith('docker://')) {
          if (!isPinned(target.slice('docker://'.length))) add(`uses ${target}: ${IMAGE_FORMAT}`);
        } else if (!FULL_SHA.test(ref)) {
          add(`uses ${target}: pin a full 40-character commit SHA`);
        } else if (!/#\s*\S/.test(uses[2]!)) {
          add(`uses ${target}: add the version in a comment (# vX.Y.Z)`);
        }
      }
      const latest = /\b(?:ubuntu|macos|windows)-latest\b/.exec(stripComment(line));
      if (latest) add(`runner "${latest[0]}": use a fixed image such as ubuntu-24.04`);
    }
  }
  return problems;
}

    problems.push({ file, message });
  };
  const differs = (value: string | undefined): string =>
    `${value === undefined ? 'is missing' : `is "${value}"`}, but .node-version is "${expected}"`;

  const runtime = devEnginesRuntime(readJson(root, 'package.json'));
  if (runtime !== expected) add('package.json', `devEngines.runtime.version ${differs(runtime)}`);

  const workspace = readOptional(root, 'pnpm-workspace.yaml') ?? '';
  const nodeVersion = /^nodeVersion:\s*["']?([^"'\s#]+)/m.exec(workspace)?.[1];
  if (nodeVersion !== expected) add('pnpm-workspace.yaml', `nodeVersion ${differs(nodeVersion)}`);

  for (const file of files.filter((path) => DOCKERFILE.test(path))) {
    for (const { image } of fromLines(read(root, file))) {
      const found = nodeVersionOfImage(image);
      if (found === null) continue;
      const wanted = found.majorOnly ? expected.split('.')[0] : expected;
      if (found.version !== wanted) {
        add(file, `FROM ${image}: Node.js ${found.version}, but .node-version is "${expected}"`);
      }
    }
  }
  return problems;
}

function checkPnpmVersions(root: string, files: string[]): Problem[] {
  const packageManager = String(readJson(root, 'package.json')?.packageManager ?? '');
  const problems: Problem[] = [];
  for (const file of files.filter((path) => DOCKERFILE.test(path))) {
    for (const [pinned] of read(root, file).matchAll(/\bpnpm@[^\s"'`\\]+/g)) {
      if (pinned === packageManager) continue;
      problems.push({ file, message: `${pinned}, but packageManager is "${packageManager}"` });
    }
  }
  return problems;
}

function checkTraefikTimeouts(root: string, files: string[]): Problem[] {
  const hasProd = files.includes(TRAEFIK_PROD);
  const hasDev = files.includes(TRAEFIK_DEV);
  if (!hasProd && !hasDev) return []; // plan 08 creates both files
  if (!hasProd || !hasDev) {
    const [missing, present] = hasProd ? [TRAEFIK_DEV, TRAEFIK_PROD] : [TRAEFIK_PROD, TRAEFIK_DEV];
    const message = `is missing, but ${present} exists (both set the entry point timeouts)`;
    return [{ file: missing, message }];
  }
  const prod = traefikTimeouts(read(root, TRAEFIK_PROD));
  const dev = traefikTimeouts(read(root, TRAEFIK_DEV));
  const problems: Problem[] = [];
  const add = (file: string, message: string): void => {
    problems.push({ file, message });
  };
  if (prod.size === 0) add(TRAEFIK_PROD, 'sets no entry point timeouts');
  if (dev.size === 0) add(TRAEFIK_DEV, 'sets no entry point timeouts');
  for (const key of [...new Set([...prod.keys(), ...dev.keys()])].sort()) {
    const devValue = dev.get(key);
    const prodValue = prod.get(key);
    if (devValue === prodValue) continue;
    const devText = devValue === undefined ? 'is not set' : `is "${devValue}"`;
    const prodText = prodValue === undefined ? 'does not set it' : `has "${prodValue}"`;
    add(TRAEFIK_DEV, `timeout ${key} ${devText}, but ${TRAEFIK_PROD} ${prodText}`);
  }
  return problems;
}

function isExactSpec(spec: unknown): boolean {
  return typeof spec === 'string' && (EXACT_VERSION.test(spec) || spec === 'workspace:*');
}

/** True for `name:tag@sha256:<digest>`, and for our own images (CI gives their digests). */
function isPinned(image: string): boolean {
  const { name, tag, digest } = parseImage(image);
  if (OWN_IMAGES.has(name.slice(name.lastIndexOf('/') + 1))) return true;
  return tag !== null && TAG.test(tag) && digest !== null && DIGEST.test(digest);
}

/**
 * The Node.js version in the tag of an official `node` image ("24.21.0" from `node:24.21.0-slim`),
 * or the major version of a distroless Node.js image ("24" from `distroless/nodejs24-debian12`,
 * whose tags carry no Node.js version). Null for other images.
 */
function nodeVersionOfImage(image: string): { version: string; majorOnly: boolean } | null {
  const { name, tag } = parseImage(image);
  if (/^(?:(?:docker\.io\/)?library\/)?node$/.test(name) && tag !== null) {
    return { version: /^\d+\.\d+\.\d+/.exec(tag)?.[0] ?? tag, majorOnly: false };
  }
  const major = /(?:^|\/)distroless\/nodejs(\d+)(?:-|$)/.exec(name)?.[1];
  return major === undefined ? null : { version: major, majorOnly: true };
}

function fromLines(text: string): Array<{ image: string; stage: string | null }> {
  const result: Array<{ image: string; stage: string | null }> = [];
  for (const line of lines(text)) {
    const match = /^\s*FROM\s+(.+)$/i.exec(line);
    if (!match) continue;
    const words = match[1]!.split(/\s+/).filter((word) => word !== '' && !word.startsWith('--'));
    const stage = words[1]?.toLowerCase() === 'as' ? (words[2] ?? null) : null;
    result.push({ image: words[0] ?? '', stage });
  }
  return result;
}

function devEnginesRuntime(manifest: Record<string, unknown> | null): string | undefined {
  const devEngines = manifest?.devEngines as { runtime?: { version?: unknown } } | undefined;
  const version = devEngines?.runtime?.version;
  return typeof version === 'string' ? version : undefined;
}

/** The lines of a file, for LF and CRLF line endings. */
function lines(text: string): string[] {
  return text.split(/\r?\n/);
}

/** Removes a YAML or shell comment (a "#" at the start or after a space, outside quotes). */
function stripComment(line: string): string {
  let quote: string | null = null;
  for (let index = 0; index < line.length; index++) {
    const char = line[index]!;
    if (quote !== null) {
      if (char === quote) quote = null;
    } else if (char === '"' || char === "'") {
      quote = char;
    } else if (char === '#' && (index === 0 || /\s/.test(line[index - 1]!))) {
      return line.slice(0, index);
    }
  }
  return line;
}

function unquote(value: string): string {
  const trimmed = value.trim();
  const quoted = /^(["'])(.*)\1$/.exec(trimmed);
  return quoted ? quoted[2]! : trimmed;
}

function read(root: string, file: string): string {
  return readFileSync(join(root, file), 'utf8');
}

function readOptional(root: string, file: string): string | null {
  try {
    return read(root, file);
  } catch {
    return null;
  }
}

function readJson(root: string, file: string): Record<string, unknown> | null {
  try {
    const value: unknown = JSON.parse(read(root, file));
    return typeof value === 'object' && value !== null ? (value as Record<string, unknown>) : null;
  } catch {
    return null;
  }
}

function main(): void {
  const problems = checkRepo(join(import.meta.dirname, '..'));
  for (const problem of problems) console.error(`${problem.file}: ${problem.message}`);
  if (problems.length > 0) {
    console.error(`check-repo: ${problems.length} problem(s)`);
    process.exitCode = 1;
  } else {
    console.log('check-repo: OK');
  }
}

if (import.meta.main) main();
```

````markdown
## Reproduce the build on another system

One commit gives the same toolchain, dependency tree, images, and cluster software on each system
(spec section 3.4).

1. Check out the commit.
2. Install pnpm 10 or newer, for example `npm install -g pnpm@12.9.0`. In this folder, pnpm switches
   to the pnpm version of `packageManager`. `pnpm-lock.yaml` records the integrity of that pnpm
   version.
3. Use Node.js 24.21.0 (`.node-version`).
4. Run `pnpm install --frozen-lockfile`. pnpm installs the exact dependency tree of
   `pnpm-lock.yaml` and fails if a `package.json` does not match the lockfile. It checks each package
   against its integrity hash, checks the lockfile again against `minimumReleaseAge` and
   `trustPolicy`, and runs install scripts only for the `allowBuilds` entries that are `true`.
5. Run `node scripts/check-repo.ts`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`.
   These are the CI jobs (`.github/workflows/ci.yml`, runner `ubuntu-24.04`).
6. Cluster software comes from `scripts/versions.sh`: the k3s version, the `rancher/k3s` image with
   its digest, and the k3d version. `scripts/setup-k3s.sh` holds the SHA-256 of the k3s
   `install.sh`. Container images always have a tag and a digest.

### Install k3d

Download the k3d binary of `K3D_VERSION` and check it against the `checksums.txt` of the same
release. Example for macOS on Apple silicon (for Linux, use `k3d-linux-amd64`):

```sh
. scripts/versions.sh
curl -fsSLO "https://github.com/k3d-io/k3d/releases/download/${K3D_VERSION}/k3d-darwin-arm64"
curl -fsSL "https://github.com/k3d-io/k3d/releases/download/${K3D_VERSION}/checksums.txt" -o k3d-checksums.txt
echo "$(grep '/k3d-darwin-arm64$' k3d-checksums.txt | cut -d' ' -f1)  k3d-darwin-arm64" | shasum -a 256 -c -
chmod +x k3d-darwin-arm64 && sudo mv k3d-darwin-arm64 /usr/local/bin/k3d && rm k3d-checksums.txt
k3d version
```

## Dependency rules

Spec section 3.4 is the full policy. In short:

- **Exact versions only.** No ranges in a `package.json` (only `workspace:*` for internal packages),
  a tag and a digest for each image, a full commit SHA for each GitHub Action. `check-repo.ts`
  enforces these rules in CI.
- **7-day minimum release age.** pnpm refuses a version younger than 7 days
  (`minimumReleaseAge: 10080`), also in an existing lockfile. Add a dependency with an exact
  version, for example `pnpm --filter @hydra/server add <name>@<version>`.
- **Install scripts.** When a new dependency has an install script, `pnpm install` stops with
  `ERR_PNPM_IGNORED_BUILDS`. Read the script, then add an `allowBuilds` entry to
  `pnpm-workspace.yaml` with a comment that gives the reason: `true` only if the package needs the
  script, else `false`.
- **Urgent security fix younger than 7 days:** add the exact version to `minimumReleaseAgeExclude`
  with a comment that gives the date, the reason, and the advisory ID.
  `minimumReleaseAgeExcludePrune` removes the entry when the lockfile no longer uses that version.
- **Trust policy exception:** add the exact version to `trustPolicyExclude` with a reason comment.
- **`overrides`:** exact versions only, each with a reason comment.
- **Updates:** Renovate opens the update pull requests (`renovate.json`). Each one must pass all
  CI jobs. Before you change the Neko, Playwright MCP, or k3s version, read the release notes.

### Update k3s

A k3s update changes three values together: `K3S_VERSION` and `K3S_IMAGE` in
`scripts/versions.sh`, and the SHA-256 of `install.sh` in `scripts/setup-k3s.sh`. Renovate updates
`K3S_VERSION` and `K3S_IMAGE` in one pull request. A person reads the new `install.sh` and updates
its SHA-256. Until then, `setup-k3s.sh` stops at the hash compare.

```sh
# 1. The SHA-256 of install.sh of the new release tag (K3S_VERSION, for example v1.36.5+k3s1):
curl -fsSL "https://raw.githubusercontent.com/k3s-io/k3s/v1.36.5+k3s1/install.sh" | shasum -a 256

# 2. The digest of the multi-arch image (the tag uses "-" instead of "+"):
TOKEN=$(curl -fsSL "https://auth.docker.io/token?service=registry.docker.io&scope=repository:rancher/k3s:pull" \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["token"])')
curl -fsSI -H "Authorization: Bearer $TOKEN" \
  -H "Accept: application/vnd.oci.image.index.v1+json" \
  -H "Accept: application/vnd.docker.distribution.manifest.list.v2+json" \
  "https://registry-1.docker.io/v2/rancher/k3s/manifests/v1.36.5-k3s1" | grep -i docker-content-digest
```
````
