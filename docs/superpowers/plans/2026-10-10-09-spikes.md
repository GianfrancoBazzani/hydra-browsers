# Spikes S1 to S6 Implementation Plan (plan 09)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer the six spike questions of spec section 16 with reproducible runs on k3d and on the EC2 target host, write one result document per spike, and apply each result (or the fallback that the spec defines) to the spike-dependent files of index section 6.

**Architecture:** A bash and TypeScript harness under `spikes/` creates its own k3d cluster `hydra-spike` with the k3s pins of `scripts/versions.sh`. It runs Neko test pods that follow spec section 7.4 for the `neko` container (no `mcp` sidecar, `emptyDir` profile, fixed spike passwords), from the Neko base image that `deploy/session/Dockerfile.session` pins. One script per spike prints Markdown tables; each spike task copies them into `docs/superpowers/spikes/S<n>-<topic>.md`. Result tasks change the files of index section 6 with tests. A target-host task repeats S1 and S6 on the EC2 host, because k3d on macOS runs on the Docker Desktop Linux VM (no AppArmor, other kernel).

**Tech Stack:** bash (3.2 on macOS, 5 on Linux), kubectl 1.34, k3d `v5.9.0` and k3s `v1.36.5+k3s1` (from `scripts/versions.sh`), Docker Desktop, Node.js 24 built-ins only (`fetch`, `WebSocket`, `http`, type stripping for `.mts`), `jq`, Google Chrome (headless, S2 only), `busybox` httpd, Vitest (result tasks).

**Spec:** `docs/superpowers/specs/2026-10-10-hydra-browsers-design.md` (sections 16, 6.7, 7.4, 7.5, 7.7, 7.10, 8.7, 9.2, 11.4, 11.6). Index: `docs/superpowers/plans/2026-10-10-00-index.md` (sections 3, 4, 6, 7).

## Review Focus

1. **The k3d result does not hold on the EC2 host.** On Ubuntu 23.10 and later, `kernel.apparmor_restrict_unprivileged_userns` can stop the user namespaces of the Chromium sandbox; with the sandbox on, Chromium would crash in every session. Pinned by Task 13 (records the sysctls, the AppArmor label, and the sandbox state on the host) and the gate in Task 14 Step 4.
2. **The seccomp profile file is missing on a node** (host prepared before the file existed, or a dev cluster created before). Pods then fail at container creation. Pinned by the `missing-profile` variant of Task 3 Step 5, which records the waiting reason (expected `CreateContainerError`; spec 7.9 rule 3 does not list it, so the 120 s rule applies).
3. **Display names with URL-reserved characters and Unicode** in the rewritten `username` value. Pinned by Task 4: the proxy sets `Zoë & Co = 1/2` and `Viewer Ünïcode`, and the checks compare the member list with these exact names.
4. **Several viewers of one session at the same time.** Pinned by Task 6 step D (two viewers at once with the multiuser provider) and by `spikes/s3/object.sh` in Task 7 (the limit of the `object` provider).
5. **A redirect from an allowed to a blocked host, and the exact-host form `.example.com`.** Pinned by Task 8: check N3 (redirect) and run 2 (N1 and N5 with `.allowed.hydra.test`).

## Spec deviations

1. **Spec updates after a spike (spec 16).** Spec 16 says to update the spec when a result changes it. AGENTS.md rule 2 forbids agent edits of the spec. The plan writes the results to `docs/superpowers/spikes/` and lists the spec text that the user must change (section "Follow-up" of each result document, and Task 16).
2. **S4, `pathPattern` value (spec 5.2), expected.** `rancher/local-path-provisioner:v0.0.37` (bundled in k3s v1.34 to v1.37) requires the rendered path to start with `<namespace>/<pvc name>/` (trailing slash), unless `allowUnsafePathPattern: "true"` (`provisioner.go`, `pathFromPattern`). The literal value `{{ .PVC.Namespace }}/{{ .PVC.Name }}` does not have the slash, so the PVC stays `Pending`. `{{ .PVC.Namespace }}/{{ .PVC.Name }}/` gives the same folders. Plan 08 already writes the value with the slash (its spec deviation 2), so Task 11 is expected to confirm decision row 1; Task 12 changes the value only if the file lacks the slash, and only after the user approves.
3. **S2 fallback, only if Task 4 fails.** With Neko 3.1.6, `serverLogin` (spec 9.2 step 5) needs `NEKO_SESSION_COOKIE_ENABLED=true` (not in the env table of spec 7.4): the legacy `/ws` handler accepts a token only as the `NEKO_SESSION` cookie, checked with `GET /api/whoami`. The handler also logs the Neko session out when the WebSocket closes, so the gateway must log in again for each WebSocket upgrade instead of keeping one token for the life of the grant. The HTTP requests of the legacy client (static files, `api/oauth/config`) need no Neko token, so the gateway adds the cookie only to WebSocket upgrades (spec 9.2 step 5 says "each request and WebSocket upgrade"). Task 5 asks the user first.
4. **S3 fallback, only if Task 6 fails.** The `object` provider uses the user name as the Neko session ID, and a second login while the first is connected fails (`session already connected`). Thus only one person per Neko profile can watch at a time, which is a larger limit than spec 6.7 states. Task 7 asks the user first.
5. **`service-node-port-range` of spec 11.6 and 11.7.** `30000-32767,<HYDRA_MEDIA_PORT_RANGE>` is not a valid value: kube-apiserver and k3s parse one range only (`k8s.io/apimachinery` `PortRange.Set` fails on the comma), so k3s does not start. The harness uses the k3s default range and no media NodePorts. Plan 08 records the problem and uses one range `30000-52099` pending a user decision; with that range, the kube-router NodePort exemption of S6 covers 30000 to 52099. Task 16 reports it to the user.
6. **S5, expected.** Chromium 150 (Debian trixie) does not block `chrome://` pages with `URLBlocklist: ["*"]` (feature `kBypassURLBlocklistWildcardForInternalChromeUrls`, enabled by default). Spec 7.5 implies that `["*"]` blocks everything outside the allowlist. No policy change unless the user wants `chrome://` pages blocked.
7. **S5, expected.** "Start from the Neko default policies" (spec 7.5) keeps the Neko `ExtensionInstallForcelist`, which installs two extensions, but the same table says "No extensions". If S5 shows the installed extensions, Task 9 removes `ExtensionInstallForcelist` and `ExtensionInstallAllowlist` (the S5 fallback permits "adjust the base policy") and tells the user. Plan 04 records the same open point (its note 8).

## Index issues

1. **`scripts/versions.sh` names.** Index section 5 has no contract for them. Plan 01 Task 4 defines `K3S_VERSION` (`v1.36.5+k3s1`), `K3S_IMAGE` (`rancher/k3s:v1.36.5-k3s1@sha256:057cfd5a…`), `K3S_INSTALL_SHA256`, and `K3D_VERSION` (`v5.9.0`). The harness uses `K3S_VERSION`, `K3S_IMAGE`, and `K3D_VERSION`. Proposed: add these names to section 5.
2. **Module paths.** The result tests import `buildSessionObjects` from `packages/server/src/orchestrator/manifests/index.ts` (plan 04 file table), `deriveSubkeys` from `src/crypto/index.ts` (plan 02), `SessionRow` from `src/db/schema.ts`, and `testConfig` from `test/helpers/config.ts`. Section 5 names the exports, not the files. Proposed: say that each module exports its public interface from `src/<module>/index.ts`.
3. **File ownership (section 4).** Plan 09 also creates test files next to the files of section 6: `orchestrator/manifests/{statefulset.s1,neko-env.s3,neko-env.s2,policies.s5}.test.ts`, `live-proxy/neko-login.s2.test.ts`, `live-proxy/neko-login.s3.test.ts`, and, for the S5 help text, `packages/web/src/lib/allowlist-help.ts` with its test. It modifies the two web files that show the allowlist field, the plan 04 policy test `keeps the other Neko defaults unchanged` if Task 9 removes the extension keys, and existing tests or snapshots of plans 04 and 06 that assert a value that a result task changes (Tasks 5, 6, 7, 9, 14). Proposed: add these to the row of plan 09.
4. **Section 6, S1.** Plan 09 changes the capabilities in `statefulset.ts` also when the sandbox fails: spec 7.4 makes the capability set an S1 result in all cases, not a fallback.
5. **Section 6, S2.** The `serverLogin` fallback also changes `orchestrator/manifests/neko-env.ts` (`NEKO_SESSION_COOKIE_ENABLED=true`), which section 6 lists only for S3.
6. **Section 6, S4.** The spec fallback ("static PVs … created by the setup script and the orchestrator") needs orchestrator code that creates PersistentVolumes (cluster-scoped, so a ClusterRole, which spec 11.2 forbids) and a `dev-cluster.sh` change. Section 6 lists only `storageclasses.yaml` and `setup-k3s.sh`. Task 12 stops and asks.
7. **Section 6, S6.** A host firewall in `setup-k3s.sh` cannot tell session pods from system pods on port 6443: every pod reaches the API server on the node address after the DNAT of the `kubernetes` Service. Task 15 stops and asks with a proposal.
8. **Lint of the harness.** Plan 01's ESLint config (`js.configs.recommended`, `tseslint.configs.recommended`) has no Node globals, so `.mjs` files would fail `no-undef`. Plan 09 uses `.mts`. Prettier checks the `.mts`, `.json`, `.html`, and `.yaml` files under `spikes/` (Markdown is in `.prettierignore`).
9. **Section 1 note.** "Plan 09 touches only its own files" is true only for Tasks 1 to 4, 8, 10, 11, and 13: the result tasks change files of section 6.
10. **Plan 06 `serverLogin` notes.** The comment of plan 06 in `neko-login.ts` says that `serverLogin` keeps the token per grant and sends the cookie with each HTTP request and upgrade. In Neko 3.1.6 the legacy handler logs the session out when the WebSocket closes (`server/internal/http/legacy/session.go`, `destroy()`), so a kept token fails at the next upgrade. Task 5 logs in for each upgrade and sends no cookie on HTTP requests; it uses the `NekoLoginStrategy` interface of plan 06 unchanged.

```bash
#!/usr/bin/env bash
# Spike S1: report the Chromium sandbox state of a running Neko pod, read from /proc.
# A sandboxed renderer runs in a nested PID namespace (2 values in NSpid) and has its own
# seccomp-bpf filter on top of the container filter (Seccomp_filters >= 2).
# Usage: spikes/lib/sandbox-status.sh [pod] [namespace]
. "$(dirname "$0")/common.sh"
pod="${1:-neko}"
ns="${2:-$SPIKE_NS}"

kubectl -n "$ns" exec "$pod" -c neko -- sh -c '
browser=""
renderers=0
sandboxed=0
for p in /proc/[0-9]*; do
  cmd=$(tr "\000" " " 2>/dev/null < "$p/cmdline") || continue
  case "$cmd" in
    /usr/lib/chromium/chromium\ *--type=renderer*)
      renderers=$((renderers + 1))
      levels=$(awk "/^NSpid:/ {print NF - 1}" "$p/status")
      filters=$(awk "/^Seccomp_filters:/ {print \$2}" "$p/status")
      echo "renderer pid=${p#/proc/} pid_namespace_levels=$levels seccomp_filters=${filters:-unknown}"
      if [ "$levels" -ge 2 ] && [ "${filters:-0}" -ge 2 ]; then sandboxed=$((sandboxed + 1)); fi
      ;;
    /usr/lib/chromium/chromium\ *--type=*) ;;
    /usr/lib/chromium/chromium\ *) browser="$cmd" ;;
  esac
done
case "$browser" in
  "") echo "browser process: not found" ;;
  *--no-sandbox*) echo "browser process: --no-sandbox present" ;;
  *) echo "browser process: --no-sandbox absent" ;;
esac
echo "renderers=$renderers sandboxed_renderers=$sandboxed"
if [ "$renderers" -gt 0 ] && [ "$sandboxed" -eq "$renderers" ]; then echo "SANDBOX=on"; else echo "SANDBOX=off"; fi
'
```

`spikes/lib/cdp.mts`:

```ts
// Minimal Chrome DevTools Protocol client for the spike scripts (Node.js 24 built-ins only).
// Node's WebSocket sends no Origin header, so Chromium accepts it without --remote-allow-origins.

export const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

// Returns the browser WebSocket URL, with the host and port of httpBase (for port-forwards).
export async function browserWsUrl(httpBase) {
  const res = await fetch(new URL('/json/version', httpBase));
  if (!res.ok) throw new Error(`GET /json/version: HTTP ${res.status}`);
  const { webSocketDebuggerUrl } = await res.json();
  const url = new URL(webSocketDebuggerUrl);
  url.host = new URL(httpBase).host;
  return url.href;
}

export async function connect(wsUrl) {
  const ws = new WebSocket(wsUrl);
  await new Promise((resolve, reject) => {
    ws.onopen = resolve;
    ws.onerror = () => reject(new Error(`CDP connection to ${wsUrl} failed`));
  });
  let nextId = 1;
  const pending = new Map();
  const listeners = new Set();
  ws.onmessage = (event) => {
    const msg = JSON.parse(event.data);
    if (msg.id !== undefined && pending.has(msg.id)) {
      const { resolve, reject } = pending.get(msg.id);
      pending.delete(msg.id);
      if (msg.error) reject(new Error(msg.error.message));
      else resolve(msg.result);
      return;
    }
    for (const listener of listeners) listener(msg);
  };
  return {
    send(method, params = {}, sessionId = undefined) {
      const id = nextId++;
      ws.send(JSON.stringify({ id, method, params, sessionId }));
      return new Promise((resolve, reject) => pending.set(id, { resolve, reject }));
    },
    on(listener) {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },
    close() {
      ws.close();
    },
  };
}

// Opens a new tab with about:blank and attaches to it. Returns the CDP session ID of the tab.
export async function openPage(cdp) {
  const { targetId } = await cdp.send('Target.createTarget', { url: 'about:blank' });
  const { sessionId } = await cdp.send('Target.attachToTarget', { targetId, flatten: true });
  await cdp.send('Page.enable', {}, sessionId);
  await cdp.send('Runtime.enable', {}, sessionId);
  return { targetId, sessionId };
}

export async function evaluate(cdp, sessionId, expression) {
  const res = await cdp.send(
    'Runtime.evaluate',
    { expression, awaitPromise: true, returnByValue: true },
    sessionId,
  );
  if (res.exceptionDetails) {
    throw new Error(res.exceptionDetails.exception?.description ?? res.exceptionDetails.text);
  }
  return res.result.value;
}

// Navigates like Playwright MCP browser_navigate (a browser-initiated navigation).
// Returns the CDP error text ('' if none) and the URL of the document after settleMs.
export async function navigate(cdp, sessionId, url, settleMs = 2000) {
  let errorText = '';
  try {
    const res = await cdp.send('Page.navigate', { url }, sessionId);
    errorText = res.errorText ?? '';
  } catch (err) {
    errorText = `CDP error: ${err.message}`;
  }
  await sleep(settleMs);
  let finalUrl = '';
  try {
    finalUrl = await evaluate(cdp, sessionId, 'location.href');
  } catch (err) {
    finalUrl = `(evaluate failed: ${err.message})`;
  }
  return { errorText, finalUrl };
}
```

```bash
#!/usr/bin/env bash
# k3d cluster for the spikes (plan 09), with the k3s pins of scripts/versions.sh.
# - The named Docker volume hydra-spike-state is HYDRA_STATE_DIR (/var/lib/hydra) of the node.
#   "down" keeps it, so that spike S4 can test a new k3s installation on the same volume.
# - $SPIKE_STATE/seccomp is the kubelet seccomp folder hydra/ (spike S1).
# - No Traefik and no load balancer; the spikes do not need them.
# Usage: spikes/cluster.sh up | down | purge
. "$(dirname "$0")/lib/common.sh"

case "${1:-}" in
  up)
    command -v k3d >/dev/null || die "k3d is not installed"
    installed="$(k3d version | awk '/^k3d version/ {print $3}')"
    [ "$installed" = "$K3D_VERSION" ] || die "k3d $installed is installed; scripts/versions.sh pins $K3D_VERSION"
    if k3d cluster get "$SPIKE_CLUSTER" >/dev/null 2>&1; then
      die "cluster $SPIKE_CLUSTER exists; run: spikes/cluster.sh down"
    fi
    mkdir -p "$SPIKE_SECCOMP_DIR"
    docker volume create hydra-spike-state >/dev/null
    k3d cluster create "$SPIKE_CLUSTER" \
      --image "$K3S_IMAGE" \
      --servers 1 --agents 0 --no-lb \
      --kubeconfig-update-default=false \
      --k3s-arg "--disable=traefik@server:0" \
      --k3s-arg "--default-local-storage-path=/var/lib/hydra/volumes@server:0" \
      --volume "hydra-spike-state:/var/lib/hydra@server:0" \
      --volume "$SPIKE_SECCOMP_DIR:/var/lib/kubelet/seccomp/hydra@server:0" \
      --wait --timeout 300s
    k3d kubeconfig get "$SPIKE_CLUSTER" >"$KUBECONFIG"
    chmod 600 "$KUBECONFIG"
    kubectl wait --for=condition=Ready node --all --timeout=180s
    kubectl get nodes -o wide
    ;;
  down)
    k3d cluster delete "$SPIKE_CLUSTER"
    ;;
  purge)
    k3d cluster delete "$SPIKE_CLUSTER" || true
    docker volume rm hydra-spike-state >/dev/null 2>&1 || true
    rm -rf "$SPIKE_STATE"
    ;;
  *)
    die "usage: spikes/cluster.sh up | down | purge"
    ;;
esac
```

- [ ] **Step 1: Write `spikes/s1/gen-seccomp.mts`**

```ts
// Spike S1: generate the Chromium seccomp profile (OCI runtime-spec format, which containerd reads
// for localhostProfile) from the containerd default profile of the pinned k3s version.
// Result: the RuntimeDefault profile of a container without CAP_SYS_ADMIN, plus "clone" without the
// namespace-flag filter, "unshare", and "chroot". These are the calls of the Chromium namespace
// sandbox (sandbox/linux/services/credentials.cc and namespace_sandbox.cc).
// Usage: node spikes/s1/gen-seccomp.mts <k3s version, for example v1.36.5+k3s1> > <file>
import { createHash } from 'node:crypto';

// Fingerprint of seccomp_default.go without its syscall-name lines. This script encodes that
// structure (socket, personality, ptrace, arch, and clone rules). Both k3s-io/containerd
// v2.2.7-k3s1 (k3s v1.34, v1.35) and v2.3.4-k3s1 (k3s v1.36, v1.37) have this fingerprint.
const KNOWN_STRUCTURE = '7ce0dbcb29b1bd01e21d2dfac2f257aae67cc021bfac4a17990ee77eb75a4eff';

const k3sVersion = process.argv[2];
if (!k3sVersion) {
  console.error('usage: node spikes/s1/gen-seccomp.mts <k3s version>');
  process.exit(2);
}

async function text(url) {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`GET ${url}: HTTP ${res.status}`);
  return res.text();
}

const goMod = await text(
  `https://raw.githubusercontent.com/k3s-io/k3s/${encodeURIComponent(k3sVersion)}/go.mod`,
);
const replace = goMod.match(
  /github\.com\/containerd\/containerd\/v2 => github\.com\/k3s-io\/containerd\/v2 (\S+)/,
);
if (!replace) throw new Error('k3s go.mod has no replace directive for containerd/v2');
const containerdVersion = replace[1];
const source = await text(
  `https://raw.githubusercontent.com/k3s-io/containerd/${containerdVersion}/contrib/seccomp/seccomp_default.go`,
);

const nameLine = /^\s*"([a-z0-9_]+)",\s*(\/\/.*)?$/;
const lines = source.split('\n');
const fingerprint = createHash('sha256')
  .update(lines.filter((line) => !nameLine.test(line)).join('\n'))
  .digest('hex');
if (fingerprint !== KNOWN_STRUCTURE) {
  console.error(
    `containerd ${containerdVersion}: unknown profile structure ${fingerprint}. ` +
      'Read contrib/seccomp/seccomp_default.go and update this script.',
  );
  process.exit(1);
}

// The first name list in DefaultProfile is the unconditional allow list.
const start = lines.findIndex((line) => line.includes('syscalls := []specs.LinuxSyscall{'));
const names = [];
for (let i = start + 1; i < lines.length; i++) {
  if (/^\s*\},\s*$/.test(lines[i])) break;
  const match = lines[i].match(nameLine);
  if (match) names.push(match[1]);
}

// Output formatted like Prettier (printWidth 100) so that "prettier --check" accepts the file.
const list = (items, indent) => {
  const inline = `${indent}"names": [${items.map((n) => `"${n}"`).join(', ')}],`;
  if (inline.length <= 100) return [inline];
  return [
    `${indent}"names": [`,
    ...items.map((n, i) => `${indent}  "${n}"${i < items.length - 1 ? ',' : ''}`),
    `${indent}],`,
  ];
};
const allow = (items, args) => [
  '{',
  ...list(items, '      '),
  args ? '      "action": "SCMP_ACT_ALLOW",' : '      "action": "SCMP_ACT_ALLOW"',
  ...(args ? [`      "args": [${args}]`] : []),
  '}',
];
const entries = [
  allow(names),
  // socket(2) for all families except AF_ALG (38) and AF_VSOCK (40), as in containerd.
  allow(['socket'], '{ "index": 0, "value": 38, "op": "SCMP_CMP_LT" }'),
  allow(['socket'], '{ "index": 0, "value": 39, "op": "SCMP_CMP_EQ" }'),
  allow(['socket'], '{ "index": 0, "value": 40, "op": "SCMP_CMP_GT" }'),
  ...[0, 8, 131072, 131080, 4294967295].map((value) =>
    allow(['personality'], `{ "index": 0, "value": ${value}, "op": "SCMP_CMP_EQ" }`),
  ),
  // Kernel 4.8 and later.
  allow(['process_vm_readv', 'process_vm_writev', 'ptrace']),
  // amd64 and arm64 additions; runc ignores names that an architecture does not have.
  allow(['arch_prctl', 'modify_ldt']),
  allow([
    'arm_fadvise64_64',
    'arm_sync_file_range',
    'sync_file_range2',
    'breakpoint',
    'cacheflush',
    'set_tls',
  ]),
  // Hydra addition for the Chromium namespace sandbox (spike S1).
  allow(['clone', 'unshare', 'chroot']),
  // As in containerd without CAP_SYS_ADMIN: ENOSYS, so that glibc falls back to clone.
  [
    '{',
    '      "names": ["clone3"],',
    '      "action": "SCMP_ACT_ERRNO",',
    '      "errnoRet": 38',
    '}',
  ],
];
const out = [
  '{',
  '  "defaultAction": "SCMP_ACT_ERRNO",',
  '  "architectures": [',
  '    "SCMP_ARCH_X86_64",',
  '    "SCMP_ARCH_X86",',
  '    "SCMP_ARCH_X32",',
  '    "SCMP_ARCH_AARCH64",',
  '    "SCMP_ARCH_ARM"',
  '  ],',
  '  "syscalls": [',
];
entries.forEach((entry, i) => {
  const block = entry.map((line, j) => (j === 0 || j === entry.length - 1 ? `    ${line}` : line));
  if (i < entries.length - 1) block[block.length - 1] += ',';
  out.push(...block);
});
out.push('  ]', '}');
process.stdout.write(`${out.join('\n')}\n`);
console.error(`containerd ${containerdVersion}: ${names.length} default syscalls`);
```

```bash
#!/usr/bin/env bash
# Spike S1: find the smallest set of capabilities for supervisord, Xorg, and Chromium (spec 7.4).
# Runs with the main path settings (RuntimeDefault seccomp, Chromium with --no-sandbox).
# Starts with all capabilities that Pod Security baseline permits and removes one at a time;
# a capability stays only if the pod fails without it. About 15 pod starts.
# Usage: spikes/s1/cap-matrix.sh
. "$(dirname "$0")/../lib/common.sh"
. "$SPIKE_REPO/spikes/lib/neko-pod.sh"

# s1_check <label>: deploys the pod from the POD_* settings, checks it, and deletes it.
# PASS needs: pod Ready, the 5 supervisord programs RUNNING, CDP answers, "supervisorctl restart
# chromium" works (supervisord signals a process of user neko), and the pod stops in less than 20 s.
# Prints one Markdown table row and returns 0 for PASS.
s1_check() {
  local label="$1" ns="${POD_NAMESPACE:-$SPIKE_NS}" pod="${POD_NAME:-neko}"
  local programs cdp restart t0 stop_s result="PASS" detail
  delete_neko
  if ! deploy_neko; then
    detail="not Ready: $(kubectl -n "$ns" get pod "$pod" \
      -o jsonpath='{.status.containerStatuses[0].state}' 2>/dev/null || true)"
    kubectl -n "$ns" logs "$pod" -c neko --tail=60 >"$SPIKE_OUT/s1-$label.log" 2>&1 || true
    delete_neko
    printf '| %s | %s | FAIL | %s |\n' "$label" "${POD_CAPS-}" "$detail"
    return 1
  fi
  wait_programs_running || true
  programs="$(supervisor_status | grep -c ' RUNNING ' || true)"
  cdp="$(kubectl -n "$ns" exec "$pod" -c neko -- curl -fsS --max-time 5 \
    http://127.0.0.1:9222/json/version 2>/dev/null | grep -c '"Browser"' || true)"
  restart="$(kubectl -n "$ns" exec "$pod" -c neko -- \
    timeout 60 supervisorctl -c /etc/neko/supervisord.conf restart chromium 2>&1 | tr '\n' ' ' || true)"
  supervisor_status >"$SPIKE_OUT/s1-$label.status"
  kubectl -n "$ns" logs "$pod" -c neko --tail=60 >"$SPIKE_OUT/s1-$label.log" 2>&1 || true
  t0="$(date +%s)"
  delete_neko
  stop_s=$(($(date +%s) - t0))
  [ "$programs" = 5 ] || result="FAIL"
  [ "$cdp" = 1 ] || result="FAIL"
  case "$restart" in *"chromium: started"*) ;; *) result="FAIL" ;; esac
  [ "$stop_s" -lt 20 ] || result="FAIL"
  detail="programs RUNNING=$programs/5, CDP=$cdp, restart=[${restart% }], stop=${stop_s}s"
  printf '| %s | %s | %s | %s |\n' "$label" "${POD_CAPS-}" "$result" "$detail"
  [ "$result" = PASS ]
}

ensure_namespace "$SPIKE_NS"
neko_files neko-files "$SPIKE_REPO/spikes/lib/policies-cdp.json"
export POD_NAME=neko-caps POD_SECCOMP=RuntimeDefault POD_SANDBOX=image

echo "| Run | Capabilities | Result | Details |"
echo "|---|---|---|---|"
current="$BASELINE_CAPS"
POD_CAPS="$current" s1_check "baseline" || die "the pod fails with all baseline capabilities; see $SPIKE_OUT"
for cap in $BASELINE_CAPS; do
  candidate="$(printf '%s\n' $current | grep -v -x "$cap" | tr '\n' ' ' || true)"
  candidate="${candidate% }"
  if POD_CAPS="$candidate" s1_check "without-$cap"; then
    current="$candidate"
  fi
done
POD_CAPS="$current" s1_check "minimal" || die "the minimal set fails; see $SPIKE_OUT"
minimal="$(printf '%s\n' $current | LC_ALL=C sort | tr '\n' ' ')"
echo
echo "MINIMAL_CAPS=${minimal% }" | tee "$SPIKE_OUT/s1-caps.txt"
```

````markdown
## Source facts (read before the run)

- Neko 3.1.6 (`m1k1o/neko` tag `v3.1.6`, commit `65fba485`): supervisord runs as root, and the
  programs `x-server`, `pulseaudio`, `neko`, `chromium`, and `openbox` run as user `neko`.

  runtime-spec `LinuxSeccomp` object, so the file has no capability conditions.
- Chromium error messages: "No usable sandbox! If you are running on Ubuntu 23.10+ …" (no setuid

- `chrome://sandbox` prints "You are adequately sandboxed." when layer 1 (namespace or setuid), PID
````

```ts
// Spike S2: a stand-in for the gateway live proxy (spec 9.2 steps 4 and 5, and 9.3).
// It serves /s/spike/* from the Neko pod without the prefix, drops the browser Cookie header and
// the pod Set-Cookie headers, and changes the WebSocket login:
//   queryRewrite: replaces the "username" and "password" query values (spec 9.2 step 4)
//   serverLogin:  calls Neko POST /api/login and adds "Cookie: NEKO_SESSION=<token>" (step 5)
// Usage: node rewrite-proxy.mts <listen-port> <queryRewrite|serverLogin> <admin|user> <display name>
// Env: NEKO_UPSTREAM (default http://127.0.0.1:18081, a port-forward to the pod port 8080)
import http from 'node:http';
import net from 'node:net';

const [portArg, mode, profile, displayName] = process.argv.slice(2);
const upstream = new URL(process.env.NEKO_UPSTREAM ?? 'http://127.0.0.1:18081');
const PREFIX = '/s/spike';
const PASSWORDS = { admin: 'spike-admin-password', user: 'spike-user-password' };
const password = PASSWORDS[profile];
if (!portArg || !['queryRewrite', 'serverLogin'].includes(mode) || !password || !displayName) {
  console.error(
    'usage: node rewrite-proxy.mts <port> <queryRewrite|serverLogin> <admin|user> <display name>',
  );
  process.exit(2);
}

function upstreamPath(url) {
  if (url === PREFIX) return '/';
  return url.startsWith(`${PREFIX}/`) ? url.slice(PREFIX.length) : null;
}

async function nekoServerLogin() {
  const res = await fetch(new URL('/api/login', upstream), {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ username: displayName, password }),
  });
  if (!res.ok) throw new Error(`POST /api/login: HTTP ${res.status}`);
  const cookie = res.headers.getSetCookie().find((c) => c.startsWith('NEKO_SESSION='));
  if (cookie) return cookie.split(';')[0].slice('NEKO_SESSION='.length);
  const body = await res.json();
  if (typeof body.token === 'string' && body.token !== '') return body.token;
  throw new Error('the Neko login response has no token');
}

const server = http.createServer((req, res) => {
  const path = upstreamPath(req.url ?? '');
  if (path === null) {
    res.writeHead(404).end();
    return;
  }
  const headers = { ...req.headers, host: upstream.host };
  delete headers.cookie;
  const options = { host: upstream.hostname, port: upstream.port, method: req.method, path, headers };
  const up = http.request(options, (upRes) => {
    const out = { ...upRes.headers };
    delete out['set-cookie'];
    res.writeHead(upRes.statusCode ?? 502, out);
    upRes.pipe(res);
  });
  up.on('error', () => res.writeHead(502).end());
  req.pipe(up);
});

server.on('upgrade', async (req, socket, head) => {
  socket.on('error', () => socket.destroy());
  const path = upstreamPath(req.url ?? '');
  if (path === null) {
    socket.destroy();
    return;
  }
  const target = new URL(path, upstream);
  const extra = [];
  try {
    if (mode === 'queryRewrite') {
      target.searchParams.set('username', displayName);
      target.searchParams.set('password', password);
    } else {
      extra.push(`Cookie: NEKO_SESSION=${await nekoServerLogin()}`);
    }
  } catch (err) {
    console.error(`upgrade ${req.url}: ${err.message}`);
    socket.destroy();
    return;
  }
  const lines = [`GET ${target.pathname}${target.search} HTTP/1.1`, `Host: ${upstream.host}`];
  for (let i = 0; i < req.rawHeaders.length; i += 2) {
    if (/^(host|cookie)$/i.test(req.rawHeaders[i])) continue;
    lines.push(`${req.rawHeaders[i]}: ${req.rawHeaders[i + 1]}`);
  }
  lines.push(...extra);
  const shown = `${target.pathname}${target.search}`.replace(/password=[^&]*/, 'password=***');
  console.log(`upgrade ${req.url} -> ${shown} (${mode})`);
  const up = net.connect(Number(upstream.port), upstream.hostname, () => {
    up.write(`${lines.join('\r\n')}\r\n\r\n`);
    if (head.length > 0) up.write(head);
    up.pipe(socket);
    socket.pipe(up);
  });
  up.on('error', () => socket.destroy());
  socket.on('close', () => up.destroy());
});

server.listen(Number(portArg), '127.0.0.1', () => {
  console.log(`proxy ${mode} ${profile} "${displayName}" on 127.0.0.1:${portArg} -> ${upstream.host}`);
});
```

```ts
// Spikes S2 and S3: connect to a legacy Neko WebSocket URL ("/ws?password=..&username=..") and
// report the login result. Prints a JSON summary and RESULT=PASS or RESULT=FAIL (exit code 0 or 1).
// Usage: node ws-login.mts <ws-url> [--expect-name <name>] [--expect-admin true|false]
//          [--expect-disconnect] [--send <json>] [--hold <ms>] [--expect-event <event>]
const args = process.argv.slice(2);
const url = args[0];
const option = (name) => {
  const i = args.indexOf(name);
  return i >= 0 ? args[i + 1] : undefined;
};
const expectName = option('--expect-name');
const expectAdmin = option('--expect-admin');
const expectEvent = option('--expect-event');
const send = option('--send');
const hold = Number(option('--hold') ?? '0');
const expectDisconnect = args.includes('--expect-disconnect');
const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

const events = [];
const members = new Map();
let init = false;
let disconnect = null;
let closed = false;

const ws = new WebSocket(url);
ws.onmessage = (event) => {
  const msg = JSON.parse(event.data);
  events.push(msg.event);
  if (msg.event === 'member/list') for (const m of msg.members) members.set(m.id, m);
  if (msg.event === 'member/connected') members.set(msg.id, msg);
  if (msg.event === 'system/init') init = true;
  if (msg.event === 'system/disconnect') disconnect = [msg.title, msg.message].filter(Boolean).join(': ');
};
ws.onclose = () => {
  closed = true;
};
ws.onerror = () => {};

// Wait up to 10 s for the login result, then 1.5 s more for the member events.
for (let waited = 0; waited < 10000 && !init && disconnect === null && !closed; waited += 100) {
  await sleep(100);
}
if (init) await sleep(1500);
const eventsBeforeSend = events.length;
if (init && send) ws.send(send);
if (hold > 0) await sleep(hold);
ws.close();

const all = [...members.values()].map((m) => ({ displayname: m.displayname, admin: m.admin }));
const me = all.find((m) => m.displayname === expectName);
console.log(JSON.stringify({ init, disconnect, events: [...new Set(events)], members: all }));
let ok;
if (expectDisconnect) {
  ok = !init && disconnect !== null;
} else {
  ok = init;
  if (expectName !== undefined) ok = ok && me !== undefined;
  if (expectAdmin !== undefined) ok = ok && me !== undefined && String(me.admin) === expectAdmin;
  if (expectEvent !== undefined) ok = ok && events.slice(eventsBeforeSend).includes(expectEvent);
}
console.log(ok ? 'RESULT=PASS' : 'RESULT=FAIL');
process.exit(ok ? 0 : 1);
```

```ts
// Spike S2: open the legacy Neko client in Google Chrome (headless, CDP) through the proxy, and
// report the WebSocket URL that the client opens and the legacy events that it receives.
// PASS: the client opened <prefix>/ws?... and received system/init, and the member list contains
// the display name that the proxy set.
// Usage: node browser-login.mts <chrome-cdp-base> <page-url> <expected display name>
import { browserWsUrl, connect, openPage, sleep } from '../lib/cdp.mts';

const [base, pageUrl, expectName] = process.argv.slice(2);
const cdp = await connect(await browserWsUrl(base));
const { sessionId } = await openPage(cdp);
const sockets = [];
const frames = [];
cdp.on((msg) => {
  if (msg.sessionId !== sessionId) return;
  if (msg.method === 'Network.webSocketCreated') sockets.push(msg.params.url);
  if (msg.method === 'Network.webSocketFrameReceived') frames.push(msg.params.response.payloadData);
});
await cdp.send('Network.enable', {}, sessionId);
await cdp.send('Page.navigate', { url: pageUrl }, sessionId);
await sleep(10000);

const events = frames.flatMap((frame) => {
  try {
    return [JSON.parse(frame)];
  } catch {
    return [];
  }
});
const init = events.some((e) => e.event === 'system/init');
const disconnect = events.find((e) => e.event === 'system/disconnect') ?? null;
const names = events.flatMap((e) => {
  if (e.event === 'member/list') return e.members.map((m) => m.displayname);
  if (e.event === 'member/connected') return [e.displayname];
  return [];
});
const prefix = new URL(pageUrl).pathname.replace(/\/$/, '');
const opened = sockets.some((s) => new URL(s).pathname === `${prefix}/ws`);
console.log(JSON.stringify({ sockets, init, disconnect, names: [...new Set(names)] }));
const ok = opened && init && names.includes(expectName);
console.log(ok ? 'RESULT=PASS' : 'RESULT=FAIL');
cdp.close();
process.exit(ok ? 0 : 1);
```

```ts
// Spike S2 fallback (docs/superpowers/spikes/S2-websocket-login.md, spec 9.2 step 5).
// Neko 3.1.6 accepts a token on the legacy /ws handler only as the NEKO_SESSION cookie of the
// upgrade request (checked with GET /api/whoami), and only with NEKO_SESSION_COOKIE_ENABLED=true.
// The handler logs the Neko session out when the WebSocket closes, so the gateway logs in again
// for each upgrade instead of keeping one token per grant. The HTTP requests of the legacy client
// need no Neko session. The browser never gets the token (the proxy removes Set-Cookie).
export const NEKO_SESSION_COOKIE = 'NEKO_SESSION';

export async function nekoServerLogin(
  endpoint: string,
  credentials: { username: string; password: string },
): Promise<string> {
  const res = await fetch(new URL('/api/login', endpoint), {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify(credentials),
  });
  if (!res.ok) throw new Error(`Neko login failed: HTTP ${res.status}`);
  const prefix = `${NEKO_SESSION_COOKIE}=`;
  const cookie = res.headers.getSetCookie().find((value) => value.startsWith(prefix));
  const token = cookie?.slice(prefix.length).split(';')[0];
  if (!token) throw new Error(`Neko login response has no ${NEKO_SESSION_COOKIE} cookie`);
  return token;
}

export function createServerLoginStrategy(subkeys: Pick<Subkeys, 'neko'>): NekoLoginStrategy {
  return {
    name: 'serverLogin',
    forUpgrade: async ({ grant, displayName, endpoint }) => {
      const token = await nekoServerLogin(endpoint, {
        username: nekoUsername(grant.nekoProfile, displayName),
        password: nekoPassword(subkeys.neko, grant.sessionId, grant.nekoProfile),
      });
      return { query: {}, headers: { cookie: `${NEKO_SESSION_COOKIE}=${token}` } };
    },
    forHttp: () => Promise.resolve({ query: {}, headers: {} }),
    forget: () => {},
  };
}
```

```ts
// Spike S5: effects of URLBlocklist ["*"] and URLAllowlist on navigations, redirects, frames,
// subresources, page requests (exfiltration), and internal pages. It drives the Chromium of the Neko
// pod over CDP and reads the request log of the blocked site (s5-blocked) with kubectl.
// Prints a Markdown table.
// Usage: node policy-probe.mts <cdp-base> <namespace> [comma-separated check IDs]
import { execFileSync } from 'node:child_process';
import { browserWsUrl, connect, evaluate, navigate, openPage, sleep } from '../lib/cdp.mts';

const [base = 'http://127.0.0.1:19222', ns = 'hydra-spike', only] = process.argv.slice(2);
const selected = only ? new Set(only.split(',')) : null;
const A = 'http://allowed.hydra.test';
const B = 'http://blocked.hydra.test';

const tabs = await (await fetch(new URL('/json/list', base))).json();
console.log('Tabs at start:');
for (const tab of tabs.filter((t) => t.type === 'page')) console.log(`- ${tab.url} (${tab.title})`);
console.log();

const cdp = await connect(await browserWsUrl(base));
const { sessionId } = await openPage(cdp);
const rows = [];
const want = (id) => selected === null || selected.has(id);

async function nav(id, check, url, hit = null) {
  if (!want(id)) return;
  const { errorText, finalUrl } = await navigate(cdp, sessionId, url, 2500);
  rows.push({ id, check, result: errorText ? `${errorText} → ${finalUrl}` : `loaded ${finalUrl}`, hit });
}
async function onAllowedPage(id, check, expression, hit) {
  if (!want(id)) return;
  await navigate(cdp, sessionId, `${A}/frame.html`, 1500);
  let result;
  try {
    result = `returned ${JSON.stringify(await evaluate(cdp, sessionId, expression))}`;
  } catch (err) {
    result = `exception ${err.message.split('\n')[0]}`;
  }
  await sleep(2500);
  const after = await evaluate(cdp, sessionId, 'location.href').catch(() => '?');
  rows.push({ id, check, result: `${result}; page now ${after}`, hit });
}

// Navigations (browser-initiated, like Playwright MCP browser_navigate).
await nav('N1', 'allowed host', `${A}/`);
await nav('N2', 'blocked host', `${B}/hit/nav`, '/hit/nav');
await nav('N3', 'redirect allowed → blocked', `${A}/cgi-bin/redirect-blocked`, '/hit/redirect');
await nav('N4', 'redirect allowed → allowed', `${A}/cgi-bin/redirect-allowed`);
await nav('N5', 'subdomain of the allowed host', 'http://sub.allowed.hydra.test/frame.html');
// Subresources of the allowed page index.html (loaded by N1).
if (want('S1')) {
  await navigate(cdp, sessionId, `${A}/`, 3000);
  for (const [id, check, hit] of [
    ['S1', 'stylesheet from the blocked host', '/hit/css'],
    ['S2', 'script from the blocked host', '/hit/script'],
    ['S3', 'image from the blocked host', '/hit/img'],
    ['S4', 'iframe from the blocked host', '/hit/iframe'],
  ]) {
    rows.push({ id, check, result: 'subresource of index.html', hit });
  }
}
// Requests from page code on an allowed page (the exfiltration question of spec 8.7).
await onAllowedPage('J1', 'fetch() no-cors', `fetch('${B}/hit/fetch', { mode: 'no-cors' }).then(() => 'sent')`, '/hit/fetch');
await onAllowedPage(
  'J2',
  'XMLHttpRequest',
  `new Promise((r) => { const x = new XMLHttpRequest(); x.onloadend = () => r(x.status); x.open('GET', '${B}/hit/xhr'); x.send(); })`,
  '/hit/xhr',
);
await onAllowedPage('J3', 'navigator.sendBeacon', `navigator.sendBeacon('${B}/hit/beacon', 'secret')`, '/hit/beacon');
await onAllowedPage(
  'J4',
  'WebSocket',
  `new Promise((r) => { const w = new WebSocket('ws://blocked.hydra.test/hit/ws'); w.onopen = () => r('open'); w.onerror = () => r('error'); setTimeout(() => r('timeout'), 3000); })`,
  '/hit/ws',
);
await onAllowedPage(
  'J5',
  'new Image()',
  `new Promise((r) => { const i = new Image(); i.onload = i.onerror = () => r('done'); i.src = '${B}/hit/img2'; })`,
  '/hit/img2',
);
// Renderer-initiated navigations from an allowed page.
await onAllowedPage('R1', 'location.href = blocked', `location.href = '${B}/hit/js-nav'`, '/hit/js-nav');
await onAllowedPage(
  'R2',
  'form POST to blocked',
  `(() => { const f = document.createElement('form'); f.method = 'POST'; f.action = '${B}/hit/form'; document.body.append(f); f.submit(); return 'submitted'; })()`,
  '/hit/form',
);
await onAllowedPage('R3', 'window.open(blocked)', `String(window.open('${B}/hit/popup'))`, '/hit/popup');
// Internal pages and other schemes.
for (const [id, url] of [
  ['I1', 'about:blank'],
  ['I2', 'chrome://newtab/'],
  ['I3', 'chrome://new-tab-page/'],
  ['I4', 'chrome://version/'],
  ['I5', 'chrome://sandbox/'],
  ['I6', 'chrome://policy/'],
  ['I7', 'chrome://settings/'],
  ['I8', 'chrome://extensions/'],
  ['I9', 'chrome://flags/'],
  ['I10', 'devtools://devtools/bundled/inspector.html'],
  ['I11', `view-source:${A}/`],
  ['I12', 'data:text/html,<p>S5 data URL</p>'],
  ['I13', 'file:///etc/hostname'],
]) {
  await nav(id, url, url);
}
cdp.close();

const log = execFileSync('kubectl', ['-n', ns, 'logs', 's5-blocked'], { encoding: 'utf8' });
const arrived = new Set([...log.matchAll(/url:(\/hit\/[a-z0-9-]+)/g)].map((m) => m[1]));
const cell = (value) => String(value).replaceAll('|', '\\|');
console.log('| ID | Check | Chromium result | Request reached blocked.hydra.test |');
console.log('|---|---|---|---|');
for (const row of rows) {
  const reached = row.hit === null ? '-' : arrived.has(row.hit) ? 'yes' : 'no';
  console.log(`| ${row.id} | ${cell(row.check)} | ${cell(row.result)} | ${reached} |`);
}
```
